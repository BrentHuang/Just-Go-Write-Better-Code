# 关键字与预定义标识符

关键字是语言的保留字，具有特殊语法含义，不能作为标识符使用。

Go 共有 25 个关键字，见 [Keywords](https://go.dev/ref/spec#Keywords)：

```text
break        default      func         interface    select
case         defer        go           map          struct
chan         else         goto         package      switch
const        fallthrough  if           range        type
continue     for          import       return       var
```

Go 预定义标识符：[Predeclared Identifiers](https://go.dev/ref/spec#Predeclared_identifiers)，包括以下几类：

- 预定义类型：

    ```text
    any bool byte comparable
    complex64 complex128 error float32 float64
    int int8 int16 int32 int64 rune string
    uint uint8 uint16 uint32 uint64 uintptr
    ```

- 常量：true false iota
- 零值：nil
- 内置函数（Go 1.21 新增 `clear`、`max`、`min`）：

    ```text
    append cap clear close complex copy delete imag len
    make max min new panic print println real recover
    ```

这些预定义标识符属于宇宙块（Universe Block），不需要导入就可以直接使用。

不要将这些预定义标识符作为变量、类型等的名称使用，会遮蔽（shadowing）原始标识符。

```go
// int 是预定义类型，不是关键字。预定义类型是语言预先定义的类型名称，虽然可以作为标识符使用，但是强烈不推荐这样做
func f(int, y int) {  // 特别注意：这里会将第一个 int 当作参数名，编译、运行不会报错
 fmt.Printf("%d %d\n", int, y)
}

func main() {
 int := 10 // 将 int 作为变量名，会遮蔽预定义类型 int
 fmt.Println(int)

 type imag struct{} // 将 imag 作为类型名，会遮蔽内置函数 imag

 i := imag{}
 fmt.Println(i)
}
```

编译、运行不会报错，执行 `revive ./...` 或 `golangci-lint run -E revive` 会产生告警：

```text
main.go:5:8: redefinition of the built-in type int
main.go:10:2: redefinition of the built-in type int
main.go:13:2: redefinition of the built-in function imag
```

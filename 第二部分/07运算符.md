# 运算符

## 算术运算符

- `+` — 加法
- `-` — 减法
- `*` — 乘法
- `/` — 除法
- `%` — 取模。结果的符号和被除数一致，因此 `-5 % 3` 和 `-5 % -3` 结果都是 -2

在 Go 中，`++`、`--` 是语句而非运算符，只能单独作为语句使用，不能用于表达式赋值。只有 `i++`，没有 `++i`，没有“前++”、“后++”的区别。

```go
func main() {
 x := 0
 v := x++  // 编译报错
}
```

## 位运算符

- `&` — 按位与
- `|` — 按位或
- `^` — 作为二元运算符时是按位异或（相同为 0，不同为 1）；作为一元运算符时是按位取反（NOT），即 `^x` 将 x 的每一位取反。例如 `^uint8(0)` 结果为 255。Go 使用 `^` 同时承担异或和按位取反两种语义，而 C 语言使用 `^` 表示异或、`~` 表示按位取反
- `&^` — 位清除（读作 AND NOT）。`a &^ b` 清除 a 中对应 b 为 1 的位，b 为 0 的位保持 a 的原值
- `<<` — 左移。左操作数的类型决定结果类型
- `>>` — 右移。对无符号整数右移时高位补 0（逻辑右移），对有符号整数右移时高位补符号位（算术右移）

```go
func main() {
 const a uint8 = 0b0001
 const b uint8 = 0b0101
 fmt.Printf("%#b\n", a^b) // 0b100
 fmt.Printf("%#b\n", ^a)  // 0b11111110
}
```

## 赋值运算符

`=`, `+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, `&=`, `|=`, `^=`, `&^=`

## 关系运算符

`==`, `!=`, `>`, `<`, `>=`, `<=`

## 逻辑运算符

`&&`（与）、`||`（或）、`!`（非）。`&&` 优先级高于 `||`。

`&&` 和 `||` 采用短路求值（short-circuit evaluation）：如果左操作数已能确定整个表达式的结果，右操作数将不会被求值。例如在 `false && f()` 中，`f()` 不会被调用；在 `true || f()` 中，`f()` 也不会被调用。

## 运算符优先级

Go 运算符按优先级从高到低排列如下（同一行优先级相同）：

| 优先级 | 运算符 | 说明 |
| -- | -- | -- |
| 5 | `*`, `/`, `%`, `<<`, `>>`, `&`, `&^` | 乘法、除法、取模、移位、按位与、位清除 |
| 4 | `+`, `-`, `\|`, `^` | 加法、减法、按位或、按位异或 |
| 3 | `==`, `!=`, `<`, `<=`, `>`, `>=` | 关系运算符 |
| 2 | `&&` | 逻辑与 |
| 1 | `\|\|` | 逻辑或 |

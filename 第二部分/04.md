# 字符类型

字符类型用单引号定义，有两种：

- 字节类型 byte，是 `uint8` 类型的别名，表示一个 ASCII 字符或原始字节数据
- 字符类型 rune，是 `int32` 类型的别名，表示一个 Unicode 码点

字符字面量的默认类型是 `rune`，因此 `var c byte = 'A'` 实际上是 `rune` 到 `byte` 的隐式转换。

字符字面量支持以下表示形式：

| 形式 | 示例 | 说明 |
| -- | -- | -- |
| 直接字符 | `'A'`、`'中'` | 直接书写字符 |
| Unicode 码点 | `'\u0041'`、`'\U00004E2D'` | `\u` 后跟 4 位十六进制，`\U` 后跟 8 位十六进制 |
| 十六进制字节 | `'\x41'` | `\x` 后跟 2 位十六进制，表示单个字节值 |
| 八进制 | `'\101'` | `\` 后跟 3 位八进制数字，表示单个字节值（0-255） |

常见转义序列：

| 转义序列 | 含义 | Unicode 码点 |
| -- | -- | -- |
| `\n` | 换行符 | U+000A |
| `\t` | 制表符 | U+0009 |
| `\\` | 反斜杠 | U+005C |
| `\'` | 单引号 | U+0027 |
| `\"` | 双引号 | U+0022 |

```go
// autocorrect-disable
func main() {
 var c byte = 'A'
 var r rune = '中'
 fmt.Printf("type of c: %T, value: %v, character: %c, Unicode code point: %U\n", c, c, c, c) // type of c: uint8, value: 65, character: A, Unicode code point: U+0041
 fmt.Printf("type of r: %T, value: %v, character: %c, Unicode code point: %U\n", r, r, r, r) // type of r: int32, value: 20013, character: 中, Unicode code point: U+4E2D
}
// autocorrect-enable
```

# 字符类型

Go 没有独立的 `char` 类型，字符类型的底层是整数类型：

- `byte` 字节类型，是 `uint8` 的类型别名，表示一个 ASCII 字符或原始字节数据
- `rune` 字符类型，是 `int32` 的类型别名，表示一个 Unicode 码点

用单引号 `''` 书写字符字面量，字符字面量的默认类型是 `rune`，因此 `var c byte = 'A'` 实际上是 `rune` 到 `byte` 的隐式转换。

```go
// autocorrect-disable
func main() {
 var c byte = 'A'
 var r rune = '中'
 fmt.Printf("type of c: %T, value: %v, character: %c, Unicode code point: %U\n", c, c, c, c) // type of c: uint8, value: 65, character: A, Unicode code point: U+0041
 fmt.Printf("type of r: %T, value: %v, character: %c, Unicode code point: %U\n", r, r, r, r) // type of r: int32, value: 20013, character: 中, Unicode code point: U+4E2D
}
// autocorrect-enable
```

---

字符字面量支持以下表示形式：

| 形式 | 示例 | 说明 |
| -- | -- | -- |
| 直接字符 | `'A'`、`'中'` | 直接书写字符 |
| 转义序列 | `'\n'`、`'\t'` | 反斜杠 + 特定字母，表示控制字符 |
| Unicode 码点 | `'\u0041'`、`'\U00004E2D'` | `\u` 后跟 4 位十六进制，`\U` 后跟 8 位十六进制 |
| 十六进制字节 | `'\x41'` | `\x` 后跟 2 位十六进制数字，表示单个字节值（0-255） |
| 八进制字节 | `'\101'` | `\` 后跟 3 位八进制数字，表示单个字节值（0-255） |

```go
func main() {
 // \u：4 位十六进制 Unicode 码点
 ru := '\u0041'
 fmt.Printf("%c %U\n", ru, ru) // A U+0041

 // \U：8 位十六进制 Unicode 码点
 rU := '\U00000041'
 fmt.Printf("%c %U\n", rU, rU) // A U+0041

 rU = '\U00004E2D'
 fmt.Printf("%c %U\n", rU, rU) // 中 U+4E2D

 // \x：2 位十六进制字节值
 bx := '\x41'
 fmt.Printf("%c %U\n", bx, bx) // A U+0041

 // \：3 位八进制字节值
 bo := '\101'
 fmt.Printf("%c %U\n", bo, bo) // A U+0041
}
```

---

常见转义序列：

| 转义序列 | 含义 | Unicode 码点 |
| -- | -- | -- |
| `\a` | 响铃符 | U+0007 |
| `\b` | 退格符 | U+0008 |
| `\f` | 换页符 | U+000C |
| `\n` | 换行符 | U+000A |
| `\r` | 回车符 | U+000D |
| `\t` | 制表符 | U+0009 |
| `\v` | 垂直制表符 | U+000B |
| `\\` | 反斜杠 | U+005C |
| `\'` | 单引号 | U+0027 |
| `\"` | 双引号 | U+0022 |

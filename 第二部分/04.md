# 自定义类型与类型别名

## 自定义类型

语法：`type 新类型 现有类型`，例如 `type MyInt int`，创建了一个新的类型 `MyInt`，其底层类型是 `int`

- 与 `int` 不是同一类型，相互之间不能比较（编译报错）
- 它们的底层类型相同，相互之间可以进行类型转换（不能直接赋值，需要显式类型转换）

```go
type MyInt1 int
type MyInt2 int

func main() {
 var i int = 10
 var i1 MyInt1 = 10
 var i2 MyInt2 = 10

 if i == i1 { // 编译报错，不同类型不能比较
  fmt.Println("i == i1")
 }

 if i1 == i2 { // 编译报错，不同类型不能比较
  fmt.Println("i1 == i2")
 }

 i = i1 // 编译报错，不同类型不能直接赋值
 i = int(i1)

 i1 = i2         // 编译报错，不同类型不能直接赋值
 i1 = MyInt1(i2) // 显式类型转换
}
```

新类型不继承原类型的任何方法，它们的方法集相互独立。

```go
type Person struct {
 Name string
 Age  int
}

type Employee Person // 创建新类型 Employee，底层类型是 Person

// 方法集独立
func (p Person) Greet() string {
 return "Hello, " + p.Name
}

func (e Employee) Work() string {
 return e.Name + " is working"
}

func main() {
 {
  p := Person{Name: "Alice", Age: 30}
  e := Employee{Name: "Bob", Age: 25}

  // 字段结构完全相同，访问方式一样
  fmt.Println(p.Name) // Alice
  fmt.Println(e.Name) // Bob

  // 内存布局完全相同
  fmt.Println(unsafe.Sizeof(p)) // 24
  fmt.Println(unsafe.Sizeof(e)) // 24

  // 相互之间可以进行类型转换（底层类型相同）
  e = Employee(p) // 显式类型转换
  p = Person(e)   // 显式类型转换
 }

 {
  p := Person{Name: "Alice", Age: 30}
  e := Employee{Name: "Bob", Age: 25}

  // 1. 不同类型不能直接赋值
  // e = p // 编译报错

  // 2. 方法集独立
  fmt.Println(p.Greet()) // "Hello, Alice"
  fmt.Println(e.Work())  // "Bob is working"
  // p.Work()  // 编译报错：Person 没有 Work 方法
  // e.Greet() // 编译报错：Employee 没有 Greet 方法

  e = Employee(p) // p 有 Greet 方法，强制转换为 Employee 类型后，e 也没有 Greet 方法
  // e.Greet()       // 编译报错：Employee 仍然没有 Greet 方法
 }
}
```

## 类型别名

语法：`type 别名类型 = 现有类型`，例如 `type MyInt = int`，只是给 `int` 类型起一个别名 `MyInt`，没有创建新类型

- 别名类型和原类型在类型系统中完全等价的，相互之间可以比较和直接赋值（无需显式类型转换）

```go
type MyInt = int // 类型别名

func main() {
 var i int = 10
 var i1 MyInt = 10

 // 完全等价，可以直接比较和赋值
 i = i1

 if i == i1 {
  fmt.Println("i == i1")
 }
}
```

## 分组声明

自定义类型和类型别名也支持分组（小括号），将相关的声明放在一起：

```go
// 自定义类型
type (
 Area   float64
 Volume float64
)

// 类型别名
type (
 Area1   = float64
 Volume1 = float64
)
```

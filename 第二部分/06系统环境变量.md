# 系统环境变量

读写环境变量的 API：

- [func Environ() []string](https://pkg.go.dev/os#Environ) 获取所有环境变量的键值对，格式为“key=value”
- [func Getenv(key string) string](https://pkg.go.dev/os#Getenv) 根据 key 获取环境变量的值，如果不存在这个环境变量则返回空字符串。key 在 Linux/macOS 上区分大小写，Windows 上不区分。如果返回空字符串，不能区分是因为这个环境变量不存在，还是因为这个环境变量的值本身就是空字符串
- [func LookupEnv(key string) (string, bool)](https://pkg.go.dev/os#LookupEnv) 根据 key 查找环境变量的值，如果不存在这个环境变量，则第二个 bool 返回值为 false
- [func ExpandEnv(s string) string](https://pkg.go.dev/os#ExpandEnv) 将参数字符串中的环境变量（`$var` 或 `${var}`）替换为其对应的值，如果环境变量不存在则替换为空字符串
- [func Setenv(key, value string) error](https://pkg.go.dev/os#Setenv) 设置环境变量的值
- [func Unsetenv(key string) error](https://pkg.go.dev/os#Unsetenv) 删除指定 key 的环境变量
- [func Clearenv()](https://pkg.go.dev/os#Clearenv) 删除所有环境变量，仅影响当前进程的环境变量（在进程启动时从系统继承而来），不影响系统或其它进程

这些操作通常不是并发安全的，多协程并发时需要同步机制。

```go
func main() {
 env := os.Environ()
 fmt.Println(env)

 path := os.Getenv("PATH")
 fmt.Println(path)

 path = os.Getenv("Path") // Linux/macOS 上 key 区分大小写，"Path" 与 "PATH" 是不同变量，Windows 上不区分大小写
 fmt.Println(path) // 空字符串

 path, ok := os.LookupEnv("PATH")
 fmt.Printf("%s %t\n", path, ok)

 // 将参数中的环境变量（$var 或 ${var}）替换为其对应的值，如果不存在则为空字符串
 fmt.Println(os.ExpandEnv("home is: $HOME"))
 fmt.Println(os.ExpandEnv("home is: ${HOME}"))

 os.Setenv("DB_USER", "fbi-001")
 os.Unsetenv("DB_USER")
 // os.Clearenv()
}
```

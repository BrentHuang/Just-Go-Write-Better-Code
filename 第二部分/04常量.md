# 常量

用 `const` 关键字声明常量，语法：`const 常量名 类型 = 值/表达式`。注意：

- 常量命名也采用驼峰法，而不是像 C 语言那样全大写加下划线分隔
- 常量在声明时必须初始化，常量表达式在编译阶段求值，而非运行时
- 类型可省略（编译器从右侧值推导），在实际中绝大部分常量声明都不写类型，只有当明确需要指定类型（比如限制为 int64 或避免精度损失）时才会加上类型

```go
const (
 secondsPerMinute = 60
 minutesPerHour   = 60
 secondsPerHour   = secondsPerMinute * minutesPerHour  // 3600
)
```

允许在一行同时声明多个常量（用逗号分隔，这些常量的类型可以不同），每个常量对应一个初始值。例如 `const a, b = 1, false`，a 为 `int` 类型，b 为 `bool` 类型。

不能用 `:=` 声明常量，即使是函数体中的局部常量也不行。

## 分组声明

常量也支持分组声明：

```go
// 分组声明全局常量
const (
 A = 1
 B = 2
)

const x = 33

func main() {
 // 分组声明局部常量
 const (
  C = 1
  D = 2
 )

 const y = 44

 fmt.Printf("%d %d %d %d %d %d\n", A, B, C, D, x, y)
}
```

分组声明允许在一行同时声明多个常量（用逗号分隔，这些常量的类型可以不同）：

```go
func main() {
 const (
  A, B = iota, iota + 1 // 分组声明，在一行同时声明多个常量
  C, D
  E, F = 5, false
 )
 fmt.Printf("%d %d %d %d %d %t\n", A, B, C, D, E, F) // 0 1 1 2 5 false
}
```

## 常量的类型限制

常量只能是基本数据类型，包括：

- bool 类型
- 数字类型：整型、浮点型、复数类型
- string 类型
- 字符类型：byte、rune

常量本质上是编译期可求值的、不可寻址的、无类型或受限类型的标量值。结构体和数组等复合类型，其元素/字段的访问依赖于运行时确定的内存地址，且内部可能包含指针，使得它们无法在编译期被固化为一个不需要内存存储的纯值。此外，即使是不含指针的复合类型，Go 出于对语言简洁性和编译效率的考量，也明确将它们排除在常量类型之外。

```go
func main() {
 const arr = [3]int{1, 2, 3} // 编译报错
 fmt.Println(arr)

 type Point struct{ X, Y int }
 const p = Point{X: 1, Y: 2} // 编译报错
 fmt.Println(p)
}

// ./main.go:6:14: [3]int{…} (value of type [3]int) is not constant
// ./main.go:10:12: Point{…} (value of struct type Point) is not constant
```

## 类型化与无类型常量

- 类型化（typed）常量：`const Pi float64 = 3.141592653589793`，声明时指定类型
- 无类型（untyped）常量：`const Pi = 3.141592653589793`，声明时不指定类型

无类型常量可以隐式转换为兼容类型，在需要时才确定具体类型。示例：

```go
func main() {
 const c = 3 + 0i
 const f1 float64 = c // untyped complex -> float64，相当于 float64(3+0i)
 var f2 float64 = f1
 fmt.Printf("%f %f\n", f1, f2) // 3.000000 3.000000
}
```

对于常量字面量，不同的写法对应不同的类型。例如 `0`、`0.0`、`0i` 和 `\u0000` 虽然有着相同的常量值，但是它们分别对应无类型的整型、无类型的浮点型、无类型的复数类型和无类型的 rune 类型。同样，true 和 false 是无类型的布尔类型，字符串字面量是无类型的字符串类型。

```go
func main() {
 const i1 = 0        // untyped int
 const i2 = 0.0      // untyped float
 const i3 = 0i       // untyped complex
 const i4 = '\u0000' // untyped rune

 const b = true    // untyped bool
 const s = "hello" // untyped string
}
```

除非需要明确的类型，应该优先使用无类型常量。编译器为无类型数字常量提供了比基础类型更高精度的算术运算，并且可以直接用于各类表达式而无需显式类型转换。

```go
func main() {
 const (
  _   = 1 << (10 * iota)
  KiB // 1024
  MiB // 1048576
  GiB // 1073741824
  TiB // 1099511627776             超出了 uint32 范围
  PiB // 1125899906842624
  EiB // 1152921504606846976
  ZiB // 1180591620717411303424    超出了 uint64 范围
  YiB // 1208925819614629174706176
 )

 fmt.Println(uint32(math.MaxUint32)) // 4294967295
 fmt.Println(uint64(math.MaxUint64)) // 18446744073709551615

 // 无类型常量 ZiB 和 YiB 的值已经超出 Go 中任何整数类型所能表示的范围，但是它们依然是合法的常量，而且像下面的常量表达式依然有效，不需要进行类型转换（也没有类型可以转了呀）
 fmt.Println(YiB / ZiB) // 1024
}
```

## 常量继承规则

在常量分组声明中，未显式赋值的常量将继承上一个常量的值/表达式（iota 表达式）：

```go
func main() {
 const (
  a = 10
  b   // 没有显式赋值，继承 a 的值 10
  c   // 没有显式赋值，继承 b 的值 10
  d = 30 // 显式设置为 30
  e   // 没有显式赋值，继承 d 的值 30
 )

 fmt.Printf("%d %d %d %d %d\n", a, b, c, d, e)  // 10 10 10 30 30
}
```

## 常量的地址

常量名只是编译期的一个符号，编译器会将常量值直接嵌入到机器码中。与变量不同，常量不会在运行时分配内存，所以不能对常量取地址。

```go
func main() {
 const x = 10    // x 只是编译期的一个符号，没有内存地址
 fmt.Println(&x)  // 对常量取地址，编译报错
}
```

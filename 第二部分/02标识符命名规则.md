
# 标识符命名规则

Go 标识符（变量名、常量名、函数名、类型名、接口名等）必须以 Unicode 字母或下划线开头，后面可以跟任意数量的字母、数字、下划线。不能以数字开头，一般也不以下划线开头。

Go 标识符使用驼峰命名（CamelCase），不使用蛇形命名（snake_case、SNAKE_CASE），也不使用匈牙利命名（strName）。

首字母的大小写决定可见性（是否导出）：

| 命名类型 | 格式 | 使用场景 | 示例 |
| -- | -- | -- | -- |
| 大驼峰 | `CamelCase` | 导出的标识符，能够在包外访问 | `HTTPServer`, `UserID` |
| 小驼峰 | `camelCase` | 未导出的标识符，只能在包内访问 | `localVariable`, `internalFunc` |

注意：

- 单独的下划线 `_` 是一个特殊的空白标识符，与以下划线开头的变量名是完全不同的概念
- 在一个包中任意源文件中定义的包级（非函数体中）标识符，对该包中的其它源文件都是可见的，可以直接访问，如同它们书写在同一源文件中一样
- 预定义标识符不受首字母大小写导出规则约束，在任何包中均可直接使用

特殊命名场景：

- 缩略词保持全大写，如 `ID`、`HTTP`；私有（未导出）且在开头时全小写，如 `httpHandler`
- 自定义错误类型以 `Error` 结尾，如 `ValidationError`，导出的错误变量以 `Err` 开头，如 `ErrNotFound`，未导出的错误变量以 `err` 开头
- 配置结构体类型以 `Config` 结尾，变量一般为 `cfg` 或 `conf`
- Getter 不加 `Get` 前缀，如 `Owner()` 而非 `GetOwner()`；Setter 加 `Set` 前缀，如 `SetOwner()`
- 测试函数名以 `Test` 开头，可通过下划线对名称分组，如 `TestMyFunction_WhatIsBeingTested`
- 基准测试函数名以 `Benchmark` 开头，如 `BenchmarkMyFunction`
- 示例函数名以 `Example` 开头，如 `ExampleMyFunction`。若示例函数包含 `// Output:` 注释，则会被 `go test` 作为可执行示例进行验证
- 模糊测试函数名以 `Fuzz` 开头（Go 1.18+），如 `FuzzMyFunction`
- 测试辅助函数（helper）命名无强制前缀，但应调用 `t.Helper()` 标记，使错误信息指向调用者而非辅助函数内部 todo

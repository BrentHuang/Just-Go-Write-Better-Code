# 变量

用 `var` 关键字声明变量，语法：`var 变量名 类型 = 表达式`。注意：

- 变量名在前，变量类型在后
- 可以省略类型或表达式，但不能同时省略
- 提供初始值时类型可省略，编译器从初始值自动推导类型；未提供初始值时变量会被隐式初始化为其类型的零值

允许在一行同时声明多个变量（用逗号分隔，这些变量的类型可以不同），每个变量对应一个初始值。例如 `var a, b, c = true, false, "no!"`，a 为 `bool` 类型，b 为 `bool` 类型，c 为 `string` 类型。

## 短变量声明

`:=` 用于短变量声明，注意：

- 只能在函数体中使用，不能用于声明全局变量
- 不需要声明类型（也不能声明类型），必须初始化，编译器从初始值自动推导类型
- 允许在一行同时声明多个短变量（用逗号分隔，这些变量的类型可以不同），其中必须至少包含一个新变量，对已声明的变量仅执行赋值操作

```go
func main() {
 x, y := 10, 20        // 同时声明两个新的 int 变量（相同类型）
 a, b := "hello", true // 同时声明两个新的 string 和 bool 变量（不同类型）
}
```

```go
func main() {
 x := 10
 x, y := 20, "hello"  // 合法：y 是新变量，x 被重新赋值
 // x := 30  // 错误：没有新变量
}
```

短变量使用场景：

接收函数的多个返回值：`f, err := os.Open("data.txt")`

循环或条件语句中的临时变量：

```go
for i := 0; i < 10; i++ {
// ...
}
```

## 类型推导

声明变量时如果未指定类型，变量的类型可以通过右侧值的类型推导出来。

当右侧值的类型已知时，新变量的类型将是相同的类型：

```go
func main() {
 var i int
 j := i // j 也是 int 类型
 fmt.Printf("%T", j) // int
}
```

当右侧值包含无类型（untyped）的数字字面量时，新变量可能是 int、float64 或 complex128，具体取决于字面量的精度：

```go
func main() {
 i := 42           // int
 f := 3.142        // float64
 g := 0.867 + 0.5i // complex128
 a := 'A'          // rune

 fmt.Printf("%T, %T, %T, %T\n", i, f, g, a) // int, float64, complex128, int32  --rune 是 int32 的别名
 fmt.Printf("%v, %v, %v, %v\n", i, f, g, a) // 42, 3.142, (0.867+0.5i), 65
}
```

## 分组声明

用 `()` 将多个相关变量声明括起来，每个变量声明单独占一行。全局变量和局部变量都允许分组声明。

```go
// 分组声明全局变量
var (
 a = 1
 b = 2
)

var x = 33

func main() {
 // 分组声明局部变量
 var (
  c = 3
  d = 4
 )

 var y = 44

 fmt.Printf("%d %d %d %d %d %d\n", a, b, c, d, x, y) // 1 2 3 4 33 44
}
```

分组声明允许在一行同时声明多个变量（用逗号分隔，这些变量的类型可以不同）：

```go
func main() {
 var (
  A, B = 1, 2 // 分组声明，在一行同时声明多个变量
  C, D = 3, 4
  E, F = 5, false
 )
 fmt.Printf("%d %d %d %d %d %t\n", A, B, C, D, E, F) // 1 2 3 4 5 false
}
```

## 变量遮蔽

当局部变量与全局变量同名（允许它们的类型不同）时，局部变量会遮蔽全局变量，并且在函数体中无法访问被遮蔽的全局变量：

```go
var x float64 // 全局变量 x，类型为 float64

func f() {
 x := 2         // 声明一个新的局部变量 x，类型为 int。函数体中无法访问被遮蔽的全局变量 x
 fmt.Println(x) // 2  --局部变量 x
}
func main() {
 x = 1          // 这里修改的是全局变量 x 的值
 fmt.Println(x) // 1  --float64 类型的全局变量 x
 f()            // 2  --函数 f 中的是 int 类型的局部变量 x，遮蔽了同名的全局变量 x
 fmt.Println(x) // 1  --float64 类型的全局变量 x
}
```

Go 不提供类似 Python 的 `global` 机制来访问被遮蔽的全局变量，这种设计是有意为之，目的是简化作用域规则，避免混淆。

类似地，内层代码块的变量也会遮蔽外层代码块的同名变量，for/if 初始化语句中的局部变量 i 也会遮蔽所在函数体中的同名局部变量。

```go
func main() {
 i := 42               // int
 fmt.Printf("%v\n", i) // 42

 for i := 0; i < 3; i++ { // 这里的 i 会遮蔽外层的 i
  fmt.Printf("%v\n", i) // 0, 1, 2
 }

 fmt.Printf("%v\n", i) // 42
}
```

注意：

- 函数体中声明的变量、函数的参数、函数的返回值都是局部变量
- 可通过大括号块 `{}` 控制变量的作用域，大括号块中的变量是单独的内层作用域，内层的变量会遮蔽外层的同名变量，即使它们的类型不同
- 不要使用 `len`、`cap`、`error`、`string`、`context` 等预定义标识符或标准库包名作为变量名，会引起混淆

```go
// len: 内置函数，用于获取长度
// cap: 内置函数，用于获取容量
// error: 内置接口类型
// string: 内置基础类型
// context: 标准库包名（context 包）
func main() {
 a := [5]int{1, 2, 3, 4, 5}
 fmt.Printf("%v\n", len(a)) // 5

 len := 20  // len 是预定义标识符（内置函数），这里被当作了变量名使用，会遮蔽预定义的函数 len
 fmt.Printf("%v\n", len) // 20
 // fmt.Printf("%v\n", len(a)) // 编译报错
}
```

## 变量的地址

变量的地址是变量在内存中的位置，用 `&` 运算符获取。

```go
func main() {
 var a int = 10
 fmt.Printf("%p\n", &a) // 0xb02d991c008  --a 的地址
}
```

## 依赖注入

应使用依赖注入替代全局变量。依赖注入是指将依赖（如数据库连接、应用配置、日志组件等）从外部传入，而非在函数体中自行创建或从全局获取。

反面示例：

```go
// log/logger.go
package log

type Logger struct {
}

func NewLogger() *Logger {
 return &Logger{}
}

func (l *Logger) SetPrefix(prefix string) {
 // ...
}

func (l *Logger) Println(msg string) {
 // ...
}

// main.go
package main

import (
 "example.com/hello-world/log"
)

// 全局变量被修改，带来的问题：1. 测试时无法替换 logger 2. 多处修改全局变量，状态难以追踪，可维护性差 3. 并发不安全
var logger *log.Logger // 用全局变量持有依赖

func InitLogger() {
 // 修改全局变量
 logger = log.NewLogger()
}

func SetPrefix(prefix string) {
 // 再次修改全局变量
 logger.SetPrefix(prefix + ": ")
}

func Process() {
 // 依赖全局变量
 logger.Println("processing...")
}
```

正面示例：

```go
// main.go
package main

import (
 "testing"

 "example.com/hello-world/log"
)

// 通过依赖注入传递所有依赖
type App struct {
 logger *log.Logger // 依赖作为结构体字段
}

// 构造函数注入
func NewApp(logger *log.Logger) *App {
 return &App{
  logger: logger,
 }
}

func (a *App) SetPrefix(prefix string) {
 a.logger.SetPrefix(prefix + ": ")
}

func (a *App) Process() {
 a.logger.Println("processing...")
}

// 测试时可以注入 mock logger
func TestApp(t *testing.T) {
 mockLogger := log.Logger{}
 app := NewApp(&mockLogger)
 app.SetPrefix("test")
 app.Process()
 // ...
}
```

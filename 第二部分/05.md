# 字符串类型

`string` 是基本数据类型，它是一种不可变（不能被修改）的值类型，并不是引用类型。字符串字面量有两种书写方式：

- 使用双引号 `""`，会识别并转义其中的转义序列，例如将 `\n` 解释为换行
- 使用反引号 ` `` `，称为原始（raw）字符串字面量。反引号中的所有内容，包括转义序列，都会被直接当作字面量处理（比如不会将 `\n` 解释为换行）。

```go
func main() {
 var s1 string     // 声明字符串变量，默认值为 ""
 s2 := "Hello\n世界" // 使用字符串字面量初始化（双引号）
 s3 := `Hello\n世界` // 原始字符串字面量（反引号）
 fmt.Println(s1)
 fmt.Println(s2)
 fmt.Println(s3)
}

// Hello
// 世界
// Hello\n世界
```

可以在字符串字面量中使用任意的字符字面量：

```go
func main() {
 s1 := "Hello\x20World" // 包含\x十六进制字节，\x20 是空格的 ASCII 码，等价于 "Hello World"
 fmt.Printf("%s\n", s1)

 s2 := "Hello\040World" // 包含\八进制字节，\040 也是空格（八进制 40 = 十进制 32 = 十六进制 20）
 fmt.Printf("%s\n", s2)

 s3 := "Hello\tWorld" // 包含 \t 转义序列
 fmt.Printf("%s\n", s3)

 // \u4E16\u754C 是中文"世界"，\u263A 是笑脸图标，\u2764\uFE0F 是心形图标，\u00E9 是重音 e
 s4 := "Hello \u4E16\u754C \u263A \u2764\uFE0F \u00E9" // 包含 \u Unicode 码点
 fmt.Printf("%s\n", s4)
}
```

原始字符串字面量天然支持多行字符串的书写，正则表达式一般也使用原始字符串字面量来书写。

Go 官方没有提供像 Javascript 模板字符串（`` `${name}` ``）或 Python f-string（`f'{name}'`）那样的插值语法，但一些第三方库支持。

## 字符串底层结构

字符串底层结构（源码：`${GOROOT}/src/runtime/string.go`）：

```go
type stringStruct struct {
    str unsafe.Pointer  // 指向底层字节序列的指针
    len int             // 字符串的字节长度
}
```

字符串底层存储的是 UTF-8 编码的字节序列（数组），一个 Unicode 字符可能占用 1~4 个字节，底层的第 i 个字节并不一定是字符串的第 i 个字符。

特别注意：通过索引 `s[i]` 访问的是字节而非字符！ASCII 字符只占用 1 个字节，可以通过 `s[i]` 正确访问。中文字符的 UTF-8 编码通常占用 3 个字节，通过 `s[i]` 只能获取到中文字符的起始字节，并不是完整的字符。

`string` 和字节切片 `[]byte` 可以相互转换：

```go
// ASCII 码：0:48 A:65 a:97
func main() {
 s := "1Aa 中国"

 b := []byte(s)              // 将字符串转换为字节切片  --[]byte 表示字节切片类型
 fmt.Println(b)              // [49 65 97 32 228 184 173 229 155 189]

 s2 := string(b)             // 将字节切片转换为字符串
 fmt.Println(s2)             // 1Aa 中国

 r := []rune(s)              // 将字符串转换为字符切片  --[]rune 表示字符切片类型
 for i := 0; i < len(r); i++ {  // for c := range r 也行
  fmt.Printf("%c ", r[i])  // 1 A a   中 国
 }
}
```

字符串一旦创建，其内容（即底层的字节序列）就不能被修改了，通过索引 `s[i]` 修改字符串会导致编译报错。任何看似修改的操作（如拼接、切片、替换）都会返回一个新的字符串，而原始字符串保持不变。

```go
func main() {
 s := "hello"
 s[0] = 'H'  // 尝试通过索引 `s[i]` 修改字符串，编译报错
}
```

字符串赋值或传参（函数参数传递）时，仅复制上述的底层结构体（指针和长度），不会复制底层字节数组，从而实现高效传递。

## 字符串的长度

内置函数 [len](https://pkg.go.dev/builtin#len) 用于获取字符串、数组、切片等的长度。

字符串的字节长度和字符长度是不同概念：

```go
func main() {
 s := "hello, 世界"
 byteCount := len(s)                         // len 获取的是字符串底层 UTF-8 编码的字节序列的长度
 runeCount := utf8.RuneCountInString(s)      // utf8.RuneCountInString 获取的是字符串中有多少个 UTF-8 编码的 rune 字符
 fmt.Printf("%d %d\n", byteCount, runeCount) // 13 9

 // 字符串类型变量在 64 位系统上的 size 总是 16:8 字节的“底层数据指针” + 8 字节的“字节长度”
 sz := unsafe.Sizeof(s)
 fmt.Println(sz) // 16
}
```

string 不能取 [cap](https://pkg.go.dev/builtin#cap)，编译报错。

## 字符串连接

```go
func main() {
 s1 := "Hello"
 s2 := "World"
 // 方法 1. 通过加号连接字符串：少量短字符串高效，编译器优化
 result := s1 + ", " + s2
 fmt.Println(result) // Hello, World

 // 方法 2. strings.Builder：循环拼接大量字符串时的最佳选择
 // 由于字符串的不可变性，频繁使用加号进行拼接会导致大量临时字符串的分配，性能较差，推荐使用 strings.Builder 高效构建字符串
 var builder strings.Builder
 builder.Grow(1024) // 预分配 1KB 空间
 builder.WriteString(s1)
 builder.WriteString(", ")
 builder.WriteString(s2)
 result = builder.String()
 fmt.Println(result) // Hello, World

 // 方法 3. strings.Join：将字符串切片连接为一个字符串，中间插入指定的分隔符
 words := []string{"Hello", "World", "Go"}
 result = strings.Join(words, ", ")
 fmt.Println(result) // Hello, World, Go

 // 方法 4. 使用 fmt.Sprintf 函数格式化输出（最慢）
 result = fmt.Sprintf("%s, %s", s1, s2)
 fmt.Println(result) // Hello, World

 // 方法 5. bytes.Buffer：适合同时需要字节操作的场景
 var buf bytes.Buffer
 buf.Grow(1024) // 预分配 1KB 空间
 buf.WriteString("hello")
 buf.WriteByte(' ')
 buf.WriteString("world")
 result = buf.String()
 fmt.Println(result) // hello world
}
```

## 字符串遍历

for range 循环会自动识别 UTF-8 编码的 rune 字符边界，返回每个 rune 字符的起始字节索引和完整的 rune 字符。

```go
func main() {
 s := `go\t语言` // '\' 和 't' 是两个字符
 // 字节遍历，索引对应的每个元素都是一个字节
 for i := 0; i < len(s); i++ {
  fmt.Printf("%#X ", s[i]) // 0X67 0X6F 0X5C 0X74 0XE8 0XAF 0XAD 0XE8 0XA8 0X80  --注意 s[i] 取的是索引 i 处的字节
 }

 fmt.Println()

 // rune 字符遍历
 // 方法 1：for range 循环（推荐）
 // for range 迭代字符串时，返回每个 rune 字符的起始字节索引和完整的 rune 字符
 for _, r := range s {
  fmt.Printf("%c ", r) // g o \ t 语 言  --从输出可以看到，字符串中的 "\t" 是 '\' 和 't' 两个字符
  r = 'X'              // r 是副本，修改 r 不影响 s
 }

 fmt.Println()
 fmt.Println(s) // go\t语言

 for i := range s {
  fmt.Printf("%d ", i) // 0 1 2 3 4 7
  // 原因分析：for i := range s 中的 i 指的是 rune 字符的起始字节索引
  // 'g'、'o'、'\'、't' 都是单字节字符，索引连续：0、1、2、3，'语'、'言'是 UTF-8 编码的中文字符，各占 3 字节，所以'语'的起始字节索引是 4，'言'的起始字节索引是 7
 }

 fmt.Println()

 for _, r := range s {
  fmt.Printf("%#U ", r) // U+0067 'g' U+006F 'o' U+005C '\' U+0074 't' U+8BED '语' U+8A00 '言'  --%U 输出 rune 字符的 Unicode 码点，# 前缀在 Unicode 码点后追加空格和带单引号的字符
 }

 fmt.Println()

 // 方法 2：先将字符串转换为 rune 切片
 runes := []rune(s)
 fmt.Println(len(runes))                // 6
 fmt.Println(utf8.RuneCountInString(s)) // 6
 for i := range runes {
  fmt.Printf("%c ", runes[i]) // g o \ t 语 言
 }

 fmt.Println()

 for i := 0; i < utf8.RuneCountInString(s); i++ {
  fmt.Printf("%#U ", s[i]) // U+0067 'g' U+006F 'o' U+005C '\' U+0074 't' U+00E8 'è' U+00AF '¯'  --注意：s[i] 取的是字节，不是字符！
 }

 fmt.Println()
}
```

## 字符串切片

子字符串切片操作 `s[i:j]`：基于字符串 `s` 底层字节序列的第 i 个字节到第 j 个字节（包含 `s[i]`，不包含 `s[j]`）生成一个新字符串。需要注意：

- 下标 `i` 和 `j` 是按字节计数的，并非按 rune 字符计数。对于包含中文字符的字符串，切片的起止位置可能会将多个字节的 UTF-8 编码切成两部分，结果是一个包含“破碎”字符的字符串
- 当 `i` 等于 `j` 时，结果是一个空字符串

```go
func main() {
 s := "hello 世界"
 for i := range s {
  fmt.Println(i, s[i])
 }

 // 按字节切片：取前 3 个元素的字节
 s1 := s[0:3]
 fmt.Println(s1) // hel  --前 3 个字节

 // 跨越中文字符切片（会产生破碎字符）
 s2 := s[0:7]
 fmt.Printf("%q\n", s2) // "hello \xe4" --第 6 个位置正好是 "世" 的第一个字节

 // 安全的 rune 切片转换
 runes := []rune(s)
 s3 := string(runes[0:7])
 fmt.Println(s3) // hello 世
}
```

## strings 包

[strings](https://pkg.go.dev/strings) 包提供了大量函数来对字符串自身的内容进行处理。因为 Go 的字符串是不可变的，所以这些函数通常不会修改原字符串，而是返回一个处理后的新字符串。

它的主要功能可以分为几类：

- 查找与判断：检查是否包含某个子串（Contains），统计出现次数（Count），查找位置（Index），判断前缀/后缀（HasPrefix、HasSuffix）等
- 比较：比较两个字符串的字典序（Compare），或忽略大小写判断是否相等（EqualFold）
- 修改与转换：转换大小写（ToUpper, ToLower），替换内容（Replace、ReplaceAll），修剪首尾指定字符（Trim、TrimLeft、TrimRight、TrimSpace）等
- 分割与拼接：将字符串按分隔符拆分成切片（Split），或将多个字符串高效拼接（Join、Builder）
- 复制：创建字符串的副本（Clone）

```go
func main() {
 a := "hello"
 b := "Hello"

 // 不区分大小写比较（Unicode Case Folding 规则）
 r1 := strings.EqualFold(a, b)
 fmt.Println(r1) // true

 // 区分大小写比较：==（推荐）或 strings.Compare
 fmt.Printf("%v\n", a == b) // false

 r2 := strings.Compare(a, b) // 如果 a == b，则结果为 0；如果 a < b，则结果为 -1；如果 a > b，则结果为 +1
 fmt.Printf("%v\n", r2)        // 1  --h 的 Unicode 码点大于 H 的 Unicode 码点
}
```

将句子中的每个单词首字母大写：

```go
import (
 "fmt"

 "golang.org/x/text/cases"
 "golang.org/x/text/language"
)

func main() {
 // 创建英文标题转换器
 caser := cases.Title(language.English)

 s := "hello world"
 fmt.Println(caser.String(s))  // 输出："Hello World"
}
```

## strconv 包

[strconv](https://pkg.go.dev/strconv) 包主要负责基本数据类型（如整型、浮点型、布尔型）与它们的字符串表示形式之间的相互转换。

它的核心功能包括：

- 字符串 -> 其他类型（解析）：将字符串解析为对应的值，如 Atoi（字符串转 int）、ParseBool、ParseFloat、ParseInt 等
- 其他类型 -> 字符串（格式化）：将值格式化为字符串，如 Itoa（int 转字符串）、FormatBool、FormatFloat、FormatInt 等
- 字符串的“引用”处理：为字符串添加引号，使其成为合法的 Go 语言字面量，主要用于生成安全或转义后的字符串。如 Quote、QuoteToASCII、Unquote 等

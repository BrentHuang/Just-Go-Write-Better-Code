# 文件操作

Go 提供了丰富的标准库来支持文件处理，包括文件的打开、关闭、读取、写入、追加、删除等操作。

- os 包：提供平台无关的文件系统操作，如打开、创建、删除、重命名、文件状态、读写等
- path/filepath包：跨平台的路径操作函数，路径分隔符推荐使用 /（跨平台），或使用 filepath.Join 构建路径
- io 包：定义了 Reader 和 Writer 接口，是读写操作的基石
- bufio 包：带缓冲的 I/O，能减少系统调用，提高读写性能
- io/ioutil包：Go 1.16+ 已弃用，请使用 os 或 io 包中的替代函数

标准输入、标准输出、标准错误：os.Stdin，os.Stdout，os.Stderr

bufio.NewReader, bufio.NewScanner

## os 包

[os](https://pkg.go.dev/os) 包提供了平台无关的操作系统功能接口，是 Go 中进行文件操作的核心包。

### 文件打开与创建

| 函数 | 说明 | 文档 |
| -- | -- | -- |
| `os.Open(name string) (*File, error)` | 以只读模式打开文件，等价于 `os.OpenFile(name, O_RDONLY, 0)` | <https://pkg.go.dev/os#Open> |
| `os.OpenFile(name string, flag int, perm FileMode) (*File, error)` | 以指定标志和权限打开/创建文件，是最底层的打开函数 | <https://pkg.go.dev/os#OpenFile> |
| `os.Create(name string) (*File, error)` | 创建或截断文件（若已存在则清空），等价于 `os.OpenFile(name, O_RDWR\|O_CREATE\|O_TRUNC, 0666)` | <https://pkg.go.dev/os#Create> |

打开标志（flag）：

| 标志 | 说明 |
| -- | -- |
| `os.O_RDONLY` | 只读 |
| `os.O_WRONLY` | 只写 |
| `os.O_RDWR` | 读写 |
| `os.O_APPEND` | 追加模式，写入时追加到文件末尾 |
| `os.O_CREATE` | 文件不存在时创建 |
| `os.O_TRUNC` | 打开时截断文件（清空内容） |
| `os.O_EXCL` | 与 O_CREATE 配合，文件已存在则返回错误 |
| `os.O_SYNC` | 同步写入，每次写入都等待磁盘确认 |

文件权限（FileMode）使用 Unix 风格的三位八进制数表示，如 `0644`（所有者读写、组只读、其他只读）、`0755`（所有者读写执行、组和其他读执行）。

```go
func main() {
 // 只读打开
 f, err := os.Open("test.txt")
 if err != nil {
  log.Fatal(err)
 }
 defer f.Close()

 // 读写 + 新建 + 追加模式，权限 0644
 f2, err := os.OpenFile("log.txt", os.O_RDWR|os.O_CREATE|os.O_APPEND, 0644)
 if err != nil {
  log.Fatal(err)
 }
 defer f2.Close()

 // 创建新文件（如已存在则清空）
 f3, err := os.Create("output.txt")
 if err != nil {
  log.Fatal(err)
 }
 defer f3.Close()
}
```

### 文件读取

[os.File](https://pkg.go.dev/os#File) 实现了 `io.Reader` 接口，可以直接使用 `Read` 方法，也可以配合 `io` 包的工具函数。

```go
func main() {
 // 方式一：os.ReadFile 一次性读取整个文件（适合小文件）
 data, err := os.ReadFile("test.txt")
 if err != nil {
  log.Fatal(err)
 }
 fmt.Println(string(data))

 // 方式二：os.File.Read 分块读取（适合大文件）
 f, err := os.Open("large.txt")
 if err != nil {
  log.Fatal(err)
 }
 defer f.Close()

 buf := make([]byte, 4096)
 for {
  n, err := f.Read(buf)
  if n > 0 {
   fmt.Print(string(buf[:n]))
  }
  if err == io.EOF {
   break
  }
  if err != nil {
   log.Fatal(err)
  }
 }
}
```

### 文件信息与状态

```go
type FileInfo interface {

```

```go
func main() {

 if err != nil {
  if os.IsNotExist(err) {
   fmt.Println("文件不存在")
   return
  }
  log.Fatal(err)

 fmt.Println("文件名：", info.Name())
 fmt.Println("大小：", info.Size())
 fmt.Println("权限：", info.Mode())
 fmt.Println("修改时间：", info.ModTime())
 fmt.Println("是目录：", info.IsDir())
}
```

## path/filepath包

[path/filepath](https://pkg.go.dev/path/filepath) 包提供了跨平台的路径操作函数，能正确处理不同操作系统的路径分隔符。与之对应的是 `path` 包，但 `path` 包仅用于以 `/` 分隔的路径（如 URL），文件系统路径应始终使用 `filepath`。

### 路径拼接与分割

| 函数 | 说明 | 文档 |
| -- | -- | -- |
| `filepath.Join(elem ...string) string` | 用操作系统的路径分隔符拼接路径，自动处理多余的分隔符和 `.`、`..` | <https://pkg.go.dev/path/filepath#Join> |
| `filepath.Split(path string) (dir, file string)` | 将路径分割为目录部分和文件名部分 | <https://pkg.go.dev/path/filepath#Split> |
| `filepath.SplitList(path string) []string` | 按 `os.PathListSeparator`（Linux 下为 `:`，Windows 下为 `;`）分割路径列表（如 PATH 环境变量） | <https://pkg.go.dev/path/filepath#SplitList> |

```go
func main() {
 // 拼接路径 —— 推荐始终使用 Join，而非手动拼接
 path := filepath.Join("home", "user", "docs", "file.txt")
 fmt.Println(path) // Linux: home/user/docs/file.txt
                    // Windows: home\user\docs\file.txt

 // Join 自动处理多余的 /
 fmt.Println(filepath.Join("a//b", "c")) // a/b/c

 // 分割路径
 dir, file := filepath.Split("/home/user/file.txt")
 fmt.Println(dir)  // /home/user/
 fmt.Println(file) // file.txt
}
```

## io 包

### io.Reader、io.Writer 接口

[io.Reader](https://pkg.go.dev/io#Reader) 接口代表一个可以从中读取字节流的数据源（输入流），比如文件、网络连接、内存缓冲、标准输入等。接口定义：

```go
type Reader interface {
 Read(p []byte) (n int, err error) // 将数据读到字节切片 p 中，返回读取的字节数 n 和错误 err。Read 返回 io.EOF 错误表示数据流结束了，没有更多数据可以读取了
}
```

接口契约：Read 不保证填满切片，调用者必须检查返回的 n，并处理 `io.EOF` 错误作为数据流正常结束的信号。

- Read 最多读取 `len(p)` 个字节到 p 中，不会在函数体中因为 append 导致扩容
- 返回实际读取的字节数 n（0 <= n <= `len(p)`）
- 当 n > 0 时，会尽可能读取数据，即使遇到错误（如 EOF）也会返回已读取的部分
- 当 n = 0 时，err 可能为：
  - `nil`：没有数据可读，但不表示流结束（调用者应再次尝试）
  - `io.EOF`：流正常结束，没有更多数据
  - 其它非 `nil` 错误：发生了真正的错误
- 除非已到达流末尾，否则 Read 调用应该阻塞直到至少读到一个字节
- 调用者必须处理 n 可能小于 `len(p)` 的情况，即使 err 为 `nil`，也不代表已读完所有数据

常见实现：

| 类型 | 说明 |
| -- | -- |
| `os.File` | 文件、标准输入 `os.Stdin` |
| `bytes.Reader` | 从内存中的 `[]byte` 读取 |
| `strings.Reader` | 从字符串读取（零拷贝） |
| `net.Conn` | TCP、UDP、Unix Socket 等网络连接 |
| `bufio.Reader` | 带缓冲的读，减少系统调用 |
| `crypto/rand.Reader` | 密码学安全随机数生成器 |
| `compress/gzip.Reader` | 解压 gzip 数据流 |
| `http.Request.Body` | HTTP 请求体 |

[io.Writer](https://pkg.go.dev/io#Writer) 接口代表一个可以往其中写入字节流的目标（输出流），比如文件、网络连接、内存缓冲、甚至是 HTTP 响应等。接口定义：

```go
type Writer interface {
    Write(p []byte) (n int, err error) // 将字节切片 p 写入底层流，返回实际写入的字节数 n 和错误 err
}
```

接口契约：返回实际写入的字节数，调用者必须处理部分写入的情况。

- Write 从 p 中读取数据写入底层数据流
- 返回实际写入的字节数 n（0 <= n <= `len(p)`）
- 如果 n < `len(p)`，则必定返回一个非 `nil` 的 error
- 调用者不应假设写入操作一定会消耗完整个 p，必须按返回的 n 来切片继续写入，除非 err != `nil`
- 写入过程中，绝不能修改切片 p 里的数据，哪怕改了又改回来（“暂时地”）也不行
- 绝对不能“保留”对传入切片 p 的引用，例如：
  - 把 p 赋值给一个包级变量或结构体字段
  - 把 p 通过通道发给另一个协程
  - 把 p 捕获进一个闭包中，并留到后台异步执行

常见实现：

| 类型 | 说明 |
| -- | -- |
| `os.File` | 文件、标准输入输出 `os.Stdout` |
| `bytes.Buffer` | 内存中可增长的字节缓冲区 |
| `strings.Builder` | 高效拼接字符串（零拷贝） |
| `net.Conn` | TCP、UDP、Unix Socket 等网络连接 |
| `bufio.Writer` | 带缓冲的写，减少系统调用 |
| `crypto/cipher.Stream` | 加密流写入 |
| `http.ResponseWriter` | HTTP 响应的写入端 |

### 分块读取的循环模式

```go
func readAll(r io.Reader) ([]byte, error) {
 buf := make([]byte, 1024) // 创建一个缓冲区
 var result []byte
 for {
  n, err := r.Read(buf) // 读取数据到缓冲区
  if n > 0 {
   result = append(result, buf[:n]...) // 将读取的数据 append 到 result 切片中
  }
  if err == io.EOF {
   break // Read 返回 io.EOF 错误表示没有数据了，正常退出循环
  }
  if err != nil {
   return nil, err // 返回错误
  }
 }
 return result, nil
}
```

Go 标准库的 [io.ReadAll](https://pkg.go.dev/io#ReadAll) 内部用了 bytes.Buffer，且经过了充分优化，是这个函数最直接的替代。

### 自定义 io.Reader 示例

实现一个 io.Reader 类型，它产生一个 ASCII 字符 'A' 的无限输入流。

```go

type MyReader struct{}

func (r MyReader) Read(p []byte) (n int, err error) {
 if len(p) == 0 {
  return 0, nil
 }

 p[0] = 'A'    // 读取数据到切片 p 中
 return 1, nil // 返回读取的字节数和错误
}

func main() {
 var r io.Reader = MyReader{}
 buf := make([]byte, 8)
 for {
  n, err := r.Read(buf)
  fmt.Printf("%d, %v\n", n, err)

  if n > 0 {
   fmt.Println(string(buf[:n]))
  }
  if err == io.EOF {
   break
  }
  if err != nil {
   fmt.Println(err)
   return
  }
 }
}
```

---

一种常见的模式是一个 io.Reader 包装另一个 io.Reader，通过某种方式修改其数据流。例如，gzip.NewReader 函数接受一个 io.Reader（压缩数据流）并返回一个同样实现了 io.Reader 的 *gzip.Reader（解压后的数据流）。

编写一个实现了 io.Reader 接口并从另一个 io.Reader 中读取数据的 rot13Reader，通过应用 rot13 代换密码对数据流进行修改。

```go
// rot13Reader 包装了另一个 io.Reader
type rot13Reader struct {
 r io.Reader
}

func (r *rot13Reader) Read(p []byte) (n int, err error) {
 n, err = r.r.Read(p)
 if err != nil {
  return n, err
 }

 for i := 0; i < n; i++ {
  if p[i] >= 'A' && p[i] <= 'Z' {
   p[i] = (p[i]-'A'+13)%26 + 'A'
  } else if p[i] >= 'a' && p[i] <= 'z' {
   p[i] = (p[i]-'a'+13)%26 + 'a'
  }
 }
 return n, nil
}

func main() {
 sr := strings.NewReader("Lbh penpxrq gur pbqr!") // 返回一个 io.Reader，从指定字符串中读取字节流
 var r io.Reader = &rot13Reader{sr}
 written, err := io.Copy(os.Stdout, r) // You cracked the code! io.Copy 从第二个参数 src 读取数据到第一个参数 dst，直到 src 的结尾或遇到错误，返回复制的字节数和复制过程中遇到的第一个错误（如果有）
 fmt.Printf("%d, %v\n", written, err)             // 21 nil
 // 此时 sr 已经读完，再次读取会返回 EOF

 var buf bytes.Buffer
 // 第二次读取：Reader 已空，无数据可读
 written, err = io.Copy(&buf, r) // io.Copy 在遇到 src 的结尾时返回 nil，而不是 io.EOF 错误
 fmt.Printf("%d, %v\n", written, err)       // 0 nil
}
```

### io 包中的常用函数

`io` 包提供了一些极其好用的函数来处理 `io.Reader`，可以大大简化代码。

> [!IMPORTANT]
> io/ioutil 包自 Go 1.16 起已弃用，请使用以下替代：
>
> - `ioutil.ReadAll` -> `io.ReadAll`
> - `ioutil.ReadFile` -> `os.ReadFile`
> - `ioutil.WriteFile` -> `os.WriteFile`
> - `ioutil.TempDir` -> `os.MkdirTemp`
> - `ioutil.TempFile` -> `os.CreateTemp`
> - `ioutil.ReadDir` -> `os.ReadDir`

| 函数 | 主要用途 | 适用场景 | 文档 |
| -- | -- | -- | -- |
| `io.ReadAll(r io.Reader) ([]byte, error)` | 一次性读取 `r` 中的所有数据，直到数据流的结尾或出现错误。遇到数据流的结尾时，ReadAll 返回 `nil` 而不是 `io.EOF` | 当确定数据量不大，可以全部读入内存时，例如，读取一个配置文件或一个完整的 HTTP 响应体 | <https://pkg.go.dev/io#ReadAll> |
| `io.Copy(dst io.Writer, src io.Reader) (written int64, err error)` | 将数据从 `src` 复制（读取）到 `dst`，直到遇到 src 的结尾或出现错误，返回复制的字节数和复制过程中遇到的第一个错误（如果有）。遇到 src 的结尾时，Copy 返回 `nil` 而不是 `io.EOF` | 在数据流之间传输大量数据，如文件拷贝、将网络响应直接写入文件。它避免了将全部数据加载到内存的开销 | <https://pkg.go.dev/io#Copy> |
| `io.CopyN(dst io.Writer, src io.Reader, n int64) (written int64, err error)` | 从 `src` 精确复制（读取） `n` 个字节到 `dst`，直到出错为止 | 需要精确控制复制数据量时 | <https://pkg.go.dev/io#CopyN> |
| `io.LimitReader(r io.Reader, n int64) io.Reader` | 返回一个 `io.Reader`，它从 `r` 读取但最多只返回 `n` 字节数据 | 需要限制读取量，例如只读取数据流的头部 | <https://pkg.go.dev/io#LimitReader> |
| `io.MultiReader(readers ...io.Reader) io.Reader` | 将多个 `io.Reader` 按从左到右的顺序串联成一个 `io.Reader`，当所有输入都返回 EOF 后，Read 也将返回 EOF。如果任何读取器返回非 `nil` 且非 EOF 的错误，Read 将返回该错误 | 需要将多个数据源（如几个文件、字符串）逻辑上合并为一个流进行读取 | <https://pkg.go.dev/io#MultiReader> |

```go
func main() {
 r := strings.NewReader("hello, world")
 data, err := io.ReadAll(r)

 fmt.Printf("%s, %v", data, err) // hello, world, nil
 if err != nil {
  fmt.Println(err)
  return
 }

 n, err := io.Copy(os.Stdout, r) // 上面 ReadAll 已经读取了 r 中的所有数据，这里再复制一次会立即遇到 io.EOF
 fmt.Printf("%d, %v", n, err)    //  0, nil
 if err != nil {
  fmt.Println(err)
  return
 }

 r1 := strings.NewReader("first reader ")
 r2 := strings.NewReader("second reader ")
 r3 := strings.NewReader("third reader\n")

 if _, err := io.Copy(os.Stdout, io.MultiReader(r1, r2, r3)); err != nil { // MultiReader 按从左到右的顺序读取，输出：first reader second reader third reader
  fmt.Println(err)
  return
 }
}
```

## bufio 包

[bufio](https://pkg.go.dev/bufio) 包实现了带缓冲的 I/O，通过减少系统调用次数来提升读写性能。它包装了 `io.Reader` 和 `io.Writer`，提供了缓冲读写、按行读取、按单词读取等便捷功能。

### bufio.Reader

[bufio.Reader](https://pkg.go.dev/bufio#Reader) 包装一个 `io.Reader`，提供内部缓冲和更丰富的数据读取方法。

创建 Reader：

```go
// 创建一个默认缓冲区大小（4096 字节）的 Reader
br := bufio.NewReader(r io.Reader)

// 创建一个指定缓冲区大小的 Reader
br := bufio.NewReaderSize(r io.Reader, size int)
```

| 方法 | 说明 | 文档 |
| -- | -- | -- |
| `Read(p []byte) (n int, err error)` | 读取数据到 p，优先从内部缓冲区返回，不够时从底层 Reader 补充 | <https://pkg.go.dev/bufio#Reader.Read> |
| `ReadByte() (byte, error)` | 读取单个字节 | <https://pkg.go.dev/bufio#Reader.ReadByte> |
| `ReadRune() (r rune, size int, err error)` | 读取单个 UTF-8 字符 | <https://pkg.go.dev/bufio#Reader.ReadRune> |
| `ReadBytes(delim byte) ([]byte, error)` | 读取直到遇到分隔符 delim（包含 delim），返回读到的字节切片 | <https://pkg.go.dev/bufio#Reader.ReadBytes> |
| `ReadString(delim byte) (string, error)` | 同 ReadBytes，但返回字符串 | <https://pkg.go.dev/bufio#Reader.ReadString> |
| `ReadLine() (line []byte, isPrefix bool, err error)` | 读取一行（低阶 API），推荐用 ReadBytes('\n') 或 Scanner 替代 | <https://pkg.go.dev/bufio#Reader.ReadLine> |
| `Peek(n int) ([]byte, error)` | 预览下 n 个字节但不移动读取指针 | <https://pkg.go.dev/bufio#Reader.Peek> |
| `UnreadByte() error` | 回退一个字节（最多回退最近读取的一个字节） | <https://pkg.go.dev/bufio#Reader.UnreadByte> |
| `UnreadRune() error` | 回退一个 UTF-8 字符 | <https://pkg.go.dev/bufio#Reader.UnreadRune> |
| `Buffered() int` | 返回当前缓冲区中可读取的字节数 | <https://pkg.go.dev/bufio#Reader.Buffered> |
| `Reset(r io.Reader)` | 丢弃缓冲区数据，切换到新的底层 Reader | <https://pkg.go.dev/bufio#Reader.Reset> |

```go
func main() {
 r := strings.NewReader("hello, world\nthis is line 2\nline 3")
 br := bufio.NewReader(r)

 // 按行读取
 for {
  line, err := br.ReadString('\n')
  if err == io.EOF {
   // 最后一行可能没有 \n
   if len(line) > 0 {
    fmt.Print(line)
   }
   break
  }
  if err != nil {
   log.Fatal(err)
  }
  fmt.Print(line) // line 已包含 \n
 }

 // Peek 预览（不消耗数据）
 br.Reset(strings.NewReader("ABCDEFG"))
 preview, _ := br.Peek(3)
 fmt.Println(string(preview)) // ABC
 // 预览之后数据仍在缓冲区
 b, _ := br.ReadByte()
 fmt.Println(string(b)) // A
}
```

### bufio.Writer

[bufio.Writer](https://pkg.go.dev/bufio#Writer) 包装一个 `io.Writer`，写入的数据会先累积在内部缓冲区中，当缓冲区满或显式调用 Flush 时才一次性写入底层 Writer，从而减少系统调用。

创建 Writer：

```go
// 创建一个默认缓冲区大小的 Writer
bw := bufio.NewWriter(w io.Writer)

// 创建一个指定缓冲区大小的 Writer
bw := bufio.NewWriterSize(w io.Writer, size int)
```

| 方法 | 说明 | 文档 |
| -- | -- | -- |
| `Write(p []byte) (nn int, err error)` | 写入字节切片到缓冲区 | <https://pkg.go.dev/bufio#Writer.Write> |
| `WriteByte(c byte) error` | 写入单个字节 | <https://pkg.go.dev/bufio#Writer.WriteByte> |
| `WriteRune(r rune) (size int, err error)` | 写入单个 UTF-8 字符 | <https://pkg.go.dev/bufio#Writer.WriteRune> |
| `WriteString(s string) (int, error)` | 写入字符串 | <https://pkg.go.dev/bufio#Writer.WriteString> |
| `Flush() error` | 将缓冲区中的数据刷新到底层 Writer。**使用 bufio.Writer 必须记得 Flush，否则数据可能丢失！** | <https://pkg.go.dev/bufio#Writer.Flush> |
| `Available() int` | 返回缓冲区剩余空间 | <https://pkg.go.dev/bufio#Writer.Available> |
| `Buffered() int` | 返回缓冲区中已写入但尚未 Flush 的字节数 | <https://pkg.go.dev/bufio#Writer.Buffered> |
| `Reset(w io.Writer)` | 丢弃缓冲区数据，切换到新的底层 Writer | <https://pkg.go.dev/bufio#Writer.Reset> |

```go
func main() {
 f, err := os.Create("output.txt")
 if err != nil {
  log.Fatal(err)
 }
 defer f.Close()

 bw := bufio.NewWriter(f)

 // 多次小写入，先进入缓冲区
 bw.WriteString("第一行\n")
 bw.WriteString("第二行\n")
 bw.WriteByte('A')

 fmt.Println("缓冲区中待刷新：", bw.Buffered()) // 缓冲区中待刷新：20

 // 必须 Flush！否则数据不会真正写入文件
 if err := bw.Flush(); err != nil {
  log.Fatal(err)
 }
}
```

### bufio.Scanner

[bufio.Scanner](https://pkg.go.dev/bufio#Scanner) 提供了一种便捷的分段读取方式，按行、单词或自定义分隔符逐段读取数据，是处理文本文件最常见的工具。

```go
// 创建 Scanner
scanner := bufio.NewScanner(r io.Reader)
```

| 方法 | 说明 | 文档 |
| -- | -- | -- |
| `Scan() bool` | 前进到下一段，有数据返回 true，到达末尾返回 false | <https://pkg.go.dev/bufio#Scanner.Scan> |
| `Text() string` | 返回当前段（不含分隔符）的字符串 | <https://pkg.go.dev/bufio#Scanner.Text> |
| `Bytes() []byte` | 返回当前段的字节切片 | <https://pkg.go.dev/bufio#Scanner.Bytes> |
| `Err() error` | 返回扫描过程中遇到的第一个非 EOF 错误 | <https://pkg.go.dev/bufio#Scanner.Err> |
| `Split(split SplitFunc)` | 设置分段函数，决定如何将数据切分成 tokens | <https://pkg.go.dev/bufio#Scanner.Split> |
| `Buffer(buf []byte, max int)` | 设置自定义缓冲区，当单行超过默认大小（64KB）时使用 | <https://pkg.go.dev/bufio#Scanner.Buffer> |

预定义的分段函数（SplitFunc）：

| 函数 | 说明 |
| -- | -- |
| `bufio.ScanLines` | 按行分割（默认），去掉 `\n` 或 `\r\n` |
| `bufio.ScanWords` | 按空格分割的单词 |
| `bufio.ScanRunes` | 按 UTF-8 字符分割 |
| `bufio.ScanBytes` | 按单个字节分割 |

```go
func main() {
 input := "hello world\nfoo bar baz\nlast line"

 // 按行扫描（默认）
 scanner := bufio.NewScanner(strings.NewReader(input))
 for scanner.Scan() {
  fmt.Println("行：", scanner.Text())
 }
 if err := scanner.Err(); err != nil {
  log.Fatal(err)
 }

 // 按单词扫描
 scanner = bufio.NewScanner(strings.NewReader("one two three four"))
 scanner.Split(bufio.ScanWords)
 for scanner.Scan() {
  fmt.Println("单词：", scanner.Text())
 }

 // 自定义分隔符：按逗号分割
 scanner = bufio.NewScanner(strings.NewReader("a,b,c,d"))
 scanner.Split(func(data []byte, atEOF bool) (advance int, token []byte, err error) {
  for i, b := range data {
   if b == ',' {
    return i + 1, data[:i], nil // 返回前进量和 token（不含逗号）
   }
  }
  // 到达数据末尾
  if atEOF && len(data) > 0 {
   return len(data), data, nil
  }
  // 请求更多数据
  return 0, nil, nil
 })
 for scanner.Scan() {
  fmt.Println("分段：", scanner.Text())
 }
}
```

**Scanner 大行问题**：Scanner 默认最大 token 大小为 64KB（`MaxScanTokenSize`），遇到超过此大小的行会导致 `bufio.ErrTooLong` 错误。处理超大行时需要手动设置缓冲区：

```go
scanner := bufio.NewScanner(file)
// 将最大 token 扩大到 1MB
buf := make([]byte, 0, 64*1024)
scanner.Buffer(buf, 1024*1024)
```

### 读写对比与选择

| 需求 | 推荐方案 |
| -- | -- |
| 一次性读写整个文件 | `os.ReadFile` / `os.WriteFile` |
| 流式拷贝大文件 | `io.Copy` |
| 逐行读取文本 | `bufio.Scanner`（首选）或 `bufio.Reader.ReadString('\n')` |
| 频发小写入 | `bufio.Writer` + `Flush()` |
| 按分隔符读取 | `bufio.Reader.ReadBytes` / `ReadString` |
| 自定义分段 | `bufio.Scanner` + 自定义 SplitFunc |
| 极致的读取控制 | 直接使用 `os.File.Read` + 自管理缓冲区 |

## image 包及 image.Image 接口

todo 对照一下官方文档

image 标准库提供了一套基础的二维图像处理能力，它的核心设计理念是围绕 image.Image 接口构建统一的图像模型，让开发者能用一致的方式处理不同格式的图片。

image.Image 接口是整个图像处理的基础，所有图像类型（无论是 JPEG、PNG 还是 GIF）都实现了这个接口。它定义了三个核心方法：

```go
type Image interface {
 // ColorModel 返回 Image 的颜色模型
 ColorModel() color.Model
 // Bounds 返回 At 可以返回非零颜色的范围，该范围不一定包含点 (0, 0)
 Bounds() Rectangle // 实际上是 image.Rectangle 
 // At 返回 (x, y) 处像素的颜色
 // At(Bounds().Min.X, Bounds().Min.Y) 返回网格左上角的像素
 // At(Bounds().Max.X-1, Bounds().Max.Y-1) 返回右下角的像素
 At(x, y int) color.Color
}
```

image 包提供了多种实现了 Image 接口的具体类型，以适应不同的颜色模型和存储需求，最常用的是 image.RGBA。

### 案例

自定义 Image 类型，实现必要方法并保存图片：

```go
type MyImage struct {
 Width, Height int
}

func (img MyImage) ColorModel() color.Model {
 return color.RGBAModel // color.Model 也是接口类型，这里返回预定义的实现 color.RGBAModel
}

func (img MyImage) Bounds() image.Rectangle {
 return image.Rect(0, 0, img.Width, img.Height)
}

func (img MyImage) At(x, y int) color.Color {
 v := uint8(x ^ y) // 这里使用异或操作，也可以尝试 x*y, (x+y)/2 等
 return color.RGBA{v, v, 255, 255} // color.Color 也是接口类型，这里返回预定义的实现 color.RGBA 
}

func main() {
 img := MyImage{256, 256}
 saveImage(img, "img.png")
 // pic.ShowImage(m) // pic.ShowImage 输出的是 Base64 编码的 PNG 图片数据
}

func saveImage(img image.Image, filename string) {
 f, err := os.Create(filename)
 if err != nil {
  log.Fatalf("failed to create file %s: %v", filename, err)
 }
 defer f.Close()

 if err := png.Encode(f, img); err != nil {
  log.Fatalf("failed to encode image to file %s: %v", filename, err)
 }

 log.Printf("image saved to %s", filename)
}
```

### 常用操作

创建图像：使用 NewRGBA、NewGray 等函数创建新的空白图像

```go
// 创建一个宽 100，高 100 的 RGBA 图像
img := image.NewRGBA(image.Rect(0, 0, 100, 100))
```

读取和写入像素：通过 Set 和 At 方法操作像素

```go
// 设置左上角第一个像素为红色
img.Set(0, 0, color.RGBA{255, 0, 0, 255})

// 获取坐标 (10, 20) 的颜色
c := img.At(10, 20)
```

遍历像素：通过 Bounds 方法获取图像尺寸，然后循环处理每个像素

```go
bounds := img.Bounds()
for y := bounds.Min.Y; y < bounds.Max.Y; y++ {
    for x := bounds.Min.X; x < bounds.Max.X; x++ {
        // 处理每个像素，例如将其设为绿色
        img.Set(x, y, color.RGBA{0, 255, 0, 255})
    }
}
```

读取图片文件：要解码特定格式的图片，需要匿名导入对应的格式包，以注册其解码器，然后使用 [image.Decode](https://pkg.go.dev/image#Decode) 从文件流中读取并解析图像，返回解码后的图像、格式、错误。处理来自外部的图片时，建议先用 image.DecodeConfig 读取图片头信息（如尺寸），防止因图片过大导致内存耗尽。

```go
import (
 "image"
 _ "image/jpeg" // 注册 JPEG 解码器
 _ "image/png"  // 注册 PNG 解码器
 "os"
)

func main() {
 file, _ := os.Open("example.jpg")
 defer file.Close()
 img, format, err := image.Decode(file) // 自动识别并解码
 // ...
}
```

保存图片文件：使用 png.Encode、jpeg.Encode 等函数将 Image 编码并保存为文件

```go
func main() {
 img := image.NewRGBA(image.Rect(0, 0, 100, 100))
 img.Set(50, 50, color.White)

 file, _ := os.Create("output.png")
 defer file.Close()
 err := png.Encode(file, img) // 编码为 PNG 格式
 // ...
}
```

## embed 包

[embed](https://pkg.go.dev/embed) 是 Go 1.16 正式引入的标准库，将静态文件（文本、图片、配置、模板等）编译打包进二进制程序（会增大程序体积），打包后运行程序不再依赖外部文件，单文件分发部署。

- 仅支持 `//go:embed` 指令，指令和变量声明不能有空行隔开
- 变量类型仅三种：`string`、 `[]byte`、`embed.FS`，`embed.FS` 仅实现 `io/fs` 接口（ReadFile、ReadDir、Open），不支持写入操作
- 指令写在包级别变量上方，不能写在函数体中
- 匹配路径相对于当前源码文件所在目录，不是相对于项目根目录，支持通配符，不能嵌入 `..` 越级路径
- 忽略 . 开头隐藏文件、符号链接、空目录

| 指令 | 说明 |
| -- | -- |
| `//go:embed file.txt` | 嵌入单个文件 |
| `//go:embed dir/*` | 嵌入目录下所有文件（不包括子目录） |
| `//go:embed dir/...` | 嵌入目录下所有文件（递归包含子目录） |
| `//go:embed a.txt b.txt` | 一行嵌入多个文件 |

导入规则

- string/[]byte 单文件：必须 import _ "embed"（匿名导入，否则编译器忽略 embed 指令）
- embed.FS 多文件：直接 import "embed" 即可，无需匿名

单个文件 -> string（文本文件首选），适合配置文件、html 模板、sql 脚本等文本内容：

```go
import (
 _ "embed" // 匿名导入，启用 embed 功能
 "fmt"
)

//go:embed hello.txt
var helloStr string

func main() {
 fmt.Println(helloStr) // helloStr 为 hello.txt 文件的内容
}
```

单个文件 -> `[]byte`（二进制文件），适合图片、exe、压缩包等二进制文件：

```go
import (
 _ "embed"
 "os"
)

//go:embed logo.png
var logoBytes []byte

func main() {
 // 把内置图片写入本地
 _ = os.WriteFile("out.png", logoBytes, 0644)
}
```

多个文件/目录 -> embed.FS（最常用），适合静态网站、模板目录等多文件场景。embed.FS 常用方法：

```go
// 读取文件 https://pkg.go.dev/embed#FS.ReadFile
func (f FS) ReadFile(name string) ([]byte, error)
// 读取目录
func (f FS) ReadDir(name string) ([]fs.DirEntry, error)
// 打开文件/目录
func (f FS) Open(name string) (fs.File, error)
// 子目录 FS，剥离路径前缀 https://pkg.go.dev/io/fs#Sub
func Sub(fsys FS, dir string) (FS, error)
// 遍历目录 https://pkg.go.dev/io/fs#WalkDir
fs.WalkDir(fsys, root, walkFn) error
// 返回所有匹配通配符的文件路径列表 https://pkg.go.dev/io/fs#Glob
fs.Glob(fsys, pattern) ([]string, error)
```

```go
// 多个文件必须用 embed.FS 类型！

//go:embed hello.txt test.txt
var str embed.FS

func main() {
 content, _ := str.ReadFile("hello.txt")
 fmt.Println(string(content)) // 为 hello.txt 文件的内容

 content, _ = str.ReadFile("test.txt")
 fmt.Println(string(content)) // 为 test.txt 文件的内容
}
```

```go
// HTTP 内置静态网页服务

//go:embed web/*
var webFS embed.FS

func main() {
 // SubFS 剥离前缀 web/，路由更干净
 sub, _ := fs.Sub(webFS, "web")
 http.Handle("/", http.FileServer(http.FS(sub)))
 http.ListenAndServe(":8080", nil)
}
```

embed.FS 实现 io/fs.FS 接口，可以搭配：

- html/template 模板加载
- net/http 静态文件服务
- os.ReadFile、fs.WalkDir 遍历文件

```go
// 嵌入整个 static 文件夹
import (
 "embed"
 "fmt"
 "io/fs"
)

//go:embed static/*
var staticFS embed.FS

func main() {
 // 读取内置文件
 content, _ := staticFS.ReadFile("static/index.html")
 fmt.Println(string(content))

 // 遍历所有嵌入文件
 fs.WalkDir(staticFS, ".", func(path string, d fs.DirEntry, err error) error {
  fmt.Println(path)
  return nil
 })
}
```

# 第七部分 方法与接口

## 概览

本部分深入讲解 Go 语言的方法与接口机制，涵盖方法的接收者类型、方法值与方法表达式、接口类型、类型断言、类型选择，以及 `fmt.Stringer` 接口与文件操作。理解接口是掌握 Go 鸭子类型和组合编程的核心。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 方法](01方法.md) | 方法接收者（值与指针）、接收者类型限制与同包原则、方法值与方法表达式、匿名字段的方法提升 | 区分值接收者与指针接收者的使用场景 |
| [02 接口](02接口.md) | 接口隐式实现、空接口、接口的内存布局（`eface`/`iface`）、nil 接口与 nil 指针、结构体嵌套 | 理解接口的工作原理，正确使用接口编程 |
| [03 类型断言](03类型断言.md) | 接口值到具体类型的断言、ok 语法、避免 panic | 安全地从接口中提取具体类型值 |
| [04 类型选择](04类型选择.md) | `type switch` 语法、接口类型匹配与具体类型匹配 | 利用类型选择实现分发的多类型处理 |
| [05 fmt.Stringer 接口](05fmt.Stringer接口.md) | `fmt.Stringer` 接口的定义与实现 | 为自定义类型实现 `String()` 方法以自定义输出格式 |
| [06 文件操作](06文件操作.md) | `os` 包、`path/filepath` 包、`io` 包（`io.Reader`/`io.Writer`）、`bufio` 包、标准输入输出错误、`image` 包与 `embed` 包 | 熟练使用标准库进行文件 I/O 操作 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第六部分（函数机制），方法是带接收者参数的函数，两者紧密相关。
- 建议按章节顺序学习：方法、接口、类型断言、类型选择、fmt.Stringer 接口、文件操作。
- 接口部分是理解 Go 类型系统的核心，建议重点理解接口的内部结构和方法集概念。

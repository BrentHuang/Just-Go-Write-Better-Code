## 方法

方法是一种具有接收者（Receiver）参数的函数，接收者参数位于 func 关键字和方法名之间，它指定了该方法所属的特定类型，只能通过接收者类型的值变量或指针变量调用方法。

Go 不支持方法重载（方法名相同，参数个数或参数类型不完全相同），特定类型下的方法名必须唯一，不允许重名。

方法名首字母大小写决定其可见性（是否导出）。

接收者参数的名字一般为其类型的第一个字母（小写）。

```go
type Vertex struct {
 X, Y float64
}

// (v Vertex) 是接收者参数，位于 func 关键字和方法名之间。方法只能有一个接收者参数，并且要用小括号括起来
func (v Vertex) Abs() float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}

func main() {
 v := Vertex{3, 4}
 fmt.Println(v.Abs()) // 5
}
```

方法只不过是一个带有接收者参数的函数而已。如下是以常规函数形式编写的 Abs 函数，其功能与上述方法完全一样。

```go
func Abs(v Vertex) float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}
```

当将一个结构体类型匿名嵌入到另一个结构体类型时，外部结构体会自动“继承”内部结构体的所有方法（方法提升）。如果外部结构体定义了与匿名内嵌结构体同名的方法，则外部结构体的方法会“覆盖”内部结构体的方法。详见“结构体”章节。

### 接收者类型要求

方法接收者类型必须是命名类型或指向命名类型的指针，Go 不允许为接口（如 `func (i error) MyMethod()`）或底层是指针（如 `type MyPtr *int`）/接口（如 `type MyError error`）的自定义类型声明方法，原因是方法必须绑定到具体类型，而接口和指针都是抽象或间接类型。

```go
type Callable interface {
 Invoke()
}

// 1. 接收者不能是接口类型，编译报错
func (c Callable) Invoke() {
}

// 
type Vertex struct {
 X, Y float64
}

type FooPointer *Vertex       // 2. 自定义类型，底层类型是指针
type FooInterface interface{} // 3. 自定义类型，底层类型是接口 interface{}

// 语义不明确：指针类型本身不是完整的类型定义，它只是对现有类型的引用
func (f FooPointer) F() {
}

// 接口是用于定义行为契约的，而不是实现行为
func (f FooInterface) F() {
}
```

```go
type Vertex struct {
 X, Y float64
}

type Ver = Vertex // 结构体类型的别名，与原结构体类型是完全等价的，可以定义方法

func (v Ver) Abs() float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}

func main() {
 v := Ver{3, 4}
 fmt.Println(v.Abs())
}
```

#### 同包原则

方法接收者的类型定义和方法声明必须在同一个包中，即声明方法时，其接收者类型只能定义在方法所在的包中，不能为定义在其它包的类型声明方法。

基于“同包原则”，

- 不能直接为基本类型声明方法（如 `func (f float64) Abs() float64`），因为基本类型定义在“宇宙块”，不是定义在声明方法的包中
- 不能为基本类型的别名（如 `type MyInt = int`）声明方法，因为别名类型和原类型在类型系统中是完全等价的

```go
// float64 是基本类型，不能直接为基本类型定义方法
// 编译报错：cannot define new methods on non-local type float64
func (f float64) Abs() float64 {
 if f < 0 {
  return -f
 }
 return f
}

// MyFloat 是 float64 的别名，不能为 MyFloat 定义方法
// 编译报错：cannot define new methods on non-local type MyFloat
type MyFloat = float64

func (f MyFloat) Abs() float64 {
 if f < 0 {
  return -f
 }
 return f
}

// 这样可以
type MyFloat float64 // 自定义类型 MyFloat，底层类型是 float64

// 一个带有 Abs 方法的数字类型 MyFloat
func (f MyFloat) Abs() float64 {
 if f < 0 {
  return float64(-f)
 }
 return float64(f)
}
```

### 值接收者与指针接收者

方法接收者参数可以是值类型或指针类型，但不能是指针的指针（`**`），这不是技术限制，而是设计选择：Go 希望方法接收者语义简单、可预测，避免多层间接带来的复杂性。

- 值接收者：方法接收者参数是值类型，如 `(v Vertex)`。调用方法时，接收者形参是实参（值变量）的一个副本，在方法体中对接收者形参的修改不影响原始的值变量。适用于不修改接收者状态或特定类型为较小结构体的场景
- 指针接收者：方法接收者参数是指针类型，如 `(v *Vertex)`。调用方法时，接收者形参是实参（指针变量）的一个副本，形参指针与实参指针指向的是同一个值变量，在方法体中对接收者形参的修改会影响原始的值变量。适用于需要修改接收者状态或特定类型为较大结构体（拷贝开销）的场景

Go 简化了方法调用，不管方法接收者参数是值类型还是指针类型，接收者类型的值变量（值实参）或指针变量（指针实参，指向值变量）都可以直接调用方法，无需手动取地址或解引用。

- 值变量 v 调用指针接收者方法 `v.Scale()`，Go 自动转为 `(&v).Scale()`，注意：只有可寻址的值变量才能自动取地址，如果值变量不可寻址（例如字面量、函数的返回值、map 索引取值），则无法直接调用指针接收者方法，编译报错
- 指针变量 p 调用值接收者方法 `p.Abs()`，Go 自动转为 `(*p).Abs()`

```go
type Vertex struct {
 X, Y float64
}

func (v Vertex) Abs() float64 {
 result := math.Sqrt(v.X*v.X + v.Y*v.Y)
 v.X = 0 // 仅示例
 return result
}

func (v *Vertex) Scale(f float64) {
 v.X *= f
 v.Y *= f
}

func main() {
 vr := Vertex{3, 4}
 fmt.Println(vr) // {3 4}

 pr := &Vertex{1, 2}
 fmt.Println(*pr) // {1 2}

 fmt.Println(vr.Abs()) // Abs 的接收者参数是值类型，可以通过值变量 v 调用，形参是实参的副本，在方法体中对接收者形参 v 的修改不影响实际的值变量
 fmt.Println(vr)       // {3, 4}，vr 保持不变

 fmt.Println(pr.Abs()) // 也可以通过指针变量 p 调用，会被编译器自动解引用为 (*p).Abs()
 fmt.Println(*pr)      // {1 2}，*pr 保持不变

 pr.Scale(10)     // Scale 的接收者参数是指针类型，可以通过指针变量 p 调用，形参指针 v 与实参指针 p 指向的是同一个值变量，在方法体中对形参 v 的修改会影响实际的值变量
 fmt.Println(*pr) // {10 20}，*pr 被改变了

 vr.Scale(10)    // 也可以通过值变量 v 调用，会被编译器自动取地址为 (&v).Scale(10)，在方法体中对形参 v 的修改会影响实际的值变量 v
 fmt.Println(vr) // {30 40}，vr 被改变了
}
```

这与函数调用有明显区别：函数调用时指针参数必须传指针变量，值参数必须传值变量。

```go
func f1(p *int) {
 fmt.Println(*p)
}

func f2(n int) {
 fmt.Println(n)
}

func main() {
 a := 1
 f1(a) // 编译报错，f1 接收指针参数，不能传入值变量
 f1(&a)

 f2(&a) // 编译报错，f2 接收值参数，不能传入指针变量
 f2(a)
}
```

建议特定类型下的方法保持一致的接收者类型，避免混用。如果有一个方法需要使用指针接收者，那么该类型的所有方法都统一使用指针接收者。

### 方法值、方法表达式

方法值和方法表达式是两种不同的方法调用方式。

#### 方法值（Method Values）

方法值是将方法绑定到特定接收者的闭包，接收者在创建方法值的那一刻就固定下来了。当方法值被调用时，会使用创建方法值时绑定的接收者。

方法值的创建语法：`fn := 接收者.方法名`，方法值是无接收者参数的普通函数，接收者已经被“固化”进 fn 里。

- 当方法接收者参数是值类型时，方法值绑定的是接收者（值变量）的一个副本，修改原始接收者（外部变量）不影响方法值中固化的副本
- 当方法接收者参数是指针类型时，方法值绑定的是接收者（指针变量）的一个副本，这个指针副本指向的就是原始接收者（外部变量）

以上两种情况，与实际接收者是值变量还是指针变量无关。

| 方法接收者类型 | 实际接收者 | 方法值绑定行为 |
| -- | -- | -- |
| 值类型 | 值变量`rect` | 拷贝`rect`的值 |
| 值类型 | 指针变量`p` | 解引用后拷贝值（`*p`） |
| 指针类型 | 值变量`rect` | Go 自动取`&rect`，持有指针 |
| 指针类型 | 指针变量`p` | 拷贝指针`p`，指向同一对象 |

```go
type Rectangle struct {
 width, height float64
}

// 值接收者方法
func (r Rectangle) Area() float64 {
 return r.width * r.height
}

// 指针接收者方法
func (r *Rectangle) Scale(factor float64) {
 r.width *= factor
 r.height *= factor
}

func main() {
 rect := Rectangle{width: 2, height: 4} // rect 为值变量
 // rect := &Rectangle{width: 2, height: 4} rect 为指针变量时结果一样，与接收者实参是值变量还是指针变量无关

 // 创建方法值
 areaFunc := rect.Area   // 值接收者方法，绑定的是接收者值变量的一个副本
 scaleFunc := rect.Scale // 指针接收者方法，等价于 (&rect).Scale，绑定的是指向接收者的指针

 fmt.Printf("%T, %T\n", areaFunc, scaleFunc) // func() float64, func(float64)，方法值是无接收者参数的普通函数

 // 修改原始接收者。方法值已经创建了，这里的修改不会影响 areaFunc（Area 是值接收者方法），但会影响 scaleFunc（Scale 是指针接收者方法）
 rect.width = 3

 fmt.Printf("rect 真实面积：%.2f\n", rect.Area()) // 12

 // 使用方法值调用
 fmt.Printf("使用方法值计算面积：%.2f\n", areaFunc()) // 8，areaFunc 绑定的接收者副本是 width=2, height=4，所以面积仍为 8

 scaleFunc(2.0)                                              // 在 width=3, height=4 的基础上缩放 2 倍，rect 变为 width=6, height=8
 fmt.Printf("实际矩形尺寸：%.2f x %.2f\n", rect.width, rect.height) // 6 x 8

 // 使用方法值调用
 fmt.Printf("缩放后的面积：%.2f\n", areaFunc()) // 8，areaFunc 绑定的接收者副本是 width=2, height=4，所以面积仍为 8

 fmt.Printf("rect 真实面积：%.2f\n", rect.Area()) // 48
}
```

使用场景：常用于回调 / 函数式风格，如 go, defer, 注册 handler 等。

```go
defer f.Close()
```

#### 方法表达式（Method Expressions）

方法表达式是把方法“提升”为普通函数，接收者变成了函数的第一个参数，调用时必须显式传接收者。

方法表达式的创建语法：

- 当方法接收者参数是值类型时：`特定类型.方法名`（第一个参数是值类型），`(*特定类型).方法名`（第一个参数是指针类型）
- 当方法接收者参数是指针类型时：`(*特定类型).方法名`（第一个参数是指针类型），不能定义第一个参数是值类型的方法表达式，编译报错

以上源于 Go 方法集的核心规则：`*T` 的方法集包含 `T` 的方法，但反过来不成立。

```go
type Circle struct {
 radius float64
}

func (c Circle) Area() float64 {
 return math.Pi * c.radius * c.radius
}

func (c *Circle) SetRadius(r float64) {
 c.radius = r
}

func main() {
 // 创建方法表达式
 areaExpr := Circle.Area              // 值接收者方法
 setRadiusExpr := (*Circle).SetRadius // 指针接收者方法，要加小括号

 fmt.Printf("%T, %T\n", areaExpr, setRadiusExpr) // func(main.Circle) float64, func(*main.Circle, float64)，接收者作为函数的第一个参数

 areaExpr2 := (*Circle).Area   // 方法 Area 是值类型接收者，允许定义指针类型的方法表达式
 fmt.Printf("%T\n", areaExpr2) // func(*main.Circle) float64，接收者作为函数的第一个参数

 // setRadiusExpr2 := Circle.SetRadius // 方法 SetRadius 是指针类型接收者，不允许定义值类型的方法表达式，编译报错
 // fmt.Printf("%T\n", setRadiusExpr2)

 c1 := Circle{radius: 5}
 c2 := Circle{radius: 10}

 // 使用方法表达式调用，需要显式传递接收者
 area1 := areaExpr(c1)
 area2 := areaExpr(c2)

 fmt.Printf("圆 1 面积：%.2f\n", area1) // 78.54
 fmt.Printf("圆 2 面积：%.2f\n", area2) // 314.16

 // 使用指针接收者的方法表达式
 setRadiusExpr(&c1, 8)                   // 修改了 c1 的半径
 newArea := areaExpr(c1)                 // c1 的面积也会改变
 fmt.Printf("修改后圆 1 面积：%.2f\n", newArea) // 201.06
}
```

使用场景：常用于反射 / 泛型 / 代码生成。

#### 总结

方法值和方法表达式本质上都是将方法转换为函数。在 Go 中，方法不是“一等公民”，方法不能直接作为函数参数传递。通过方法值和方法表达式可以将方法转换为函数，从而实现回调和高阶函数。

示例：

```go
// 在运行时动态选择方法（策略模式）
type Point struct{ X, Y float64 }

func (p Point) Add(q Point) Point { return Point{p.X + q.X, p.Y + q.Y} }
func (p Point) Sub(q Point) Point { return Point{p.X - q.X, p.Y - q.Y} }

type Path []Point

func (path Path) TranslateBy(offset Point, add bool) {
 var op func(p, q Point) Point
 if add {
  op = Point.Add // 方法表达式，接收者变成了函数的第一个参数
 } else {
  op = Point.Sub
 }

 for i := range path {
  // Call either path[i].Add(offset) or path[i].Sub(offset).
  path[i] = op(path[i], offset) // 如果不使用方法表达式，在这里就要根据 add 参数来选择调用 Add 或 Sub 方法
 }
}

func main() {
 path := Path{
  {1, 2},
  {3, 4},
  {5, 6},
 }
 path.TranslateBy(Point{10, 10}, true)
 println(path)
}
```

```go
// 函数式编程
type Rectangle struct {
 width  int
 height int
}

func (r Rectangle) Area() int {
 return r.width * r.height
}

// 通用的 map 函数
func mapSlice[T, U any](slice []T, f func(T) U) []U {
 result := make([]U, len(slice))
 for i, item := range slice {
  result[i] = f(item)
 }
 return result
}

func main() {
 rects := []Rectangle{{1, 2}, {3, 4}, {5, 6}}

 // 使用方法表达式作为映射函数
 areas := mapSlice(rects, Rectangle.Area) // 方法表达式
 fmt.Println(areas) // [2 12 30]
}
```

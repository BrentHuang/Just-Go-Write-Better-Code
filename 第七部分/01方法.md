# 方法

方法是一种具有接收者（Receiver）参数的函数，接收者参数位于 `func` 关键字和方法名之间，它指定了该方法所属的类型。

方法只能有一个接收者参数，必须用小括号括起来。根据 Go 项目惯例，一个类型的方法通常使用类型名首字母的小写形式作为接收者参数名。

方法名首字母大小写决定其可见性（是否导出）。

Go 不支持方法重载（方法名相同，但参数个数或参数类型不完全相同），一个类型下的方法名必须唯一，不允许重名。

```go
type Vertex struct {
 X, Y float64
}

// (v Vertex) 是接收者参数，位于 func 关键字和方法名之间。方法只能有一个接收者参数，并且要用小括号括起来
func (v Vertex) Abs() float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}

func main() {
 v := Vertex{3, 4}
 fmt.Println(v.Abs()) // 5  --通过接收者类型的值调用方法
}
```

方法只不过是一个带有接收者参数的函数而已。如下是以常规函数形式编写的 `Abs` 函数，其功能与上述方法完全一样。

```go
func Abs(v Vertex) float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}
```

当将一个结构体类型匿名嵌入到另一个结构体类型时，外部结构体会自动获得内部结构体的所有方法（方法提升）。如果外部结构体定义了与匿名内嵌结构体同名的方法，则外部结构体的方法会“覆盖”内部结构体的方法。

## 接收者类型要求

方法接收者类型必须是自定义类型或指向自定义类型的指针类型，

- 不允许直接将接口类型用作方法接收者（如 `func (i error) MyMethod()`）
- 不允许为将接口类型作为基础类型的自定义类型声明方法（如 `type MyError error`）
- 不允许为将指针类型作为基础类型的自定义类型声明方法（如 `type MyPtr *int`）

```go
// 接口
type Callable interface {
 Invoke()
}

// 1. 接收者不能是接口类型，编译报错：invalid receiver type Callable (pointer or interface type)
func (c Callable) Invoke() {
}

type Vertex struct {
 X, Y float64
}

type FooInterface interface{} // 2. 自定义类型，底层类型是接口类型
type FooPointer *Vertex       // 3. 自定义类型，底层类型是指针类型

// 编译报错：invalid receiver type FooInterface (pointer or interface type)
func (f FooInterface) F() {
}

// 编译报错：invalid receiver type FooPointer (pointer or interface type)
func (f FooPointer) F() {
}
```

```go
type Vertex struct {
 X, Y float64
}

type Ver = Vertex // 类型别名：Ver 与 Vertex 等价，可定义方法

func (v Ver) Abs() float64 {
 return math.Sqrt(v.X*v.X + v.Y*v.Y)
}

func main() {
 v := Ver{3, 4}
 fmt.Println(v.Abs())
}
```

### 同包原则

方法接收者的类型定义和方法声明必须在同一个包中，即声明方法时，其接收者类型只能定义在方法所在的包中，不能为定义在其它包中的类型声明方法。基于“同包原则”，

- 不能直接为基本类型声明方法（如 `func (f float64) Abs() float64`），因为预声明的内置类型（如 `float64`、`int`）不在任何可导入的包内，无法满足同包原则要求
- 不能为基本类型的别名（如 `type MyInt = int`）声明方法，因为别名类型和原类型在类型系统中是完全等价的

```go
// float64 是预声明的基本类型，不能直接为其定义方法。编译报错：cannot define new methods on non-local type float64
func (f float64) Abs() float64 {
 if f < 0 {
  return -f
 }
 return f
}

// MyFloat 是 float64 的类型别名（等价于 float64），不能为其定义方法，编译报错：cannot define new methods on non-local type MyFloat
type MyFloat = float64

func (f MyFloat) Abs() float64 {
 if f < 0 {
  return -f
 }
 return f
}

// 使用类型定义而非别名创建新类型，可以声明方法
type MyFloat float64 // 自定义类型 MyFloat，虽然底层类型是 float64，但 MyFloat 是一个新类型

func (f MyFloat) Abs() float64 {
 if f < 0 {
  return float64(-f)
 }
 return float64(f)
}
```

## 值接收者与指针接收者

方法接收者参数可以是值类型或指针类型，但不能是指针的指针（`**`），这不是技术限制，而是设计选择：Go 希望方法接收者语义简单、可预测，避免多层间接带来的复杂性。

- 值接收者：方法接收者参数是值类型，如 `(v Vertex)`。调用方法时，接收者形参是实参（值）的一个副本，在方法体中对接收者形参的修改不影响实参。适用于不修改接收者状态且类型为较小结构体/数组的场景
- 指针接收者：方法接收者参数是指针类型，如 `(v *Vertex)`。调用方法时，接收者形参是实参（指针）的一个副本，形参指针与实参指针指向的是同一个值，在方法体中对接收者形参的修改会影响实参。适用于需要修改接收者状态或类型为较大结构体/数组（拷贝开销）的场景

官方 Wiki 对方法接收者的说明：<https://go.dev/wiki/CodeReviewComments#receiver-type>

- 引用类型接收者不用指针：如果接收者是映射、函数、通道，不要用指向它们的指针。如果接收者是切片，且方法不重新切片、不重新分配内存，也不要用指针
- 需要修改接收者的状态，必须用指针
- 含同步字段（如 sync.Mutex）的结构体，必须用指针
- 大型结构体/大数组用指针，减少拷贝开销
- 接收者可能被外部并发修改，用指针：值接收者会在方法调用时拷贝一份，外部的修改不会反映到这个副本上。如果希望方法看到原始接收者的最新状态，必须用指针
- 元素含指针，优先指针：如果接收者是结构体、数组、切片，且其中任何元素是指向可能变化的东西的指针，优先用指针接收者，让意图更清晰
- 小而不可变的值类型，值接收者合适：如果接收者是小型数组/结构体，天然是值类型（如 `time.Time`），没有可变字段、没有指针，或者是 `int`、`string` 这样的基本类型，值接收者更合适
- 不要混用接收者类型：同一个类型的所有方法，要么全用指针，要么全用值
- 拿不准就用指针

Go 简化了方法调用，不管方法接收者参数是值类型还是指针类型，接收者类型的值变量（值实参）或指针变量（指针实参，指向值变量）都可以直接调用方法，无需手动取地址或解引用。

- 值变量 v 调用指针接收者方法 `v.Scale()`，编译器自动转为 `(&v).Scale()`，注意：只有可寻址的值变量才能自动取地址，如果值变量不可寻址（例如常量、函数的返回值、映射的值），则无法直接调用指针接收者方法，编译报错
- 指针变量 p 调用值接收者方法 `p.Abs()`，编译器自动转为 `(*p).Abs()`

```go
type Vertex struct {
 X, Y float64
}

func (v Vertex) Abs() float64 {
 result := math.Sqrt(v.X*v.X + v.Y*v.Y)
 v.X = 0 // 仅示例
 return result
}

func (v *Vertex) Scale(f float64) {
 v.X *= f
 v.Y *= f
}

func main() {
 vr := Vertex{3, 4}
 fmt.Println(vr) // {3 4}

 pr := &Vertex{1, 2}
 fmt.Println(*pr) // {1 2}

 fmt.Println(vr.Abs()) // Abs 方法的接收者参数是值类型，可以通过值变量 vr 调用，形参是实参的副本，在方法体中对接收者形参 v 的修改不影响原始变量
 fmt.Println(vr)       // {3 4}  --vr 保持不变

 fmt.Println(pr.Abs()) // 也可以通过指针变量 p 调用，会被编译器隐式解引用为 (*pr).Abs()，在方法体中对接收者形参 v 的修改不影响原始变量
 fmt.Println(*pr)      // {1 2}  --*pr 保持不变

 pr.Scale(10)     // Scale 方法的接收者参数是指针类型，可以通过指针变量 pr 调用，形参指针 v 与实参指针 pr 指向的是同一个值变量，在方法体中对形参 v 的修改会影响原始变量
 fmt.Println(*pr) // {10 20}  --*pr 被改变了

 vr.Scale(10)    // 也可以通过值变量 vr 调用，会被编译器隐式取地址为 (&v).Scale(10)，在方法体中对形参 v 的修改会影响原始变量
 fmt.Println(vr) // {30 40}  --vr 被改变了
}
```

这与函数调用有明显区别：函数调用时指针参数必须传指针变量，值参数必须传值变量。

```go
func f1(p *int) {
 fmt.Println(*p)
}

func f2(n int) {
 fmt.Println(n)
}

func main() {
 a := 1
 f1(a) // 编译报错，f1 接收指针参数，不能传入值变量
 f1(&a)

 f2(&a) // 编译报错，f2 接收值参数，不能传入指针变量
 f2(a)
}
```

可以用第三方工具 <https://github.com/raeperd/recvcheck> 检查方法接收者类型是否一致。

安装：`go install github.com/raeperd/recvcheck/cmd/recvcheck@latest`

使用：`recvcheck ./...`

## 方法值、方法表达式

方法值和方法表达式是两种不同的方法调用方式。

### 方法值（Method Values）

方法值是将方法绑定到特定接收者的函数值，创建语法：`fn := 接收者.方法名`。

接收者在创建方法值的那一刻就固定下来了，所以方法值是无接收者参数的普通函数。当方法值被调用时，会使用创建方法值时保存的接收者。

- 当方法接收者参数是值类型时，方法值保存的是接收者（值）的一个副本，修改原始接收者不影响方法值中固化的副本
- 当方法接收者参数是指针类型时，方法值保存的是接收者（指针）的一个副本，这个指针副本指向的就是原始接收者

| 方法接收者类型 | 实际接收者 | 方法值绑定行为 |
| -- | -- | -- |
| 值类型 | 值变量 `rect` | 拷贝 `rect` 的值，方法值保存的接收者（值）是 `rect` 的一个副本 |
| 值类型 | 指针变量 `p`，指向 `rect` 变量 | 自动解引用后拷贝 `*p`，方法值保存的接收者（值）是 `rect` 的一个副本 |
| 指针类型 | 值变量 `rect` | 自动取地址后拷贝 `&rect`，方法值保存的接收者（指针）指向 `rect` 变量 |
| 指针类型 | 指针变量 `p`，指向 `rect` 变量 | 拷贝指针 `p`，方法值保存的接收者（指针）指向 `rect` 变量 |

```go
type Rectangle struct {
 width, height float64
}

// 值接收者方法
func (r Rectangle) Area() float64 {
 return r.width * r.height
}

// 指针接收者方法
func (r *Rectangle) Scale(factor float64) {
 r.width *= factor
 r.height *= factor
}

func main() {
 rect := Rectangle{width: 2, height: 4} // rect 为值变量
 // rect := &Rectangle{width: 2, height: 4} rect 为指针变量时结果一样，与实际接收者是值变量还是指针变量无关，仅与方法接收者参数类型有关

 // 创建方法值
 areaFunc := rect.Area   // 值接收者方法，保存的是 rect 的一个副本
 scaleFunc := rect.Scale // 指针接收者方法，等价于 (&rect).Scale，保存的是指向 rect 的指针

 fmt.Printf("%T, %T\n", areaFunc, scaleFunc) // func() float64, func(float64)  --方法值是无接收者参数的普通函数

 // 修改原始接收者。方法值已经创建了，这里的修改不会影响 areaFunc（Area 是值接收者方法），但会影响 scaleFunc（Scale 是指针接收者方法）
 rect.width = 3

 fmt.Printf("rect 真实面积：%.2f\n", rect.Area()) // 12

 // 使用方法值调用
 fmt.Printf("使用方法值计算面积：%.2f\n", areaFunc()) // 8  --areaFunc 保存的接收者（副本）是 width=2, height=4，所以面积仍为 8

 scaleFunc(2.0)                                              // 在 width=3, height=4 的基础上缩放 2 倍，rect 变为 width=6, height=8
 fmt.Printf("实际矩形尺寸：%.2f x %.2f\n", rect.width, rect.height) // 6 x 8

 // 使用方法值调用
 fmt.Printf("使用方法值计算面积：%.2f\n", areaFunc()) // 8  --areaFunc 保存的接收者（副本）是 width=2, height=4，所以面积仍为 8

 fmt.Printf("rect 真实面积：%.2f\n", rect.Area()) // 48
}
```

使用场景：常用于回调/函数式风格，如 go 启动协程、defer 延迟、注册 handler 等。

```go
defer f.Close()
```

### 方法表达式（Method Expressions）

方法表达式是把方法“提升”为普通函数，接收者变成了函数的第一个参数，调用时必须显式传递这个参数。

方法表达式的创建语法：

- 当方法接收者参数是值类型时：`类型.方法名`（函数的第一个参数是值类型），`(*类型).方法名`（函数的第一个参数是指针类型，要加小括号）
- 当方法接收者参数是指针类型时：`(*类型).方法名`（函数的第一个参数是指针类型），不能定义第一个参数是值类型的方法表达式，编译报错

```go
type Circle struct {
 radius float64
}

func (c Circle) Area() float64 {
 return math.Pi * c.radius * c.radius
}

func (c *Circle) SetRadius(r float64) {
 c.radius = r
}

func main() {
 // 创建方法表达式
 areaExpr := Circle.Area              // 值接收者方法
 setRadiusExpr := (*Circle).SetRadius // 指针接收者方法，要加小括号

 fmt.Printf("%T, %T\n", areaExpr, setRadiusExpr) // func(main.Circle) float64, func(*main.Circle, float64)  --接收者作为函数的第一个参数

 areaExpr2 := (*Circle).Area   // 方法 Area 是值类型接收者，允许定义指针类型的方法表达式
 fmt.Printf("%T\n", areaExpr2) // func(*main.Circle) float64  --接收者作为函数的第一个参数

 // setRadiusExpr2 := Circle.SetRadius // 方法 SetRadius 是指针类型接收者，不允许定义值类型的方法表达式，编译报错
 // fmt.Printf("%T\n", setRadiusExpr2)

 c1 := Circle{radius: 5}
 c2 := Circle{radius: 10}

 // 使用方法表达式调用，需要显式传递接收者参数
 area1 := areaExpr(c1)
 area2 := areaExpr(c2)

 fmt.Printf("圆 1 面积：%.2f\n", area1) // 78.54
 fmt.Printf("圆 2 面积：%.2f\n", area2) // 314.16

 // 使用指针接收者的方法表达式
 setRadiusExpr(&c1, 8)                   // 修改了 c1 的半径
 newArea := areaExpr(c1)                 // c1 的面积也会改变
 fmt.Printf("修改后圆 1 面积：%.2f\n", newArea) // 201.06
}
```

使用场景：常用于泛型/反射/代码生成。

### 总结

方法值和方法表达式本质上都是将方法转换为函数。在 Go 中，方法不是“一等公民”，方法不能直接作为函数参数传递，通过方法值和方法表达式可以将方法转换为函数，从而实现回调和高阶函数。

示例：在运行时动态选择方法（策略模式）

```go
type Point struct{ X, Y float64 }

func (p Point) Add(q Point) Point { return Point{p.X + q.X, p.Y + q.Y} }
func (p Point) Sub(q Point) Point { return Point{p.X - q.X, p.Y - q.Y} }

type Path []Point

func (path Path) TranslateBy(offset Point, add bool) {
 var op func(p, q Point) Point
 if add {
  op = Point.Add // 方法表达式，接收者变成了函数的第一个参数
 } else {
  op = Point.Sub
 }

 for i := range path {
  // Call either path[i].Add(offset) or path[i].Sub(offset).
  path[i] = op(path[i], offset) // 如果不使用方法表达式，在这里就要根据 add 参数来选择调用 Add 或 Sub 方法
 }
}

func main() {
 path := Path{
  {1, 2},
  {3, 4},
  {5, 6},
 }
 path.TranslateBy(Point{10, 10}, true)
 println(path)
}
```

示例：函数式编程

```go
type Rectangle struct {
 width  int
 height int
}

func (r Rectangle) Area() int {
 return r.width * r.height
}

// 通用的 map 函数
func mapSlice[T, U any](slice []T, f func(T) U) []U {
 result := make([]U, len(slice))
 for i, item := range slice {
  result[i] = f(item)
 }
 return result
}

func main() {
 rects := []Rectangle{{1, 2}, {3, 4}, {5, 6}}

 // 使用方法表达式作为映射函数
 areas := mapSlice(rects, Rectangle.Area) // 方法表达式
 fmt.Println(areas) // [2 12 30]
}
```

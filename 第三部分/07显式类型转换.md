# 显式类型转换

Go 不支持隐式类型转换，在不同类型的项之间赋值时需用 `T(v)` 显式转换，表达式 `T(v)` 表示将值 `v` 转换为类型 `T`。对于指针类型，语法为 `(*T)(v)`。

## 数值类型转换

```go
func main() {
 var i int = 42
 var f float64 = float64(i) // int -> float64
 var u uint = uint(f)       // float64 -> uint
 var b byte = byte(i)       // int -> byte
 var r rune = rune(i)       // int -> rune

 fmt.Printf("%v %v %v %v %v\n", i, f, u, b, r) // 42 42 42 42 42
}
```

数值类型转换时需注意：常量转换要求值能被目标类型精确表示，否则编译报错；以下有损转换的例子都需先把值存入变量。

- 大范围整数转小范围整数：超出目标类型范围的位被截断，仅保留低位。例如 `int16(1000)` 转为 `int8` 时，1000 超出 `int8` 的范围（-128~127），结果为 `-24`（1000 的低 8 位为 `11101000`，按补码解释）
- 浮点数转整数：小数部分被直接舍弃（向零截断），不会四舍五入。例如 `float64(3.99)`转为 `int` 的结果为 3，`float64(-3.99)`转为 `int` 的结果为 -3
- 整数转浮点数：若整数值的有效位数超出浮点数的精度位数，可能丢失精度。例如 `int64` 的最大值 `int64(9223372036854775807)` 转为 `float64` 时，会因 `float64` 仅 53 位有效尾数而丢失低位精度

```go
func main() {
 {
  var a int16 = 1000
  var b int8 = int8(a)
  fmt.Println(b) // -24
 }

 {
  var a float64 = 3.99
  var b int = int(a)
  fmt.Println(b) // 3

  a = -3.99
  b = int(a)
  fmt.Println(b) // -3
 }

 {
  var a int64 = math.MaxInt64
  var b float64 = float64(a)
  fmt.Println(b) // 9.223372036854776e+18
 }
}
```

## 字符串与字节切片互转

```go
func main() {
 s := "hello"
 b := []byte(s)  // string -> []byte
 s2 := string(b) // []byte -> string

 fmt.Printf("%v %v\n", s, s2) // hello hello
}
```

## 字符串与 rune 切片互转

`string` 与 `[]rune` 的转换用于按 Unicode 码点（Code Point）处理字符串，避免因多字节字符被按字节切分而出现乱码。

```go
func main() {
 s := "你好，世界"
 rs := []rune(s)   // string -> []rune，按 Unicode 码点切分
 s2 := string(rs)  // []rune -> string

 fmt.Printf("%v %v\n", len(rs), s2) // 5 你好，世界
}
```

## 自定义类型转换

```go
func main() {
 type MyInt int
 var x MyInt = 10
 var y int = int(x)     // MyInt -> int
 var z MyInt = MyInt(y) // int -> MyInt

 fmt.Printf("%v %v %v\n", x, y, z) // 10 10 10
}
```

## 指针类型转换

Go 中不同类型的指针之间不能直接转换，必须借助 `unsafe.Pointer` 作为桥梁。`unsafe.Pointer` 转换绕过了类型系统，在使用时须确保二者内存布局兼容。

```go
func main() {
 // 将一个 *int 转换为 *float64（仅示例，结果无意义）
 n := 42
 pn := &n
 // pf := (*float64)(pn) // 直接转换，编译报错
 pf := (*float64)(unsafe.Pointer(pn))             // *int -> unsafe.Pointer -> *float64
 fmt.Printf("%v\n", *pf)                          // 2.08e-322  --结果无意义，因为 int 与 float64 的内存布局完全不同

 // 将结构体指针转换为另一个结构体指针（须确保内存布局兼容）
 type A struct{ Name string }
 type B struct {
  Name string
  Age  int32
 }

 pa := &A{Name: "hello"}
 // pb := (*B)(pa) // 直接转换，编译报错
 pb := (*B)(unsafe.Pointer(pa)) // *A -> unsafe.Pointer -> *B
 fmt.Println(pb.Name)           // hello

 // uintptr 与 unsafe.Pointer 互转（用于底层内存操作）
 var i int = 100
 ptr := unsafe.Pointer(&i)
 addr := uintptr(ptr)           // unsafe.Pointer -> uintptr  --应即用即弃，不应长期保存 uintptr 值，因为 GC 不会将其视为指针引用，对象可能被回收
 newPtr := unsafe.Pointer(addr) // uintptr -> unsafe.Pointer
 pi := (*int)(newPtr)           // unsafe.Pointer -> *int
 fmt.Printf("%v\n", *pi)        // 100
}
```

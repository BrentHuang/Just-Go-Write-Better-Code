
# 各类型的零值

对于没有显式初始化的变量（包括全局变量、函数体中的局部变量、函数的命名返回值等），编译器会将它们隐式初始化为其类型的零值，确保所有变量始终处于一种可用的“确定”状态：

| 类型 | 零值 |
| -- | -- |
| bool 类型 | `false` |
| 整型（`int`、`byte`、`rune` 等） | `0` |
| 浮点型 | `0.0` |
| 复数类型 | `(0+0i)` |
| string 类型 | `""`（空字符串） |
| 指针、切片、映射、函数、接口、通道类型 | `nil` |
| 数组类型 | 各个元素的零值构成的数组 |
| 结构体类型 | 各个成员的零值构成的结构体 |

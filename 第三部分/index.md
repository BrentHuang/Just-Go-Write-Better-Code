# 第三部分

## 概览

本部分系统介绍 Go 语言的类型系统，涵盖基本数据类型（bool、数字、字符、string）、自定义类型与类型别名的区别、各类型的零值，以及 fmt 包的格式化输出功能。理解类型系统是掌握 Go 语言设计与高效编程的关键。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 布尔类型](01布尔类型.md) | bool 值语义、与 string 的转换（strconv 包） | 掌握布尔值的使用与转换，避免隐式类型转换误区 |
| [02 数字类型](02数字类型.md) | 整数、浮点数、复数，字面量与进制、strconv 转换、NaN 与无穷大 | 理解整数溢出回绕、浮点数精度约束与正确比较方法 |
| [03 自定义类型与类型别名](03自定义类型与类型别名.md) | `type` 定义与类型别名的区别、方法集独立性、分组声明 | 正确区分“新类型”与“别名”，合理运用类型系统机制 |
| [04 字符类型](04字符类型.md) | byte、rune 与字符字面量、转义序列 | 理解字符的整数本质与各种字面量书写形式 |
| [05 字符串类型](05字符串类型.md) | 字符串字面量、底层结构、字节与 rune、遍历与切片、连接与 strings/strconv 包 | 理解字符串不可变性与字符边界的正确处理 |
| [06 各类型的零值](06各类型的零值.md) | 各类型对应零值速查 | 明确“未初始化即有确定值”的语言保证 |
| [07 fmt 包](07fmt包.md) | Print 家族函数、格式化动词、宽度与精度、参数索引 | 熟练使用格式化输出并掌握动词语义 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第二部分，掌握变量（`var`、`:=`）与常量的声明语法，本部分示例大量依赖它们。
- 建议按章节顺序学习：布尔类型、数字类型、自定义类型与类型别名、字符类型、字符串类型、各类型的零值、fmt 包。
- 数字类型中的 strconv 转换是小节化知识点，可与字符串类型的 strconv 小节对照学习；两处存在交叉引用。
- 各类型的零值是对前五章类型的小结，可在阅读后将其作为速查表保留。
- fmt 包是对前六章类型的综合练习与输出手段，建议完成前六章后再学习。

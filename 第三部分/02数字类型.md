# 数字类型

数字类型包括整数、浮点数、复数类型，它们都是基本数据类型。

## 整数类型

整型：int、int8、int16、int32、int64

无符号整型：uint、uint8、uint16、uint32、uint64、uintptr

int、uint 和 uintptr 的位宽取决于系统架构是 32 位还是 64 位。

需要整数值时应使用 `int` 类型，除非有特殊理由使用固定位宽或无符号类型。无符号整数通常并不用于仅仅表达非负数量的场合，只在位运算或其它特殊的运算场景才会使用，比如 bit 集合、分析二进制文件格式、哈希和加密操作等。

常量 [math.MaxInt](https://pkg.go.dev/math#MaxInt)、[math.MinInt](https://pkg.go.dev/math#MinInt)、[math.MaxUint](https://pkg.go.dev/math#MaxUint) 分别表示对应类型的最大、最小值。

Go 的整数运算在溢出时不抛出异常，而是按二进制补码规则回绕（wrap around）。例如 `uint8(255) + 1` 结果为 `0`，`int8(127) + 1` 结果为 `-128`。编译器仅对常量表达式的溢出报错，变量运算的溢出在运行时静默发生。

除十进制外，整数字面量还可以用十六进制、八进制和二进制表示。

- 十六进制表示法：以 `0x` 或 `0X` 开头
- 八进制表示法：以 `0` 开头 或者 `0o` 开头，八进制数据通常用于 POSIX 操作系统上的文件访问权限标志
- 二进制表示法：以 `0b` 开头

```go
func main() {
 a := 0xff
 b := 0xFF

 c := 012
 d := 0o12

 e := 0b10

 fmt.Printf("%d %d %d %d %d\n", a, b, c, d, e) // 255 255 10 10 2
 fmt.Printf("a: %#x\n", a)  // 0xff
 fmt.Printf("a: %#X\n", a)  // 0XFF
 fmt.Printf("c: %#o\n", c)  // 012
 fmt.Printf("d: %#O\n", d)  // 0o012
 fmt.Printf("e: %#b\n", e)  // 0b10
}
```

### 整型与 string 的转换

将整数转换为字符串：用 [func Itoa(i int) string](https://pkg.go.dev/strconv#Itoa) 或 [func FormatInt(i int64, base int) string](https://pkg.go.dev/strconv#FormatInt)，无符号整数用 [func FormatUint(i uint64, base int) string](https://pkg.go.dev/strconv#FormatUint)，性能均优于 `fmt.Sprintf`。

将字符串解析为整数：用 [func Atoi(s string) (int, error)](https://pkg.go.dev/strconv#Atoi) 或 [func ParseInt(s string, base int, bitSize int) (i int64, err error)](https://pkg.go.dev/strconv#ParseInt)，无符号整数用 [func ParseUint(s string, base int, bitSize int) (uint64, error)](https://pkg.go.dev/strconv#ParseUint)。

FormatInt 和 ParseInt 的第二个参数 base 表示进制。

| base 值 | 含义 | 示例 |
| -- | -- | -- |
| 0 | 自动检测（根据前缀判断：`0x` 十六进制，`0` 八进制，其它为十进制） | `"0xFF"` -> 255 |
| 2 | 二进制 | `"1101"`（13） |
| 8 | 八进制 | `"077"`（63） |
| 10 | 十进制 | `"123"`（123） |
| 16 | 十六进制 | `"0xFF"` 或 `"FF"`（255） |

ParseInt 返回的结果总是 int64 类型，通过第三个参数 bitSize（位宽）指定校验范围，若结果超出该范围则返回错误。ParseUint 同理，始终返回 uint64。

| bitSize | 校验目标类型 | 含义 |
| -- | -- | -- |
| 0 | int（平台相关） | 32 位平台同 int32，64 位平台同 int64 |
| 8 | int8 | 结果必须落在 int8 能够表示的范围内 |
| 16 | int16 | 结果必须落在 int16 能够表示的范围内 |
| 32 | int32 | 结果必须落在 int32 能够表示的范围内 |
| 64 | int64 | 结果必须落在 int64 能够表示的范围内 |

```go
func main() {
 x := 123
 s1 := fmt.Sprintf("%d", x)
 fmt.Println(s1) // 123

 s2 := strconv.Itoa(x)
 fmt.Println(s2) // 123

 s3 := strconv.FormatInt(int64(x), 2) // 第二个参数 base 指定输出字符串的进制，2<=base<=36
 fmt.Println(s3)                      // 1111011  --二进制字符串

 s4 := strconv.FormatInt(int64(x), 10)
 fmt.Println(s4) // 123

 s5 := strconv.FormatInt(int64(x), 16)
 fmt.Println(s5) // 7b

 x1, err := strconv.Atoi("123") // x is an int
 fmt.Printf("%d %v\n", x1, err) // 123 nil

 y, err := strconv.ParseInt("1101", 2, 0)
 fmt.Printf("%d %v\n", y, err) // 13 nil

 y1, err := strconv.ParseInt("123", 10, 0)
 fmt.Printf("%d %v\n", y1, err) // 123 nil

 y2, err := strconv.ParseInt("FF", 16, 8) // base=16 表示十六进制，bitSize=8 表示校验 int8 范围
 fmt.Printf("%d %v\n", y2, err)           // 127 strconv.ParseInt: parsing "FF": value out of range  --0xFF 超出了 int8 能够表示的范围
}
```

### uintptr 类型

uintptr 是无符号整数类型，用于存储 `unsafe.Pointer` 的值（内存地址）。

Go 普通指针不支持算术运算（如 `p++`、`p+offset`），开发者可以先将指针通过 `unsafe.Pointer` 转换为 uintptr 进行地址的算术计算，再立即转换回 `unsafe.Pointer`。

uintptr 不具备指针语义，不持有对象的引用，GC 不会追踪 uintptr 变量。应在同一表达式中完成“转换（unsafe.Pointer -> uintptr） -> 计算 -> 转换（uintptr -> unsafe.Pointer）”，从 `unsafe.Pointer` 转换得到的 uintptr 变量，绝对不应赋值给其它变量保存起来供后续使用。

```go
func main() {
 arr := []int{1, 2, 3}

 // 正确用法：在同一表达式中完成“转换（unsafe.Pointer -> uintptr） -> 计算 -> 转换（uintptr -> unsafe.Pointer）”
 p := unsafe.Pointer(&arr[0])
 p1 := unsafe.Pointer(uintptr(p) + unsafe.Sizeof(arr[0])) // p1 指向数组的第二个元素。在这个表达式中完成了“转换 - 计算 - 转换”

 fmt.Println(*(*int)(p1)) // 2

 // 错误用法：将 uintptr 保存到变量后再使用
 // p2 := uintptr(p)  
 // 危险！GC 可能在此期间移动或回收地址为 p2 的对象
 // p3 := unsafe.Pointer(p2) // 地址可能失效
}
```

Go 1.17 引入了 `unsafe.Add(p, len)`，语义明确，不会脱离 GC 跟踪，凡是“指针 + 偏移量”，都应该使用 `unsafe.Add`。

## 浮点型

浮点型：float32、float64

应优先使用 float64，因为 float32 的累计计算误差很容易扩散。

常量 [math.MaxFloat32](https://pkg.go.dev/math#MaxFloat32)、[math.MaxFloat64](https://pkg.go.dev/math#MaxFloat64) 分别表示对应类型的最大值，[math.SmallestNonzeroFloat32](https://pkg.go.dev/math#SmallestNonzeroFloat32) 和 [math.SmallestNonzeroFloat64](https://pkg.go.dev/math#SmallestNonzeroFloat64) 分别是 float32 和 float64 能表示的最小正浮点数（约 1.40e-45 和 4.94e-324）。

IEEE 754 浮点数在正负方向是对称的，最大的正浮点数取负就是最小的负浮点数。所以最负的 float32 就是 `-math.MaxFloat32`。这与整数不同，整数采用补码表示，负数比正数多一个值（如 int8 的 MaxInt8 = 127，MinInt8 = -128）。

浮点数字面量小数点前面或后面的数字可以省略（默认为 0），如 `.707` 或 `1.`。

```go
func main() {
 // 省略整数部分
 a := .707      // 等价于 0.707
 fmt.Println(a) // 0.707

 // 省略小数部分
 b := 1.        // 等价于 1.0
 fmt.Println(b) // 1
}
```

科学记数法表示：`<底数部分>e<指数部分>` 或 `<底数部分>E<指数部分>`，其中：

- 底数部分可以是整数或浮点数
- 指数部分必须是整数（可带正负号）
- `e`/`E` 表示“10 的 n 次方”（以 10 为底）

fmt 包使用 `%e` 或 `%E` 输出浮点数的科学记数法表示形式。

在 Go 表达式 `math.SmallestNonzeroFloat64 = 0x1p-1022 * 0x1p-52` 中，符号 p 代表的是以 2 为底的指数。这种表示法的通用格式是 `0x<十六进制底数>p<十进制指数>`，常用于需要精确描述浮点数位模式的场景。

### 浮点型与 string 的转换

将浮点数转换为字符串：用 [func FormatFloat(f float64, fmt byte, prec, bitSize int) string](https://pkg.go.dev/strconv#FormatFloat)，性能优于 `fmt.Sprintf`。参数 `fmt` 指定输出格式，`prec` 控制精度，`bitSize` 表示原始数值的位宽：32 或 64。

| fmt | 含义 | prec 的含义 |
| -- | -- | -- |
| `'f'` | 小数形式（无指数），如 `-ddd.ddd` | 小数点后的位数 |
| `'e'`/`'E'` | 科学记数法，如 `-d.dddde±dd` | 小数点后的位数 |
| `'g'`/`'G'` | 自动选择 `'f'` 或 `'e'` | 有效数字总位数 |

将字符串解析为浮点数：用 [func ParseFloat(s string, bitSize int) (float64, error)](https://pkg.go.dev/strconv#ParseFloat)，参数 `bitSize` 指定结果精度：32 或 64。

```go
func main() {
 f := 3.14159

 s1 := strconv.FormatFloat(f, 'f', 2, 64)
 fmt.Println(s1) // 3.14

 s2 := strconv.FormatFloat(f, 'e', 4, 64)
 fmt.Println(s2) // 3.1416e+00

 s3 := strconv.FormatFloat(f, 'g', 3, 64)
 fmt.Println(s3) // 3.14

 f1, err := strconv.ParseFloat("3.14", 64)
 fmt.Printf("%v %v\n", f1, err) // 3.14 nil

 f2, err := strconv.ParseFloat("1.5e3", 64)
 fmt.Printf("%v %v\n", f2, err) // 1500 nil
}
```

### 浮点数比较

由于 IEEE 754 浮点数的精度限制，直接使用 `==` 比较两个浮点数往往不可靠。例如 `0.1 + 0.2 == 0.3` 在 Go 中求值为 `false`，因为 `0.1` 和 `0.2` 在二进制浮点表示中无法被精确表示。应使用误差容忍的方式进行近似比较。

- 绝对误差：测量值与真实值之间的差值的绝对值，适用于比较的数值量级相近的场景
- 相对误差：绝对误差与真实值的比值，适用于比较的数值量级可能相差很大的场景

```go
// isZero 检查浮点数是否接近零（浮点数与 0 比较）
func isZero(f float64, epsilon float64) bool {
 return math.Abs(f) <= epsilon
}

// almostEqual 判断两个浮点数是否接近相等（浮点数相等比较）
func almostEqual(a, b, epsilon float64) bool {
 if a == b { // 快速路径，包括处理 ±0 相等的情况
  return true
 }
 diff := math.Abs(a - b)
 // 结合绝对误差和相对误差，避免在比较两个很大的数时因绝对误差失效
 return diff <= epsilon || diff <= epsilon*math.Max(math.Abs(a), math.Abs(b))
}

func main() {
 epsilon := 1e-9 // 根据具体场景调整误差范围

 {
  f1 := 0.0
  f2 := 1e-10
  f3 := -1e-10

  fmt.Println(isZero(f1, epsilon)) // true
  fmt.Println(isZero(f2, epsilon)) // true
  fmt.Println(isZero(f3, epsilon)) // true

  a := 0.1 + 0.2
  b := 0.3

  fmt.Println(almostEqual(a, b, epsilon)) // true
 }

 {
  // 场景 1：比较接近零的数
  a := 1e-10
  b := 0.0
  // 绝对误差：|1e-10 - 0| = 1e-10 <= 1e-9
  // 相对误差：无意义（分母为 0）
  fmt.Println(almostEqual(a, b, epsilon)) // true

  // 场景 2：比较大数
  c := 1e18
  d := 1e18 + 1
  // 绝对误差：|1e18 - (1e18+1)| = 1 <= 1e-9（失败）
  // 相对误差：1 / 1e18 = 1e-18 <= 1e-9（成功）
  fmt.Println(almostEqual(c, d, epsilon)) // true
 }
}
```

在金融计算等不能容忍任何精度损失的场景，需要使用专门的高精度数学库，如 [math/big](https://pkg.go.dev/math/big)。

## 复数类型

复数类型：

- complex64: 32 位实部 + 32 位虚部
- complex128: 64 位实部 + 64 位虚部

内置的 [func complex(r, i FloatType) ComplexType](https://pkg.go.dev/builtin#complex) 函数用于构建复数，内置的 [func real(c ComplexType) FloatType](https://pkg.go.dev/builtin#real) 和 [func imag(c ComplexType) FloatType](https://pkg.go.dev/builtin#imag) 函数分别返回复数的实部和虚部。[math/cmplx](https://pkg.go.dev/math/cmplx) 包提供了复数的基本常量和数学函数。

注意：`complex()` 函数的实部和虚部的类型必须一致，为 float32 时返回 complex64，为 float64 时返回 complex128。

```go
func main() {
 // 1. 使用复数字面量创建复数
 var c1 complex64 = 3 + 4i       // complex64 类型
 var c2 complex128 = 2.5 - 3.14i // 复数字面量默认 complex128 类型

 // 2. 使用 complex() 函数创建复数
 c3 := complex(1, 2)                                // 默认 complex128 类型
 var c4 complex64 = complex(float32(5), float32(6)) // complex64 类型
 fmt.Printf("%v\n", c4)                             // (5 + 6i)

 // 3. 使用 real() 和 imag() 获取实部和虚部
 fmt.Printf("%v\n", c1)                          // (3+4i)
 fmt.Printf("实部：%v，虚部：%v\n", real(c1), imag(c1)) // 实部：3，虚部：4

 // 4. 复数运算。加减：二维坐标下的平移，乘除：二维平面上的旋转和缩放
 sum := c2 + c3      // 加法
 diff := c2 - c3     // 减法
 product := c2 * c3  // 乘法
 quotient := c2 / c3 // 除法

 fmt.Printf("c2 + c3 = %v\n", sum)      // c2 + c3 = (3.5-1.1400000000000001i)
 fmt.Printf("c2 - c3 = %v\n", diff)     // c2 - c3 = (1.5-5.140000000000001i)
 fmt.Printf("c2 * c3 = %v\n", product)  // c2 * c3 = (8.780000000000001+1.8599999999999999i)
 fmt.Printf("c2 / c3 = %v\n", quotient) // c2 / c3 = (-0.756-1.6280000000000001i)

 // 5. 使用 math/cmplx 包的函数
 abs := cmplx.Abs(c2)   // 绝对值（模）
 conj := cmplx.Conj(c2) // 共轭复数
 sqrt := cmplx.Sqrt(-1) // 求平方根（虚数单位 i）

 fmt.Printf("|c2| = %v\n", abs)      // |c2| = 4.013676618762403
 fmt.Printf("共轭：%v\n", conj)         // 共轭： (2.5+3.14i)
 fmt.Printf("sqrt(-1) = %v\n", sqrt) // sqrt(-1) = (0+1i)
}
```

## 数字分隔符

为提高大数字的可读性，Go 1.13 引入了下划线 `_` 作为数字分隔符：

```go
func main() {
 million := 1_000_000                                // 十进制 1000000
 hexBytes := 0xFF_FF_FF_FF                           // 十六进制表示
 binary := 0b1010_1011                               // 二进制表示
 fmt.Printf("%d %d %d\n", million, hexBytes, binary) // 1000000 4294967295 171

 f := 18_168e+2
 fmt.Printf("%f\n", f) // 1816800.000000
}
```

## 无穷大与 NaN

```go
func main() {
 var z float64
 fmt.Printf("%v, %v, %v, %v, %v\n", z, -z, 1/z, -1/z, z/z) // 0, -0, +Inf, -Inf, NaN
 fmt.Printf("%v, %v, %v\n", math.Inf(1), math.Inf(-1), math.NaN())        // +Inf, -Inf, NaN
}
```

NaN 是 "Not a Number" 的缩写，表示不是一个有效的数字。浮点数 `0.0/0.0` 的结果是 NaN，因为 IEEE 754 标准规定零除以零在数学上无定义，应返回“Not a Number”。

`NaN` 的特殊性质：它与任何值（包括自身）用 `==` 比较都返回 `false`。判断一个值是否为 `NaN` 需使用 `math.IsNaN()` 函数。

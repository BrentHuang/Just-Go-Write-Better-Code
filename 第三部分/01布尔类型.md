# 布尔类型

`bool` 是基本数据类型，取值为 `true` 或 `false`。`true` 和 `false` 是布尔字面量，也是无类型常量。

布尔值不会隐式转换为 `int` 类型的 0 或 1，反之亦然。

用 `%t` 格式化输出布尔值：

```go
func main() {
 b := false
 fmt.Printf("%t\n", b)  // false
}
```

## bool 与 string 的转换

[func FormatBool(b bool) string](https://pkg.go.dev/strconv#FormatBool) 将 `bool` 转换为字符串 `"true"` 或 `"false"`：

```go
func main() {
 s := strconv.FormatBool(true)
 fmt.Printf("%q\n", s) // "true"
}
```

[func ParseBool(str string) (bool, error)](https://pkg.go.dev/strconv#ParseBool) 将字符串解析为 `bool`。它接受 `"1"`, `"t"`, `"T"`, `"true"`, `"TRUE"`, `"True"` 为真，`"0"`, `"f"`, `"F"`, `"false"`, `"FALSE"`, `"False"` 为假：

```go
func main() {
 b, err := strconv.ParseBool("true")
 if err != nil {
  fmt.Println(err)
 }
 fmt.Println(b) // true

 b, err = strconv.ParseBool("1")
 if err != nil {
  fmt.Println(err)
 }
 fmt.Println(b) // true

 b, err = strconv.ParseBool("f")
 if err != nil {
  fmt.Println(err)
 }
 fmt.Println(b) // false

 b, err = strconv.ParseBool("off")
 if err != nil {
  fmt.Println(err) // strconv.ParseBool: parsing "off": invalid syntax
 }
 fmt.Println(b) // false
}
```

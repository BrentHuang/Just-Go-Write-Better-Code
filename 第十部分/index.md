# 第十部分 运行时与垃圾回收

## 概览

本部分深入 Go 运行时（Runtime）内部，涵盖 G-M-P 协程调度模型、内存分配器、垃圾回收（GC）机制等底层原理。理解运行时有助于编写更高效的 Go 程序。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [gc.md](gc.md) | GC 触发条件、三色标记法、STW 优化、`GOGC` 环境变量、GC 性能调优 | 理解 Go 垃圾回收机制的工作原理与调优方法 |
| [go 运行时.md](go运行时.md) | G-M-P 调度模型、内存分配、系统调用封装、netpoller、动态栈 | 理解 Go 运行时的运行机制和五大核心能力 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第九部分（并发编程），运行时调度涉及 G-M-P 模型与协同调度。
- 建议先学习 go 运行时，了解整体架构后再深入 GC 细节。
- 本部分涉及运行时内部实现细节，适合有一定 Go 经验的开发者阅读。

## 模板

Go 标准库的 [text/template](https://pkg.go.dev/text/template) 包和 [html/template](https://pkg.go.dev/html/template) 包提供了强大且内置的模板引擎。

- text/template：用于生成任意格式的文本，如配置文件、代码、邮件等
- html/template：专用于生成 HTML 文档。它提供了与 text/template 相同的 API，但核心区别在于它会自动且上下文感知地转义 HTML 内容，从而有效防止跨站脚本攻击（XSS）

### 模板语法

模板由静态文本和包裹在分隔符 `{{` 和 `}}` 中的[“动作”（Actions）](https://pkg.go.dev/text/template#hdr-Actions)组成。对于每一个 Action，都有一个当前值的概念，写作 `{{.}}`。当前值 `{{.}}` 被初始化为调用模板时的参数，当传入的是结构体或映射时，可以通过 `{{.Field}}` 访问其字段或键值。

“空”的定义：在 Go 模板中，nil、0、false、""、长度为零的数组/切片/映射都被视为“空”。

注释：`{{/* a comment */}}`

条件动作 `{{if 条件}} ... {{end}}`：用于条件渲染。当其后的管道（pipeline）值为空值时，视为 false。示例：

```go
{{if .IsAdmin}} <h1>管理面板</h1> {{end}}

{{if .IsLogin}} 欢迎回来 {{else}} 请先登录 {{end}}

{{if eq .Score 100}} A+ {{else if gt .Score 60}} Pass {{else}} Fail {{end}}
```

循环动作 `{{range 可迭代对象}} ... {{end}}`：用于遍历数组、切片、映射或通道。在循环体中，`{{.}}` 会被设置为当前迭代的元素。示例：

```go
{{range .Fruits}}
    {{.}} // 这里的 {{.}} 是 Fruits 中的每个元素
{{end}}

{{range .Fruits}}
    {{.}}
{{else}} 
     // 列表为空时执行（点 . 恢复为进入 {{range}} 之前的外部上下文）
{{end}}
```

在循环中可以使用 `{{break}}` 和 `{{continue}}`。

`{{with}}`：有条件地改变当前上下文（即点 `.`的值），从而在块中简化对深层字段的访问，同时也能进行空值判断。示例：

```go
{{with 表达式}}
    // 如果表达式的值不为空（非零值），则在此块内，点 . 被设置为该表达式的值
{{end}}

{{with 表达式}}
    // 表达式不为空时执行
{{else}}
    // 表达式为空时执行（点 . 恢复为进入 {{with}} 之前的外部上下文）
{{end}}

// autocorrect-disable
{{with 表达式1}}
    // 表达式1不为空时执行，则在此块内，点 . 被设置为表达式1的值
{{else with 表达式2}}
    // 表达式2不为空时执行，则在此块内，点 . 被设置为表达式2的值
{{end}}
// autocorrect-enbale
```

变量：可以使用 `{{$var := .Field}}` 在模板内定义变量，使用 `:=` 进行初始化。使用变量：`{{$var}}`。对已存在的变量重新赋值 `{{$var = 新表达式}}`，用 `=`，而非 `:=`。变量遵循块级作用域，在 `{{range}}`、`{{if}}` 等动作内部定义的变量，仅在该块中有效；在顶层（模板根部）定义的变量则是全局的。

`$` 是一个预定义的特殊变量，它始终指向传递给 `Execute()` 的根数据对象。无论你在模板的哪个位置（包括 `{{range}}`、`{{if}}` 等嵌套块中），`$` 都保持不变，可以在任意位置通过 `{{$}}` 引用整个根数据，或通过 `{{$.Field}}` 访问其字段。

管道（pipeline）：管道是一个相互连接的“命令”序列。其中的命令可以是一个简单的变量，也可以是一个函数或方法调用（可能带有参数）。使用管道字符 `|` 分隔一系列命令，从而形成链式结构。在链式管道中，每个命令的结果会被作为下一个命令的最后一个参数传递。管道中最后一个命令的输出就是该管道的值。一个命令的输出结果要么是一个值，要么是两个值，其中第二个值是 error 类型。如果第二个值存在且不为 nil，则执行终止，并将错误返回给 Execute 的调用者。

- 最简单的管道：就是一个字段或变量，如 `{{.Name}}` 或 `{{$x}}`
- 带函数的管道：如 `{{.Date | formatTime}}`

如果管道末尾没有接任何函数（例如 `{{.Name}}`），就调用 fmt.Print 输出它的值。如果管道最后接了一个函数（例如 `{{.Name | printf "%s"}}`），那就不再使用默认的 fmt.Print，而是由该函数的返回值决定输出。

空白控制 `{{-` 和 `-}}`：默认情况下，模板中的空白字符会原样输出。在左分隔符后添加一个减号和一个空格，可以修剪内容左边的空白，在右分隔符前添加一个空格和一个减号，可以修剪内容右边的空白，让模板源码更整洁。示例：

```go
// 模板：{{23 -}} < {{- 45}}
// 输出：23<45  (空白被移除)
```

内置与自定义函数：

- 模板提供了如 and、or、not、eq、ne、printf 等[内置函数](https://pkg.go.dev/text/template#hdr-Functions)
- 可以通过 [template.FuncMap](https://pkg.go.dev/text/template#FuncMap) 注册自定义函数扩展模板能力，社区流行的 [Sprig](https://github.com/Masterminds/sprig/) 库就提供了超过 100 个常用函数，大大丰富了 Go 模板函数的数量

Go 模板支持嵌套，让你能够复用公共部分（如页眉、页脚）。

- 定义 (`{{define}}`)：用于定义一个命名的模板块。
- 执行 (`{{template}}`)：用于在模板中调用另一个已定义的模板

```go
// layout.tmpl
{{define "layout"}}
<html>
<head><title>{{.Title}}</title></head>
<body>
    {{template "content" .}} // 调用 "content" 模板，并传入当前数据
</body>
</html>
{{end}}

// content.tmpl
{{define "content"}}
    <h1>Hello, {{.User}}!</h1>
{{end}}
```

### text/template 包的使用

创建模板：[func New(name string) *Template](https://pkg.go.dev/text/template#New)，返回一个具有给定名称的新创建的模板（未定义），用于解析和执行。

解析模板：使用 Parse()、ParseFiles() 或 ParseGlob() 方法解析模板字符串或文件。

- [func (t *Template) Parse(text string) (*Template, error)](https://pkg.go.dev/text/template#Template.Parse)：将模板文本 text 解析为 t 的模板主体
- [func (t *Template) ParseFiles(filenames ...string) (*Template, error)](https://pkg.go.dev/text/template#Template.ParseFiles)：解析指定的文件，并将解析结果模板与 t 关联起来
- [func (t *Template) ParseGlob(pattern string) (*Template, error)](https://pkg.go.dev/text/template#Template.ParseGlob)：解析模式所识别的文件中的模板定义，并将解析结果模板与 t 关联起来
- [func (t *Template) ParseFS(fsys fs.FS, patterns ...string) (*Template, error)](https://pkg.go.dev/text/template#Template.ParseFS)：读取的是 fsys 文件系统而不是主机操作系统的文件系统。它接受一个 glob 模式列表，大多数文件名本身就是 glob 模式，仅匹配自身

处理错误：强烈建议使用 [func Must(t *Template, err error) *Template](https://pkg.go.dev/text/template#Must) 函数包裹解析操作，这样在模板语法错误时能直接 panic，避免后续使用无效模板。

`var t = template.Must(template.New("name").Parse("text"))`

执行模板：调用 Execute() 或 ExecuteTemplate() 方法，传入输出目标（如 os.Stdout 或 http.ResponseWriter）和数据，完成渲染。

- [func (t *Template) Execute(wr io.Writer, data any) error](https://pkg.go.dev/text/template#Template.Execute)：将解析后的模板应用于指定的数据对象 data，并将输出写入 wr
- [func (t *Template) ExecuteTemplate(wr io.Writer, name string, data any) error](https://pkg.go.dev/text/template#Template.ExecuteTemplate)：将与对象 t 关联的、具有给定名称的模板应用于指定的数据对象，并将输出写入 wr

```go
import (
 "log/slog"
 "os"
 "text/template"
 "time"
)

type IssuesSearchResult struct {
 TotalCount int
 Items      []*Issue
}

type Issue struct {
 Number    int
 Title     string
 User      *User
 CreatedAt time.Time
}

type User struct {
 Login string
}

func main() {
 // 模板中 {{range .Items}} 和 {{end}} 对应一个循环 action，
 // 在 Title 这一行的 action 中，第二个操作是一个 printf 函数，是一个基于 fmt.Sprintf 实现的内置函数，所有模板都可以直接使用。
 const tmpl = `{{.TotalCount}} issues:
{{range .Items}}----------------------------------------
Number: {{.Number}}
User:   {{.User.Login}}
Title:  {{.Title | printf "%.64s"}}
Age:    {{.CreatedAt | daysAgo}} days
{{end}}`

 // template.New 创建并返回一个模板；Funcs 方法将 daysAgo 等自定义函数注册到模板中，并返回模板；最后调用 Parse 函数解析模板。
 t := template.Must(template.New("issuelist").
  Funcs(template.FuncMap{"daysAgo": daysAgo}).
  Parse(tmpl))

 data := IssuesSearchResult{
  TotalCount: 3, // 字段必须是大写导出的，否则模板中无法访问
  Items: []*Issue{
   {
    Number: 1,
    Title:  "Issue 1",
    User: &User{
     Login: "user1",
    },
    CreatedAt: time.Now().AddDate(0, 0, -10),
   },
   {
    Number: 2,
    Title:  "Issue 2",
    User: &User{
     Login: "user2",
    },
    CreatedAt: time.Now().AddDate(0, 0, -20),
   },
   {
    Number: 3,
    Title:  "Issue 3&<", // html 模板会进行转义，text 模板不会转义
    User: &User{
     Login: "user3",
    },
    CreatedAt: time.Now().AddDate(0, 0, -30),
   },
  },
 }

 if err := t.Execute(os.Stdout, data); err != nil {
  slog.Error("t.Execute", "err", err)
 }
}

func daysAgo(t time.Time) int {
 return int(time.Since(t).Hours() / 24)
}
```

### html/template 包的使用

html/template 与 text/template 的 API 相同，但会对模板输出的字符串进行上下文感知的自动转义（HTML、JS、CSS、URL），从而防止 XSS 注入等安全攻击。注意示例中 Title 为 `"Issue 3&<"` 的数据会被转义为 `Issue 3&amp;&lt;`。

```go
import (
 "html/template"
 "log/slog"
 "os"
 "time"
)

type IssuesSearchResult struct {
 TotalCount int
 Items      []*Issue
}

type Issue struct {
 Number    int
 Title     string
 User      *User
 CreatedAt time.Time
}

type User struct {
 Login string
}

func main() {
 const tmpl = `
<h1>{{.TotalCount}} issues</h1>
<table>
<tr style='text-align: left'>
  <th>#</th>
  <th>User</th>
  <th>Title</th>
</tr>
{{range .Items}}
<tr>
  <td><a href='https://www.baidu.com'>{{.Number}}</a></td>
  <td><a href='https://www.baidu.com'>{{.User.Login}}</a></td>
  <td><a href='https://www.baidu.com'>{{.Title}}</a></td>
</tr>
{{end}}
</table>
`
 t := template.Must(template.New("issuelist").Parse(tmpl))

 data := IssuesSearchResult{
  TotalCount: 2,
  Items: []*Issue{
   {
    Number: 1,
    Title:  "Issue 1",
    User: &User{
     Login: "user1",
    },
    CreatedAt: time.Now().AddDate(0, 0, -10),
   },
   {
    Number: 2,
    Title:  "Issue 2",
    User: &User{
     Login: "user2",
    },
    CreatedAt: time.Now().AddDate(0, 0, -20),
   },
   {
    Number: 3,
    Title:  "Issue 3&<", // html 模板会进行转义，text 模板不会转义  <td><a href='https://www.baidu.com'>Issue 3&amp;&lt;</a></td>
    User: &User{
     Login: "user3",
    },
    CreatedAt: time.Now().AddDate(0, 0, -30),
   },
  },
 }

 if err := t.Execute(os.Stdout, data); err != nil {
  slog.Error("t.Execute", "err", err)
 }
}
```

可以对信任的 HTML 字符串使用 template.HTML 类型抑制自动转义，给 html/template 一个“安全信号”——这是可信内容，不要转义。

- template.HTML 类型：表示可信的 HTML 字符串，例如富文本
- template.JS 类型：表示可信的 JavaScript 代码片段
- template.CSS 类型：表示可信的 CSS 代码片段
- template.URL 类型：表示可信的 URL 字符串

```go
import (
 "html/template"
 "log/slog"
 "os"
)

func main() {
 const templ = `<p>A: {{.A}}</p><p>B: {{.B}}</p>`
 t := template.Must(template.New("escape").Parse(templ))
 var data struct {
  A string        // 不受信任的纯文本，会被转义
  B template.HTML // 受信任的 HTML，不会转义
 }
 data.A = "<b>Hello!</b>"
 data.B = "<b>Hello!</b>"
 if err := t.Execute(os.Stdout, data); err != nil {
  slog.Error("t.Execute", "err", err)
 }
}

// <p>A: &lt;b&gt;Hello!&lt;/b&gt;</p><p>B: <b>Hello!</b></p>h
// 可以看到 A 的黑体标记被转义失效了，但是 B 没有。
```

### 注意事项

- 分离逻辑与表现：模板应仅负责展示。，有复杂的业务逻辑和数据预处理都应在 Go 代码中完成，仅将最终结果传给模板
- 安全第一：始终为 HTML 输出选择 html/template，对于 text/template，切勿直接渲染不可信的用户输入
- 预编译模板：在程序启动时（如 `init()` 或全局变量）解析（Parse）一次模板，而不是在每个请求中解析，以提升性能

## 正则表达式

Go 标准库提供了 [regexp](https://pkg.go.dev/regexp#pkg-overview) 包，用于处理正则表达式匹配。

推荐使用反引号（原始字符串字面量）包裹正则表达式，避免反斜杠转义问题。

使用正则表达式的第一步，是编译（Compile）模式，生成一个可复用的 Regexp 对象：

- [func Compile(expr string) (*Regexp, error)](https://pkg.go.dev/regexp#Compile)
 和 [func MustCompile(str string) *Regexp](https://pkg.go.dev/regexp#MustCompile)：用于编译正则表达式。Compile 返回一个可复用的 `*Regexp` 对象和一个错误（如果模式语法有误），而 MustCompile 在 compile 失败时会直接引发 panic

Regexp 对象是并发安全的，可以在多个协程中并发访问（但 Longest 等配置方法除外）。

常用匹配与查找方法：

- [func MatchString(pattern string, s string) (matched bool, err error)](https://pkg.go.dev/regexp#MatchString)：检查字符串是否匹配模式，返回 bool
- [func (re *Regexp) FindString(s string) string](https://pkg.go.dev/regexp#Regexp.FindString)：返回第一个匹配的字符串，如果是空匹配（empty match）或没有匹配，则返回空字符串
- [func (re *Regexp) FindAllString(s string, n int) []string](https://pkg.go.dev/regexp#Regexp.FindAllString)：返回所有匹配的字符串切片，第二个参数 n 限制匹配数量（最多返回 n 个匹配），-1 表示全部
- [func (re *Regexp) FindStringIndex(s string) (m []int)](https://pkg.go.dev/regexp#Regexp.FindStringIndex)：返回第一个匹配的起始和结束索引（左闭右开），如果没有匹配则返回 nil
- [func (re *Regexp) FindAllStringIndex(s string, n int) [][]int](https://pkg.go.dev/regexp#Regexp.FindAllStringIndex)
- [func (re *Regexp) FindStringSubmatch(s string) []string](https://pkg.go.dev/regexp#Regexp.FindStringSubmatch)：返回一个切片，包含第一个匹配的完整文本及所有捕获组（括号子表达式）的文本，完整匹配结果就是 result[0]，第一个子匹配结果则是 result[1]，以此类推。如果没有匹配则返回 nil
- [func (re *Regexp) FindAllStringSubmatch(s string, n int) [][]string](https://pkg.go.dev/regexp#Regexp.FindAllStringSubmatch)
- [func (re *Regexp) FindStringSubmatchIndex(s string) []int](https://pkg.go.dev/regexp#Regexp.FindStringSubmatchIndex)：返回第一个匹配及所有捕获组的起始和结束索引对，完整匹配结果为 s[m[0]:m[1]]，第一个子匹配结果为 s[m[2]:m[3]]，依此类推。如果没有匹配则返回 nil
- [func (re *Regexp) FindAllStringSubmatchIndex(s string, n int) [][]int](https://pkg.go.dev/regexp#Regexp.FindAllStringSubmatchIndex)

Expand 匹配结果：

- [func (re *Regexp) Expand(dst []byte, template []byte, src []byte, match []int) []byte](https://pkg.go.dev/regexp#Regexp.Expand)：基于正则匹配到的“位置索引”match 从 src 中提取匹配结果，并按照自定义的模板 template“重组”成一个新的字节切片 dst 并返回这个 dst。template 中可以包含普通的文本和 `$name` 这样的特殊变量，模板中的变量有两种写法：`$name` 或 `${name}`，其中 name 可以是：

  - 纯数字（如 `$1`）：代表第几个捕获组（下标从 1 开始）
  - 命名捕获组（如 `$user`）：对应正则中 (`?P<user>...`) 定义的名称

替换、分割操作：

- [func (re *Regexp) ReplaceAllString(src, repl string) string](https://pkg.go.dev/regexp#Regexp.ReplaceAllString)：将所有匹配的子串替换为指定的替换文本 repl，repl 中的 `$1`、`${name}` 等会被展开为捕获组内容，返回一个新字符串
- [func (re *Regexp) ReplaceAllLiteralString(src, repl string) string](https://pkg.go.dev/regexp#Regexp.ReplaceAllLiteralString)：同上，但 repl 中的 `$1`、`${name}`会被当作字面量处理，不会被展开为捕获组内容
- [func (re *Regexp) ReplaceAllStringFunc(src string, repl func(string) string) string](https://pkg.go.dev/regexp#Regexp.ReplaceAllStringFunc)：将所有匹配的子串传递给一个函数，用其返回值进行替换，返回一个新字符串
- [func (re *Regexp) Split(s string, n int) []string](https://pkg.go.dev/regexp#Regexp.Split)：按正则表达式匹配结果来分割字符串，相比于 strings.Split，它支持更复杂的、基于模式的分隔规则。第二个参数 n 用于控制分割的次数和返回切片中元素的数量，n > 0: 返回最多 n 个子字符串，最后一个子字符串包含剩余未分割的部分；n == 0: 返回一个空切片 ([]string{})；n < 0: 返回所有子字符串，不限制数量

```go
func main() {
 // 匹配一个或多个逗号、分号或空白字符，这是 regexp.Split 的优势所在，可以一次按多个不同的分隔符进行分割
 re := regexp.MustCompile(`[,;\s]+`)
 text := "apple,banana; cherry date;elderberry"
 parts := re.Split(text, -1)
 for _, part := range parts {
  fmt.Println(part)
 }
}

// 输出：
// apple
// banana
// cherry
// date
// elderberry
```

对于 []byte 类型，可以使用不带 `String` 的对应方法，例如：[func (re *Regexp) Find(b []byte) []byte](https://pkg.go.dev/regexp#Regexp.Find)。

### 基本语法

Go 正则表达式使用 RE2 引擎，语法与 Perl、Python 类似，文档：<https://pkg.go.dev/regexp/syntax>。

元字符：`. ^ $ * + ? { } [ ] \ | ( )`，要匹配它们本身，需要用反斜杠转义，如 `\.`

- 小括号表示分组或标志，中括号表示一组字符，大括号表示重复次数
- `.`：匹配任意一个字符（除换行符 `\n`）
- `^`：匹配字符串的开头
- `$`：匹配字符串的结尾
- `\`：转义符
- `|`：逻辑或，`x|y` 表示匹配 x 或 y

字面量精确匹配：`abc` 精确匹配 "abc"

字符类：

- `[xyz]`: 匹配 x、y 或 z 中的任意一个字符
- `[^xyz]`: 匹配除 x、y、z 之外的任意一个字符
- `\d`: 匹配一个数字，等价于 `[0-9]`
- `\D`：与 `\d` 相反
- `\w`：匹配一个 Unicode 字母（大写、小写均可）、数字或下划线
- `\W`：与 `\w` 相反
- `\s`：匹配一个空白字符（空格、制表符 `\t`、回车 `\r`、换行 `\n`、换页 `\f`、垂直制表符 `\v`）
- `\S`：与 `\s` 相反
- `\b`：匹配单词边界（\w 和 \W 之间的位置）
- `\B`：与 `\b` 相反

量词（重复次数）：
  
- `*`: 0 次或多次（贪婪），表示前面的字符出现 0 次或多次
- `+`: 1 次或多次（贪婪），表示前面的字符出现 1 次或多次
- `?`: 0 次或 1 次（贪婪），表示前面的字符出现 0 次或 1 次
- `{n}`：恰好 n 次，表示前面的字符恰好出现 n 次
- `{n,}`：至少 n 次，表示前面的字符至少出现 n 次
- `{n,m}`: 至少 n 次，至多 m 次（贪婪），表示前面的字符至少出现 n 次，至多出现 m 次
- 在量词后加 `?` 变为**非贪婪（惰性）**匹配，如 `*?`、`+?`

贪婪和非贪婪是量词匹配的两种模式，区别在于：

- 贪婪：匹配尽可能多的字符
- 非贪婪：匹配尽可能少的字符

```go
func main() {
 {
  s := "<a>123</a>"

  re1 := regexp.MustCompile(`<.+>`) // 贪婪
  fmt.Println(re1.FindString(s))    // <a>123</a>

  re2 := regexp.MustCompile(`<.+?>`) // ? 非贪婪
  fmt.Println(re2.FindString(s))     // <a>
 }

 {
  s := "aXXXXbXXXXb"
  re1 := regexp.MustCompile(`a.*b`) // 贪婪
  fmt.Println(re1.FindString(s))    // aXXXXbXXXXb

  re2 := regexp.MustCompile(`a.*?b`) // 非贪婪
  fmt.Println(re2.FindString(s))     // aXXXXb
 }

 {
  re1 := regexp.MustCompile(`a{2,4}`)                       // 贪婪
  fmt.Println(re1.FindAllString("a aa aaa aaaa aaaaa", -1)) // [aa aaa aaaa aaaa]，匹配次数：2、3、4、4（aaaaa 中被匹配了前 4 个 a，剩下的 1 个 a 不满足条件）

  re2 := regexp.MustCompile(`a{2,4}?`)                      // 非贪婪
  fmt.Println(re2.FindAllString("a aa aaa aaaa aaaaa", -1)) // [aa aa aa aa aa aa]，匹配次数：2、2、2、2、2、2
 }
}
```

### 捕获组语法

捕获组在正则表达式中有三个核心作用：

1. 从匹配结果中提取子串
2. 在替换文本中用 `$1`、`${name}` 引用捕获内容
3. 对一组字符整体应用量词，而不只是对前一个字符

语法：

- `(...)`: 编号捕获组，按左括号出现的顺序从 1 开始编号，FindStringSubmatch 返回切片中按编号排列。适合简单正则，通过索引访问子匹配，注意：增删捕获组时索引可能变化
- `(?P<name>...)`: 命名捕获组，通过名称引用，可用 SubexpNames() 获取名称列表，SubexpIndex(name) 获取索引。适合复杂正则，通过名称访问子匹配，名称比索引更易读
- `(?:...)`: 非捕获组，明确表达这只是一个分组，不是捕获组，不占用编号、不保存匹配内容。可对分组应用量词，如 `(?:...){2,4}`，表示对分组至少匹配 2 次，至多匹配 4 次

相关方法：

- [func (re *Regexp) NumSubexp() int](https://pkg.go.dev/regexp#Regexp.NumSubexp)：返回正则表达式中包含的括号内子表达式的数量
- [func (re *Regexp) SubexpNames() []string](https://pkg.go.dev/regexp#Regexp.SubexpNames)：返回正则表达式中各括号内的子表达式的名称。第一个子表达式的名称为 names[1]；因此，如果 m 是一个匹配结果，那么 m[i] 对应的名称就是 SubexpNames()[i]。由于整个正则表达式本身无法被赋予名称，因此 names[0] 始终为空字符串
- [func (re *Regexp) SubexpIndex(name string) int](https://pkg.go.dev/regexp#Regexp.SubexpIndex)：返回具有指定名称的第一个子表达式的索引值；如果不存在该名称的子表达式，则返回 -1

```go
func main() {
 {
  // 编号捕获组，从 1 开始编号
  re1 := regexp.MustCompile(`(\w+)@(\w+\.\w+)`)
  match := re1.FindStringSubmatch("user@example.com")
  fmt.Println(match) // [user@example.com user example.com]
  // match[0] = "user@example.com" (完整匹配)
  // match[1] = "user"             (第 1 个捕获组)
  // match[2] = "example.com"      (第 2 个捕获组)
  fmt.Println(match[0]) // user@example.com 完整匹配
  fmt.Println(match[1]) // user         第 1 个捕获组
  fmt.Println(match[2]) // example.com  第 2 个捕获组

  // 脱敏手机号（中间 4 位替换 *）
  re2 := regexp.MustCompile(`^(\d{3})\d{4}(\d{4})$`)
  fmt.Println(re2.ReplaceAllString("13800138000", "$1****$2")) // 138****8000，$1 表示第 1 个捕获组，$2 表示第 2 个捕获组
 }

 {
  // 命名捕获组，尖括号中的是组名
  re1 := regexp.MustCompile(`(?P<name>\w+)@(?P<domain>\w+\.\w+)`)
  names := re1.SubexpNames()
  for _, name := range names {
   fmt.Printf("%q\n", name) // ""   "name"   "domain"
  }
  match := re1.FindStringSubmatch("user@example.com")
  // 通过名字获取捕获组内容
  fmt.Println(match[re1.SubexpIndex("name")])   // user
  fmt.Println(match[re1.SubexpIndex("domain")]) // example.com

  // 命名捕获组：解析日期
  re2 := regexp.MustCompile(`(?P<year>\d{4})-(?P<month>\d{2})-(?P<day>\d{2})`)
  match = re2.FindStringSubmatch("2024-03-15")
  names = re2.SubexpNames()
  for i, name := range names {
   if i > 0 { // 0 是完整匹配
    fmt.Printf("%s: %s\n", name, match[i]) // year: 2024   month: 03   day: 15
   }
  }
 }

 {
  // 非捕获组，只是一个分组
  re := regexp.MustCompile(`(?:\d{4}-){3}\d{4}`)
  fmt.Println(re.FindString("1234-5678-9012-3456")) // 1234-5678-9012-3456
 }
}
```

### 模式标志（flags）

模式标志（flags）用于改变正则表达式的匹配行为，放在表达式最前面，格式为 `(?flag)`，可组合使用如 `(?mi)`。

| 标志 | 作用 | 默认行为 | 对比 |
| --- | --- | --- | --- |
| `(?i)` | 忽略大小写 | 大小写敏感 | `(?i)go` 匹配`Go`、`GO`、`go` |
| `(?m)` | 多行模式：`^`、`$` 分别匹配每行的行首、行尾 | `^`、`$` 只匹配整个文本的首尾 | `(?m)^\d+` 能匹配文本中间行开头的数字 |
| `(?s)` | 单行模式：`.` 也匹配换行符 `\n` | `.` 不匹配换行符 | `(?s)a.*b` 可以跨行匹配 `a...\n...b` |
| `(?U)` | 交换贪婪：`*` 变非贪婪，`*?` 变贪婪 | `*` 贪婪，`*?` 非贪婪 | 很少用，通常直接写 `*?` 更直观 |
| `(?x)` | 忽略模式中的空白字符和 `#` 注释 | 空白字符和 `#` 是字面量 | 让复杂正则分行写、加注释，提高可读性 |

```go
func main() {
 re := regexp.MustCompile(`(?i)go`)
 fmt.Println(re.MatchString("GO")) // true

 {
  text := "abc\n123\nxyz"

  // 无 (?m)：^ 只匹配整个字符串开头
  re1 := regexp.MustCompile(`^\d+`)
  fmt.Println(re1.FindString(text)) // ""（没匹配到，开头是 abc）

  // 有 (?m)：^ 匹配每一行开头
  re2 := regexp.MustCompile(`(?m)^\d+`)
  fmt.Println(re2.FindString(text)) // "123"（匹配到第二行开头）
 }

 {
  // 多行 + 忽略大小写
  re := regexp.MustCompile(`(?mi)^[a-z]+`)
  fmt.Println(re.FindAllString("abc\nDEF\nGhi", -1)) // ["abc", "DEF", "Ghi"]
 }
}
```

### 不支持的语法

Go 正则表达式不支持：

- 反向引用（backreference）：`\1`,`\2` 等
- 环视断言：`(?=...)` 正向先行、`(?!...)` 负向先行、`(?<=...)` 正向后行、`(?<!...)` 负向后行
- 回溯依赖的某些高级语法

### GLOB vs 正则表达式

| 对比项 | GLOB 模式 | 正则表达式 |
| -- | -- | -- |
| 设计用途 | 匹配文件路径 | 匹配文本字符串 |
| `*` 的含义 | 匹配任意字符（不包括路径分隔符） | 量词，表示前面的元素重复 0 次或多次 |
| `.` 的含义 | 匹配字面量点号 `.` | 匹配任意单个字符（除换行符） |
| 斜杠处理 | 通常自动处理 OS 差异（Windows 转义） | 需手动写 `\/` 或 `\\` |
| 复杂度 | 简单、易读 | 强大、难读 |

> [!NOTE]
> 在 shell 里敲的 `*.txt` 就是标准 GLOB，在代码里写的 `^.*\.txt$` 是正则。

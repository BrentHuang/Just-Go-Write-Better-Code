# 第八部分 错误处理与高级特性

## 概览

本部分涵盖 Go 语言的错误处理、泛型编程、反射、随机数、Glob 模式匹配、模板引擎和正则表达式。这些特性使 Go 在处理复杂业务逻辑时更加灵活和强大。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 错误处理](01错误处理.md) | `error` 类型、错误包装与检查、多错误合并 | 掌握惯用的错误处理方式 |
| [02 泛型编程](02泛型编程.md) | 类型参数、类型约束、泛型函数与泛型类型 | 编写类型安全、可复用的泛型代码 |
| [03 反射](03反射.md) | `reflect` 包、`reflect.Value` 与 `reflect.Type`、动态操作 | 理解反射的工作原理，在需要时使用反射 |
| [04 rand 随机数](04rand随机数.md) | `math/rand` 包、伪随机数生成器、种子与并发安全 | 正确使用随机数生成器 |
| [Glob 模式匹配](glob模式匹配.md) | `path` 与 `path/filepath` 包的 Glob 匹配、通配符使用 | 利用 glob 模式进行文件路径匹配 |

| [正则表达式](正则表达式.md) | `regexp` 包、正则表达式语法、匹配与替换 | 熟练使用正则表达式处理文本模式匹配 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第七部分（方法与接口），泛型、反射等功能建立在接口知识的基础上。
- 错误处理建议优先学习，是所有后续章节的基础。
- 泛型编程涉及 Go 1.18+ 新特性，理解接口约束是泛型的核心。
- 反射属于高级特性，适合在熟悉基础语法后学习。

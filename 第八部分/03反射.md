## 反射（reflection）

反射允许程序在运行时检查类型信息、修改变量值、调用方法等。由标准库中的 [reflect](https://pkg.go.dev/reflect) 包提供支持，是许多高级功能（如 JSON 序列化、ORM、依赖注入、RPC 框架等）的基石。

- [reflect.Type](https://pkg.go.dev/reflect#Type) 是一个接口类型，表示 Go 类型的运行时描述符，通过 [func TypeOf(i any) Type](https://pkg.go.dev/reflect#TypeOf) 获取 i 的 reflect.Type，记为 t
- [reflect.Value](https://pkg.go.dev/reflect#Value) 表示值的反射对象，可以读取或修改它，通过 [func ValueOf(i any) Value](https://pkg.go.dev/reflect#ValueOf) 获取 i 的 reflect.Value，记为 v，[func (v Value) Type() Type](https://pkg.go.dev/reflect#Value.Type) 返回一个 reflect.Type, [func (v Value) Kind() Kind](https://pkg.go.dev/reflect#Value.Kind) 返回一个 reflect.Kind, [func (v Value) CanAddr() bool](https://pkg.go.dev/reflect#Value.CanAddr) 判断其是否可以被取地址
- [reflect.Kind](https://pkg.go.dev/reflect#Kind)：Type 的 Kind 属性，如 reflect.Int、reflect.Struct、reflect.Map 等

Type 告诉你"有什么字段、叫什么、什么类型、tag 是什么"，是静态结构；Value 告诉你"每个字段里现在装的是什么数据"，是动态内容。

### 获取类型信息

- Type.Kind()：返回底层类型 Kind
- Type.Name()：返回类型名称（如 "MyStruct"），自定义结构体才有名称，内置类型如 int/string 有名称；指针、切片、映射的名称为空
- Type.NumField() / Field(i)：获取结构体字段信息
- Type.NumMethod() / Method(i)：获取方法信息

```go
func main() {
 var f float64 = 3.14

 // 获取类型
 t := reflect.TypeOf(f)
 fmt.Printf("Type: %v\n", t)        // Type: float64
 fmt.Printf("Kind: %v\n", t.Kind()) // Kind: float64

 // 获取值
 v := reflect.ValueOf(f)
 fmt.Printf("Value: %v\n", v)       // Value: 3.14
 fmt.Printf("Type: %v\n", v.Type()) // Type: float64
 fmt.Printf("Kind: %v\n", v.Kind()) // Kind: float64
 if v.Kind() == reflect.Float64 {
  fmt.Printf("Float: %v\n", v.Float()) // Float: 3.14
 }

 // 结构体反射（最常用场景）
 type Person struct {
  Name string `json:"name"`
  Age  int
 }

 p := Person{Name: "Alice", Age: 30}
 t = reflect.TypeOf(p)
 for field := range t.Fields() {
  fmt.Printf("%q %q %q\n", field.Name, field.Type, field.Tag.Get("json")) // "Name" "string" "name"   "Age" "int" ""
 }

 nameField, ok := t.FieldByName("Name")
 if ok { // true
  fmt.Printf("%q %q %q\n", nameField.Type, nameField.Name, nameField.Tag.Get("json")) // "string" "Name" "name"
 }
}
```

### 类型 Kind 枚举

```go
func checkKind(i any) {
 v := reflect.ValueOf(i)
 switch v.Kind() {
 case reflect.Bool:
  fmt.Printf("布尔值：%t\n", v.Bool())
 case reflect.Int:
  fmt.Printf("整数：%d\n", v.Int())
 case reflect.Float64:
  fmt.Printf("浮点数：%f\n", v.Float())
 case reflect.String:
  fmt.Printf("字符串：%s\n", v.String())
 case reflect.Struct:
  fmt.Printf("结构体：%v\n", v.Type())
 case reflect.Array:
  fmt.Printf("数组：%v\n", v.Type())
 case reflect.Slice:
  fmt.Printf("切片：%v\n", v.Type())
 case reflect.Map:
  fmt.Printf("映射：%v\n", v.Type())
 case reflect.Pointer:
  fmt.Printf("指针：%p\n", v.Type())
 case reflect.Interface:
  fmt.Printf("接口：%v\n", v.Type())
 case reflect.Func:
  fmt.Printf("函数：%v\n", v.Type())
 case reflect.Chan:
  fmt.Printf("通道：%v\n", v.Type())
 case reflect.Uintptr:
  fmt.Printf("uintptr：%v\n", v.Type())
 default:
  fmt.Printf("其它类型：%v\n", v.Kind())
 }
}
```

### 读取和设置值

- [func (v Value) Interface() (i any)](https://pkg.go.dev/reflect#Value.Interface)：将 reflect.Value 恢复为 interface{}
- [func (v Value) Kind() Kind](https://pkg.go.dev/reflect#Value.Kind)：类似于 Type.Kind()，返回 v 的 Kind 属性
- [func (v Value) Field(i int) Value](https://pkg.go.dev/reflect#Value.Field)：返回结构体的第 i 个字段
- [func (v Value) FieldByName(name string) Value](https://pkg.go.dev/reflect#Value.FieldByName)：返回指定名字的结构体字段
- [func (v Value) Int() int64](https://pkg.go.dev/reflect#Value.Int)：返回 v 的底层值，这里是整数类型，另有 Float()、Bool()、String() 等方法
- [func (v Value) SetInt(x int64)](https://pkg.go.dev/reflect#Value.SetInt)：修改值，需满足可设置性（`CanSet()` 为 true）。这里为整数类型，另有 SetFloat()、SetBool()、SetString() 等方法
- [func (v Value) Elem() Value](https://pkg.go.dev/reflect#Value.Elem)：专门用来解开两种“包装”类型：
  - 接口（Interface）：剥开 interface{} 的外壳，拿到里面装着的具体值
  - 指针（Pointer）：顺着内存地址，拿到指向的那个实际变量

reflect.ValueOf 拿到的是值拷贝，所有通过 reflect.ValueOf(i) 返回的 reflect.Value 都是不可取地址的。要想修改原变量必须传指针，再调用 Elem() 解引用，即通过调用 `reflect.ValueOf(&i).Elem()`，来获取任意变量 i 对应的可取地址的 Value。

```go
func main() {
 var x float64 = 3.14

 // 错误方式：无法修改
 // v := reflect.ValueOf(x)
 // v.SetFloat(6.28) // panic: reflect.Value.SetFloat using unaddressable value

 // 正确方式：使用指针
 v := reflect.ValueOf(&x).Elem() // Elem() 获取指针指向的值
 if v.CanSet() {
  v.SetFloat(6.28)
  fmt.Printf("修改后的 x: %f\n", x) // 6.28
 }

 // 修改结构体字段
 type Person struct {
  Name string
  Age  int
 }

 p := Person{Name: "Alice", Age: 20}
 fmt.Printf("修改前：%+v\n", p) // {Name:Alice Age:20}
 v = reflect.ValueOf(p)
 for _, field := range v.Fields() {
  switch field.Kind() {
  case reflect.String:
   fmt.Printf("字符串：%s\n", field.String())
  case reflect.Int:
   fmt.Printf("整数：%d\n", field.Int())
  }
 }

 vp := reflect.ValueOf(&p).Elem()
 nameField := vp.FieldByName("Name")
 if nameField.CanSet() { // 结构体字段首字母大写对外导出才行，小写无法反射读写（CanSet=false）
  nameField.SetString("Bob")
 }

 ageField := vp.FieldByName("Age")
 if ageField.CanSet() {
  ageField.SetInt(25)
 }

 fmt.Printf("修改后：%+v\n", p) // {Name:Bob Age:25}
}
```

### 调用方法

通过反射调用方法需先获取方法 Value，然后调用 Call 传入参数。

```go
func add(a, b int) int {
 return a + b
}

type MyStruct struct{}

func (m MyStruct) Hello(name string) string {
 return "Hello, " + name
}

func main() {
 // 普通函数反射调用
 fn := reflect.ValueOf(add)
 // 构造参数切片 []reflect.Value
 args := []reflect.Value{reflect.ValueOf(10), reflect.ValueOf(20)}
 // 调用函数
 result := fn.Call(args)
 // 获取返回值
 fmt.Println(result[0].Int()) // 30

 // 结构体方法反射调用
 s := MyStruct{}
 v := reflect.ValueOf(s)
 method := v.MethodByName("Hello")
 args = []reflect.Value{reflect.ValueOf("World")}
 result = method.Call(args)
 fmt.Println(result[0].String()) // Hello, World
}
```

## 泛型编程

泛型编程（Generic Programming）是一种编程范式，核心思想是用类型参数（type parameters）编写代码，让同一段逻辑能够适用于多种类型，而不需要为每种类型重复编写相似的代码。

### 泛型函数

泛型函数是包含类型参数的函数，泛型函数的类型参数位于函数名和函数参数列表之间的方括号 `[]` 中（其他语言如 Java/C++/C# 通常使用尖括号 `<>`），语法：

`func Index[T comparable](s []T, x T) int`，s 是满足约束 comparable 的任何类型 T 的切片，x 是 T 类型的值。

```go
// Index 返回 x 在 s 中的索引，未找到则返回 -1
func Index[T comparable](s []T, x T) int {
 for i, v := range s {
  if v == x {
   return i
  }
 }
 return -1
}
```

comparable 是一个内置约束，表示 T 必须是可比较的类型。另一个内置约束是 any，`[T any]` 表示 T 可以是任何类型。comparable 和 any 都是接口，但 comparable 接口只能用于类型参数约束，不能用作变量类型。

类型参数命名通常使用大写字母 T、K、V、E 等

- T：Type，通用类型，例如 `func F[T any](t T)`
- K：Key，键类型，例如 `func Set[K comparable, V any](m map[K]V, k K, v V)`
- V：Value，值类型
- E：Element，元素类型，例如 `func Find[E any](s []E, e E)`
- R：Result，返回类型，例如 `func Map[T, R any](s []T, f func(T) R) []R`

可以定义多个类型参数，如 `[K comparable, V any]`。

不要过度使用泛型。先编写具体类型的代码，当确认需要处理多种类型且逻辑完全相同时，再重构为泛型。

### 自定义约束

可以自定义约束，自定义约束的核心在于理解接口中可以包含的两种元素：

- 方法元素：接口中定义了一组方法集。当这样的接口作为类型参数时，表示只有实现了该接口的类型才可以特化
- 类型元素：使用 `|` 运算符组合多个允许的类型（“或”的关系），例如 `~int | float64`，int 前的 `~` 表示近似约束，允许底层类型为 int 所有类型，例如 `type MyInt int` 自定义类型 MyInt 也满足此约束。当这样的接口作为类型参数约束时，表示只有属于这些类型之一的类型才可以特化

包含了类型元素（或嵌入了包含类型元素的接口）的接口称为“非基本接口类型”。这种接口只能用作类型参数的约束，而不能像传统接口那样声明变量（编译报错）。

约束的接口名应能清晰表达其限定的类型范围或行为，例如 Number、Stringable、Cloner 等。

```go
// 只允许 int 或 float64 类型
type Numeric interface {
    ~int | float64
}
```

可以组合类型元素和方法元素，创建更强大的约束，要求类型同时满足多种条件（“并”的关系）。

```go
// 类型必须可比较（comparable）且实现 String() 方法
type StringableComparable interface {
 comparable   // 嵌入内置约束，要求类型支持 == 和 !=
 fmt.Stringer // 嵌入接口，要求实现 String() 方法
}
```

过滤掉零值并输出字符串：

```go
func FilterAndStringify[T StringableComparable](s []T) []string {
 var zero T
 var result []string
 for _, v := range s {
  if v != zero { // 可比较操作是允许的
   result = append(result, v.String()) // 调用 String 方法是允许的
  }
 }
 return result
}
```

[golang.org/x/exp/constraints](https://pkg.go.dev/golang.org/x/exp/constraints) 包（实验性）提供了一些有用的预定义约束，如 constraints.Ordered（支持排序比较的类型），可以基于它们构建自己的约束。注：Go 1.21 已将 cmp.Ordered 加入了标准库 cmp 包，可以替代实验性的 constraints.Ordered。

```go
import "golang.org/x/exp/constraints"

// 定义一个要求类型为有序数值的约束
type OrderedNumeric interface {
 constraints.Integer | constraints.Float // 约束类型必须为整数或浮点数
}

// 使用示例：求最大值
func Max[T OrderedNumeric](a, b T) T {
 if a > b {
  return a
 }
 return b
}
```

### 调用泛型函数

有函数参数且可从实参推导类型，不需要显式指定类型：

```go
// Index 返回 x 在 s 中的索引，未找到则返回 -1
func Index[T comparable](s []T, x T) int {
 for i, v := range s {
  if v == x {
   return i
  }
 }
 return -1
}

func main() {
 // Index 可以在整数切片上使用
 si := []int{10, 20, 15, -10}
 fmt.Println(Index(si, 15)) // 自动推导 T = int

 // Index 也可以在字符串切片上使用
 ss := []string{"hello", "world", "go"} // 自动推导 T = string
 fmt.Println(Index(ss, "world"))
}
```

无函数参数，类型参数无法推导，需要显式指定类型：

```go
func Zero[T any]() T {
 var v T
 return v
}

func main() {
 n := Zero[int]() // 必须显式指定 T = int
 fmt.Println(n)
}
```

返回值类型无法从实参推导，需要显式指定类型：

```go
func ToType[T, R any](v T) R {
 return any(v).(R) // 仅作示意
}

func main() {
 s := ToType[int, string](42) // 必须显式指定 R = string，且必须一并指定其它所有类型（即使可从实参推导）
 fmt.Println(s)
}
```

泛型函数支持可变参数：

```go
func Sum[T int | float64](values ...T) T {
 var total T
 for _, v := range values {
  total += v
 }
 return total
}

func main() {
 fmt.Println(Sum(1, 2, 3, 4))    // 10
 fmt.Println(Sum(1.1, 2.2, 3.3)) // 6.6
}
```

### 泛型类型

除泛型函数外，Go 还支持泛型类型和泛型接口。

泛型类型允许我们定义能够容纳不同数据类型的通用数据结构，类型参数位于类型名之后的方括号 `[]` 中。使用泛型类型时，需要显式指定类型。

```go
// 协程安全的泛型映射
type SafeMap[K comparable, V any] struct {
 data  map[K]V
 mutex sync.RWMutex
}
```

泛型接收者：类型参数定义在结构体上，方法直接使用，方法自身不新增泛型参数。

```go
// List 表示通用的单链表，可以容纳任何类型的值
type List[T any] struct {
 next *List[T]
 val  T
}

func (l *List[T]) Append(val T) { // 注意方法接收者的语法，类型名之后的方括号中是类型参数（不需要跟约束）
 l.next = &List[T]{next: nil, val: val}
}

func (l *List[T]) Print() {
 p := l
 for {
  fmt.Printf("val: %v, next: %v\n", p.val, p.next)
  if p.next == nil {
   break
  }
  p = p.next
 }
}

func (l *List[T]) Len() int {
 len := 0
 p := l.next
 for {
  len++
  if p == nil {
   break
  }
  p = p.next
 }
 return len
}

// 删除第一个含有指定值的节点。需要注意，如果需要对值进行比较，类型参数 T 的约束应为 comparable 而不是 any
func (l *List[T]) Delete(val T) {
 // ...
}

func main() {
 // 值为 int 的单链表
 l := List[int]{next: nil, val: 10} // 使用泛型类型时，需要显式指定类型，这里是 int
 l.Append(20)
 l.Print()
 fmt.Println(l.Len())

 // 值为 string 的单链表
 sl := List[string]{next: nil, val: "hello"}
 sl.Append("world")
 sl.Print()
 fmt.Println(sl.Len())
}
```

### 泛型接口

泛型接口允许定义能够处理不同数据类型的通用接口，类型参数位于接口名之后的方括号 `[]` 中。与普通接口一样，实现泛型接口是隐式的，编译器通过方法签名自动推断类型参数；但声明泛型接口类型的变量时，需要显式指定类型；调用参数为泛型接口的函数时，参考“调用泛型函数”。

```go
type Processor[T any] interface {
 Process(data T) T
 Save(data T) error
}

// StringProcessor 实现了 Processor[string]，StringProcessor 不是泛型类型
type StringProcessor struct{}

func (sp StringProcessor) Process(data string) string {
 return data + " processed"
}
func (sp StringProcessor) Save(data string) error {
 fmt.Printf("Saved: %v\n", data)
 return nil
}

// IntProcessor 实现了 Processor[int]
type IntProcessor struct{}

func (ip IntProcessor) Process(data int) int {
 return data * 2
}

func (ip IntProcessor) Save(data int) error {
 fmt.Printf("Saved: %v\n", data)
 return nil
}

// 泛型接口作为函数参数
func Execute[T any](p Processor[T], data T) error {
 return p.Save(p.Process(data))
}

func main() {
 var p1 Processor[string] = StringProcessor{} // 声明泛型接口变量时，需要显式指定类型
 var p2 Processor[int] = IntProcessor{}

 p1.Save(p1.Process("hello")) // Saved: hello processed
 p2.Save(p2.Process(42))      // Saved: 84

 Execute(p1, "hello") // Saved: hello processed，调用参数为泛型接口的函数时，根据实参自动推导类型
 Execute(p2, 42)      // Saved: 84
}
```

### 泛型方法

Go 1.27 补齐了泛型最大短板：方法可以声明自己独立的类型参数，不再依赖结构体泛型参数（泛型接收者）。

```go
type Box[T any] struct {
 Val T
}

// Go 1.27：除了使用泛型接收者的类型参数 T 外，方法还可以定义新的类型参数 U
func (b Box[T]) Map[U any](fn func(T) U) Box[U] {
 return Box[U]{Val: fn(b.Val)}
}

func main() {
 intBox := Box[int]{100}

 // 调用：类型自动推断，写法干净优雅
 strBox := intBox.Map(strconv.Itoa)
 fmt.Println(strBox.Val)
}
```

泛型方法的限制：

- 接口不能定义带类型参数的泛型方法，泛型方法也不能实现接口
- 反射无法获取泛型方法

```go
type Mapper interface {
    Map[U any](fn func(int) U) Box[U] // 编译报错：接口方法不能有类型参数
}
```

```go
type Demo interface {
 Show(T any)
}

type MyInt int

func (i MyInt) Show[T any](t T) {
 fmt.Println(i)
}

func main() {
 var d Demo
 d = MyInt(100) // 编译报错：MyInt 类型没有实现 Show 方法
 d.Show("hello")
}
```

#### cmp 包

[cmp](https://pkg.go.dev/cmp)提供了比较相关的类型和函数。

```go
func main() {
 // cmp.Compare 比较两个值，返回 -1(小于)、0(等于)、1(大于)
 fmt.Println(cmp.Compare(1, 2)) // -1
 fmt.Println(cmp.Compare(2, 2)) // 0
 fmt.Println(cmp.Compare(3, 2)) // 1
}

// cmp.Ordered 是一个泛型约束，表示可排序的类型
// 包括：string、整数类型、浮点数类型
// 可用于泛型编程中的类型参数约束
func Max[T cmp.Ordered](a, b T) T {
 if cmp.Compare(a, b) > 0 {
  return a
 }
 return b
}
```

#### slices 包

[slices](https://pkg.go.dev/slices)提供了操作切片的通用函数，比 sort 包更通用。

```go
func main() {
 s := []int{3, 1, 2}
 fmt.Printf("原始切片：%v\n", s)

 // slices.Sort 升序排列（原地修改）
 slices.Sort(s) // s: [1 2 3]
 fmt.Printf("排序后的切片：%v\n", s)

 // slices.SortFunc 使用自定义比较函数排序
 slices.SortFunc(s, func(a, b int) int {
  return cmp.Compare(b, a) // 降序
 })
 fmt.Printf("降序排序后的切片：%v\n", s)

 // slices.Contains 判断切片是否包含某元素
 fmt.Println(slices.Contains(s, 2)) // true

 // slices.Index 返回元素首次出现的索引，-1 表示不存在
 fmt.Println(slices.Index(s, 2)) // 1

 // slices.Clone 创建切片的完整独立副本，自动分配新的底层数组，返回新切片。元素通过赋值进行复制，因此是浅拷贝
 clone := slices.Clone(s)
 fmt.Printf("克隆后的切片：%v\n", clone)

 // slices.Equal 判断两个切片是否相等
 fmt.Println(slices.Equal(s, clone)) // true

 // slices.EqualFunc 使用自定义比较函数判断
 fmt.Println(slices.EqualFunc(s, clone, func(a, b int) bool {
  return a == b
 })) // true

 // slices.Compact 压缩连续重复的元素（原地修改）
 s2 := []int{1, 1, 2, 2, 3, 2}
 s2 = slices.Compact(s2) // [1 2 3 2]
 fmt.Printf("压缩后的切片：%v\n", s2)

 // slices.Insert 在指定位置插入元素（返回新切片）
 s3 := slices.Insert(s2, 1, 99, 100) // 在索引 1 处插入 99, 100，原来的元素后移
 fmt.Printf("插入后的切片：%v\n", s3)          // [1 99 100 2 3 2]

 // slices.Delete 删除指定范围的元素（返回新切片）
 s4 := slices.Delete(s3, 1, 3) // 删除索引 1 到 2 的元素，前闭后开，后面的元素前移
 fmt.Printf("删除后的切片：%v\n", s4)    // [1 2 3 2]

 // slices.Reverse 反转切片（原地修改）
 slices.Reverse(s4)
 fmt.Printf("反转后的切片：%v\n", s4) // [2 3 2 1]

 // slices.BinarySearch 在已升序排列的切片中二分查找，返回目标值首次出现的位置，第二个返回值指示目标值是否真的存在于该切片中
 slices.Sort(s4)
 fmt.Printf("排序后的切片：%v\n", s4)               // [1 2 2 3]
 idx, found := slices.BinarySearch(s4, 2) //
 fmt.Printf("二分查找结果：%v\n", idx, found)       // idx: 1, found: true

 // slices.Grow 预分配容量（减少多次 append 时的内存分配）
 s5 := slices.Grow(s4, 100) // 预分配容量，确保容量足够再追加 100 个元素。在调用 Grow(n) 之后，至少可以再向该切片中添加 n 个元素，而无需再进行内存分配
 fmt.Printf("预分配后的切片容量：%v\n", cap(s5))
}
```

#### maps 包

[maps](https://pkg.go.dev/maps)提供了操作 Map 的通用函数。

```go
func main() {
 m := map[string]int{"a": 1, "b": 2}
 fmt.Printf("原始 Map：%v\n", m)

 // maps.Clone 返回 map 的浅拷贝
 clone := maps.Clone(m)
 fmt.Printf("克隆的 Map：%v\n", clone)

 // maps.Copy 将 src 的所有键值对复制到 dst（浅拷贝，只复制键值对的顶层映射关系，不会递归复制值。如果值是引用类型（如切片、指针、另一个 map），就能看出区别）
 dst := map[string]int{"c": 3}
 maps.Copy(dst, m) // dst: {"a":1, "b":2, "c":3}
 fmt.Printf("复制后的 Map：%v\n", dst)

 // maps.Equal 判断两个 map 是否相等（键值对完全相同）
 fmt.Println(maps.Equal(m, clone)) // true

 // maps.EqualFunc 使用自定义比较函数判断两个 map 是否相等
 fmt.Println(maps.EqualFunc(m, clone, func(v1, v2 int) bool {
  return v1 == v2
 })) // true

 // maps.Keys 返回 map 的所有 key（顺序不确定）
 keys := maps.Keys(m) // []string{"a", "b"}（顺序可能不同）
 for key := range keys {
  fmt.Println(key)
 }

 // maps.Values 返回 map 的所有 value（顺序不确定）
 values := maps.Values(m) // []int{1, 2}
 for value := range values {
  fmt.Println(value)
 }

 // maps.All 返回 map 的所有键值对（顺序不确定）
 fmt.Println(maps.All(m)) // map[string]int{ "a":1, "b":2 }

 for k, v := range maps.All(m) {
  fmt.Printf("%v: %v\n", k, v)
 }

 // maps.DeleteFunc 删除满足条件的键值对
 maps.DeleteFunc(m, func(k string, v int) bool {
  return v < 2 // 删除 value < 2 的键值对
 })
 fmt.Println(m)
}
```

### 类型特化策略

Go 泛型在编译阶段完成类型特化，运行时性能与手写特定类型代码相当。

编译策略上，最直观的做法是单态化（monomorphization）：编译器根据实际传入的具体类型，为每种类型组合生成一份独立的、类型确定的代码副本，即把“通用模板”变成“特定类型的实体函数”。但纯单态化会导致严重的二进制膨胀。

Go 实际采用的是按形状分组（GCShape stenciling）的优化方案：具有相同底层结构（大小、对齐、是否含指针）的类型归为同一 shape 组，共享同一份编译后的代码，通过运行时传递的类型字典来区分具体操作。例如所有指针类型（`*int`、`*string`、`*MyStruct`）属于同一 shape，只生成一份代码，有效缓解了二进制膨胀。因此膨胀程度取决于实际使用的类型种类数量及形状多样性，而非类型总数量。

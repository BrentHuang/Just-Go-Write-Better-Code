# 递归函数

递归函数：函数直接或间接调用自身。

一个递归函数通常包含两个关键部分：

- 基准情形（base case）：递归终止的条件，用于防止函数无限调用自身，避免发生栈溢出错误
- 递归情形（recursive case）：函数调用自身的部分，其作用是将原始问题分解为规模更小的子问题，逐步向基准情形逼近

递归函数可以解决多种数学问题，如计算阶乘、生成斐波那契数列、树/图的遍历等。

```go
// 递归函数计算阶乘
func factorial(n int) int {
 // 基准
 if n == 0 {  // 终止条件
  return 1
 }

 // 递归
 return n * factorial(n-1)
}

func main() {
 fmt.Println(factorial(5))  // 输出：120
}
```

注意：Go 不支持尾调用优化（Tail Call Optimization），即使写成尾递归形式，每次调用仍会消耗新的栈帧，不会像某些函数式语言那样被编译器优化为循环。因此对于深度较大的递归，应优先使用迭代。

## 间接递归

间接递归（互递归）同样需要每个函数都具备自己的基准情形，两个函数互相调用、逐步逼近终止条件：

```go
// 互递归：isEven 与 isOdd 相互调用
func isEven(n int) bool {
 if n == 0 { // n == 0 时：0 是偶数
  return true
 }
 return isOdd(n - 1) // 递归情形：委托给另一个函数
}

func isOdd(n int) bool {
 if n == 0 { // n == 0 时：0 不是奇数
  return false
 }
 return isEven(n - 1) // 递归情形：委托给另一个函数
}

func main() {
 fmt.Println(isEven(10)) // true
 fmt.Println(isOdd(10))  // false
 fmt.Println(isEven(11)) // false
 fmt.Println(isOdd(11))  // true
}
```

## 无限递归

无限递归导致协程栈溢出：

```go
func infiniteRecursion() {
 infiniteRecursion() // 无限递归，没有终止条件
}

func main() {
 infiniteRecursion()
}
```

运行上述程序会输出以下错误信息：

```text
runtime: goroutine stack exceeds 1000000000-byte limit
runtime: sp=0xc020160390 stack=[0xc020160000, 0xc040160000]
fatal error: stack overflow
```

协程栈的默认上限在 64 位平台为 1 GB（32 位平台为 250 MB），通常只有在深度递归或处理大量数据时才可能触发栈溢出。结合 Go 不支持尾调用优化的特点，对于递归深度较大的场景，应优先使用迭代替代递归。

## 递归函数

递归函数：函数直接或间接调用自身。

一个递归函数通常包含两个关键部分：

- 基准情形（base case）：递归终止的条件，用于防止函数无限调用自身，避免发生栈溢出错误
- 递归情形（recursive case）：函数调用自身的部分，其作用是将原始问题分解为规模更小的子问题，逐步向基准情况逼近

递归函数对于解决数学问题非常有用，像计算阶乘、生成斐波那契数列、树/图的遍历等。

```go
// 递归函数计算阶乘
func factorial(n int) int {
 // 基准
 if n == 0 {  // 终止条件
  return 1
 }

 // 递归
 return n * factorial(n-1)
}

func main() {
 fmt.Println(factorial(5))  // 输出：120
}
```

无限递归导致栈溢出：

```go
func infiniteRecursion() {
 infiniteRecursion() // 无限递归
}

func main() {
 infiniteRecursion()
}

// runtime: goroutine stack exceeds 1000000000-byte limit
// runtime: sp=0xc020160390 stack=[0xc020160000, 0xc040160000]
// fatal error: stack overflow
```

默认的 Goroutine 栈大小上限为 1 GB。这是一个非常大的限制，通常只有在深度递归或处理大量数据时才可能触发栈溢出。

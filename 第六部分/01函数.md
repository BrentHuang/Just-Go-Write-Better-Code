
## 函数

### 基本语法

```go
func 函数名(参数列表) 返回值列表 {
  // 函数体
}
```

用 `func` 关键字定义函数，可以有 0 个或多个参数（建议不超过 5 个），0 个或多个返回值。没有返回值时可省略返回值列表，也可以指定返回值的名字（命名返回值）。

```go
// 函数名为 add，有两个 int 类型的参数，有一个 int 类型的返回值
func add(a int, b int) int {  // 参数名在前，参数类型在后
 return a + b  // 一行语句结束时不需要加分号
}
```

参数名不能省略。连续多个参数类型相同时，除最后一个类型外，前面的相同类型都可以省略，命名返回值同理。

```go
func add(a, b int) int {  // 将参数 a int, b int 简写为 a, b int
 return a + b
}
```

main 函数没有参数且没有返回值。

```go
func main() {
}
```

Go 不要求函数定义在调用之前，这是与 C/C++ 的一个重要区别。

```go
// 合法：函数定义在调用之后
func main() {
 greet()  // 调用 greet，但 greet 定义在下面
}

func greet() {
 fmt.Println("Hello!")
}
```

可能偶尔遇到没有函数体的函数声明，这表示该函数不是以 Go 实现的，这样的声明定义了函数签名。

```go
package math

func Sin(x float64) float  // implemented in assembly language
```

### 可变参数函数

在参数类型前放置 `...` 表示函数可以接受任意数量的该类型参数，即可变参数（variadic），典型的例子就是 `fmt.Printf`。在函数体中部，可变参数 `args` 被当做切片处理，可以通过 `len(args)` 获取参数数量，通过 `args[index]` 访问参数。

可变参数必须是函数的最后一个参数，不允许同时存在多个可变参数。

将切片作为可变参数传递，需要在切片变量后放置 `...` 将切片展开。数组不能直接展开，需要先创建整个数组视图的切片，再对切片展开 `a[:]...`。

```go
// 0 个或多个参数的函数，参数类型都为 int
func myFunc1(args ...int) {
 fmt.Printf("len args: %d\n", len(args))
 for _, v := range args { // 这里的 v 是一个独立的副本
  fmt.Println(v)
 }
}

// 1 个或多个参数的函数，可变参数必须是最后一个参数
func myFunc2(a string, args ...int) {
 fmt.Println(a)
 fmt.Printf("len args: %d\n", len(args))
 for _, v := range args {
  fmt.Println(v)
 }
}

func sum(nums ...int) int {
 total := 0
 for _, num := range nums {
  total += num
 }
 return total
}

func main() {
 myFunc1()
 myFunc1(1, 2)
 myFunc2("hello")
 myFunc2("hello", 1, 2)

 fmt.Println(sum(1, 2, 3, 4, 5))        // 传递多个独立参数
 numbers := []int{1, 2, 3, 4, 5}
 fmt.Println(sum(numbers...))           // 在切片变量后放置 ... 将切片展开
}
```

至少有一个返回值的函数调用可以作为可变参数传递，没有返回值的函数调用不能作为可变参数传递。

```go
func main() {
 f()         // 可以传入 0 个参数
 f(g())      // g 有一个返回值，可以将 g() 调用作为 f 的参数
 // f(h())   // h 没有返回值，不能将 h() 调用作为 f 的参数，编译报错
}

func f(args ...int) {
 for _, arg := range args {
  fmt.Println(arg)
 }
}

func g() int {
 return 1
}

func h() {
}
```

不允许同时存在多个可变参数：

```go
func f(args1 ...int, args2 ...string) {  // 编译报错
}
```

在可变参数函数体中将可变参数传给另一个可变参数函数，需要将可变参数展开：

```go
func errorf(linenum int, format string, args ...any) {
 fmt.Fprintf(os.Stderr, "Line %d: ", linenum)
 fmt.Fprintf(os.Stderr, format, args...)  // 这里的 args... 表示可变参数的展开操作
 fmt.Fprintln(os.Stderr)
}

func main() {
 linenum, name := 12, "count"
 errorf(linenum, "undefined: %s", name)  // "Line 12: undefined: count"
}
```

可变参数函数和以切片作为参数的函数是不同的类型：

```go
func f(...int) {}
func g([]int)  {}

func main() {
 fmt.Printf("%T\n", f)  // "func(...int)"
 fmt.Printf("%T\n", g)  // "func([]int)"
}
```

### 多返回值

函数有多个返回值时，需要用小括号括起来：

```go
func swap(x, y string) (string, string) {  // 返回两个 string 值
 return y, x
}
```

标准库中的许多函数返回两个值，一个是期望得到的返回值，另一个是函数出错时的错误信息。

按照惯例，若失败原因只有一个，则最后一个返回值用 bool 类型（通常命名为 ok）；若失败原因不止一个，则用 error 类型。

Go 允许命名的返回值，返回值的名字表示其含义。编译器会在函数体的开始处将命名返回值隐式初始化为其类型的零值。

函数的返回值列表要么全不命名，要么全命名。命名时可以用简写形式（多个同类型合并），但不能混用命名和不命名返回值。

```go
// 混用命名和不命名返回值，语法错误
func f1() (a, b int, string) { ... }
func f2() (a int, int) { ... }
```

哪怕只有一个命名返回值，也要用小括号括起来。

```go
// 命名返回值需要用小括号括起来
func g() (x int) {
 x = 1
 return
}
```

没有参数的 return 语句会直接返回已命名的返回值（按命名顺序返回所有值），被称为裸返回（bare return）。裸返回语句一般只用于简短的函数，在较长的函数体中会影响代码可读性。

```go
func split(sum int) (x, y int) {  // 将返回值 x int, y int 简写为 x, y int
 // 编译器会在函数体的开始处将命名返回值隐式初始化为其类型的零值
 x = sum * 4 / 9
 y = sum - x
 return  // 裸返回，等价于 return x, y
}

func f() (int, y int) {  // 需要注意：这里会将第一个 int 当作命名返回值，而不是返回值类型
 y = 20
 return  // 0, 20 未显式赋值的命名返回值会被隐式初始化为其类型的零值
}

func main() {
 fmt.Println(split(100))  // 44, 56
 fmt.Println(f())         // 0, 20
}
```

要么裸返回，要么全部返回，不能只返回部分返回值。

```go
func f(x, y int) {
 return x // 有两个命名返回值，这里只返回了一个，编译报错
}
```

### 空白标识符

空白标识符（blank identifier）`_` 参数用于强调该参数未被使用，虽然调用时允许传参，函数体中也不会用到该参数：

```go
func first(x int, _ int) int { return x }
```

在函数体中，也可以用空白标识符消除 unused 错误：

```go
func main() {
 a := 1
 _ = a  // 类似于 C++ 中的 (void) a

 b := true
 _ = b
}
```

用空白标识符接收函数调用返回值，可以忽略不需要的返回值，避免编译报错。

### 函数参数传递方式

Go 函数参数传递机制只有值传递（Pass by Value）一种，这意味着，无论传递什么类型的变量给函数，函数接收到的永远是这些变量的一个副本。

| 传递情况 | 机制描述 | 函数体中修改对原始数据的影响 | 示例 |
| -- | -- | -- | -- |
| 值类型：基本类型（bool、int、float、string）、结构体、数组 | 形参是实参的副本，函数体中操作的是与原始数据完全无关的新副本 | 不影响原始数据<br>如果结构体、数组中包含指针字段，修改指针字段指向的内存会改变原始数据 | 在函数体中修改 int 类型形参，外部的 int 类型实参不受影响 |
| 指针类型：`*基本类型`、`*结构体`、`*数组`、`*切片` 等 | 形参是实参的副本，形参指针与实参指针指向的是同一块内存 | 影响原始数据<br>传递大的结构体、数组会产生性能问题，因为需要复制大量数据，此时通常使用指针 | 在函数体中通过 `*int` 形参指针修改其指向的值，外部的 int 类型实参的值也会随之改变 |
| 引用类型：切片、map、通道、函数 | 形参是实参的副本，复制的是“引用头”的副本而非底层数据，形参与实参指向的是同一块底层数据 | 影响原始数据 | 在函数体中通过形参修改切片元素，外部的切片实参也会看到变化，因为修改的是同一个底层数组 |

```go
type Person struct {
 Name string
 Age  int
 ptr  *int // 仅用作示例
}

// 实现 fmt.Stringer 接口，用于自定义打印格式
func (p Person) String() string {
 return fmt.Sprintf("%s is %d years old, value ptr points to is %d", p.Name, p.Age, *p.ptr)
}

func updatePerson(p Person) {
 p.Name = "Alice" // 修改的是副本，不影响原始数据
 p.Age = 30       // 修改的是副本，不影响原始数据
 *p.ptr = 2000    // 修改的是指针指向的底层数据，影响原始数据
}

func main() {
 a := 100
 p := Person{Name: "Bob", Age: 25, ptr: &a}
 fmt.Println(p) // Bob is 25 years old, value ptr points to is 100

 updatePerson(p)
 fmt.Println(p) // Bob is 25 years old, value ptr points to is 2000
 fmt.Println(a) // 2000，改变了
}
```

当函数参数为切片时，如果在函数体中对切片执行了扩容操作（比如使用 append 并且导致容量不足时），函数体中的切片变量副本可能会被指向一个新的、更大的底层数组。此时，在函数体中继续修改切片元素，将不会影响外部的原始切片，因为它们指向了不同的底层数组。如果需要在函数体中修改切片参数并希望影响原始数据，应该传递指向切片的指针。

请仔细观察如下示例的打印，示例中的现象与 Go 的编译器和运行时优化密切相关，不同的 Go 版本甚至不同的编译选项都可能导致不同的结果。

```go
func f(s []int) {
 s = append(s, 100)
 fmt.Printf("cap: %d\n", cap(s)) // cap: 4  当 Go 编译器检测到函数体中的切片副本不会被外部引用时，会采用更激进的扩容策略，预分配更多空间可以减少后续 append 操作的内存分配次数
}

func g(s *[]int) {
 *s = append(*s, 100)
 fmt.Printf("cap: %d\n", cap(*s)) // cap: 1  通过指针操作原始切片时，编译器采用更保守的扩容策略，避免过度预分配导致内存浪费，特别是当切片可能被多个地方引用时
}

func main() {
 { // 大括号块开启一个新的内层作用域
  s := make([]int, 0) // 创建一个长度为 0、容量为 0 的 int 类型切片
  fmt.Println(cap(s)) // 0
  f(s)
  fmt.Println(cap(s)) // 0
 }

 {
  s := make([]int, 0)
  fmt.Println(cap(s)) // 0
  g(&s)
  fmt.Println(cap(s)) // 1
 }
}
```

### 求值顺序

Go 规定，在函数调用时，其参数列表中的表达式，包括嵌套的函数调用、方法调用或通道操作的求值顺序是从左到右。

```go
func f() int {
 fmt.Println("calling f")
 return 1
}
func g(a, b, c int) int {
 fmt.Printf("calling g, a: %d, b: %d, c: %d\n", a, b, c)
 return 2
}
func h() int {
 fmt.Println("calling h")
 return 3
}
func i() int {
 fmt.Println("calling i")
 return 1
}
func j() int {
 fmt.Println("calling j")
 return 1
}

func main() {
 var x = []int{21, 22, 23}
 var c chan int = make(chan int)
 go func() { c <- 1 }()

 // 总体调用顺序：f() -> h() -> i() -> j() -> <-c -> g()
 fIndex := f()  // 1
 y := []int{11, 12, 13}
 y[fIndex] = g(h(), i()+x[j()], <-c)  // g(3, 23, 1)
 fmt.Println(y)                       // [11 2 13]
}
```

虽然普通函数参数的求值顺序是明确的，但在一些特殊场景下，求值顺序的规则有所不同：

- 赋值语句的**多值赋值**：在 `x, y = y, x` 这类语句中，求值分为两个阶段。首先，赋值语句右边的所有表达式会按从左到右的顺序进行求值；然后，再将求值结果按从左到右的顺序赋值给左边的变量。这意味着交换变量值这类操作在 Go 中是安全且符合直觉的，不需要像 C 语言那样引入一个 tmp 变量
- 包级变量的初始化：包级变量的初始化顺序主要由变量声明的顺序和它们之间的初始化依赖关系决定，如果变量 a 的初始化依赖于变量 b，那么 b 会先被初始化
- defer 语句的函数参数：对于 `defer func(a, b int) {...}(expr1, expr2)`，其中的 `expr1` 和 `expr2` 的求值顺序同样遵循从左到右的规则。需要注意的是，这些参数表达式在遇到 defer 语句时就会立即求值固定下来，只是函数体的执行会被延迟

### 函数调用优化

从 Go 1.17 开始，函数参数的传递方式发生了重大变化，从之前的完全通过栈传递改为优先使用寄存器传递。

- Go 1.17 之前：所有函数参数和返回值都通过栈传递。优点是实现简单，跨平台一致性好，但性能有损耗，因为访问内存比访问寄存器慢
- Go 1.17+：对于 9 个以内的参数和返回值，会优先使用寄存器来传递，超出部分再使用栈，使得典型程序（函数调用频繁且参数数量适中）的性能提升约 5-10%

Go 函数返回值通常存储在栈上或通过寄存器传递，这些存储区域在函数返回后会被立即重用或回收。因此，不能直接对函数返回值取地址，因为它是一个没有固定内存位置的临时值，即使是命名返回值函数也不行。正确的做法是，先将返回值赋值给一个局部变量，然后对该变量取地址。

```go
func getValue() int {
 return 42
}

func main() {
 // 错误：不能直接对函数返回值取地址
 // ptr := &getValue()  // 编译报错：cannot take address of getValue()

 // 正确：先赋值给变量
 value := getValue()
 ptr := &value  // 合法
 _ = ptr
}
```

### 匿名函数

Go 中函数是第一类值（first-class values，一等公民），函数值（即函数类型的变量）可以赋值给变量、作为函数的参数传递、作为函数的返回值。

```go
// compute 接受一个计算函数，允许对两个 float64 值进行操作，并返回一个 float64 结果。
// 计算函数可以是任何符合签名的函数，例如计算平方根、幂或其它操作。
func compute(fn func(float64, float64) float64, x, y float64) float64 {
 return fn(x, y)
}

func main() {
 hypot := func(x, y float64) float64 {  // 匿名函数
  return math.Sqrt(x*x + y*y)  // 计算平方根
 }
 fmt.Println(unsafe.Sizeof(hypot))     // 8 普通函数的 size 恒为 8
 fmt.Println(unsafe.Sizeof(math.Sqrt)) // 8

 fmt.Println(compute(hypot, 3, 4))  // 5, 计算直角三角形的斜边长度

 fmt.Println(compute(math.Pow, 3, 4))  // 81,  计算 3 的 4 次幂

 fmt.Println(compute(func(x, y float64) float64 {  // 匿名函数
  return x + y
 }, 3, 4))  // 7, 计算 3 加 4
}
```

Go 不支持在函数体中直接使用 `func` 关键字定义另一个具有名字的嵌套函数，可以通过将匿名函数赋值给变量的方式来实现类似功能。

```go
func main() {
 // func(int) string 是一个函数类型
 var f func(int) string              // 声明一个函数类型的变量 f
 fmt.Printf("类型：%[1]T，值：%[1]v\n", f)  // 函数的零值为 nil，调用值为 nil 的函数值会引发 panic

 // 将一个同类型的匿名函数赋值给变量 f
 f = func(x int) string {  // 函数字面量的语法和函数声明类似，区别在于 func 关键字后没有函数名（匿名）
  return fmt.Sprintf("hello %d", x)
 }
 fmt.Println(f(10))  // hello 10
}
```

### 函数底层结构

函数是引用类型，函数值（如 var f func(x int) string）保存的不是函数代码本身，可以认为函数值是一个指向如下 funcval 结构体的指针（源代码：`${GOROOT}/src/runtime/runtime2.go`）：

```go
// 简化版
type funcval struct {
    fn uintptr   // 函数入口地址
    // 后面是闭包捕获的变量数据（可变长度）
}
```

函数变量本身是一个指针，在 64 位操作系统上 size 恒为 8；闭包捕获的外部变量存储在指针指向的 funcval 结构体中，不影响函数变量的 size。

函数类型的零值为 nil，函数变量可与 nil 比较，但函数变量之间不能通过 `==` 操作符比较，因为可能为闭包，闭包除了函数代码外还捕获了外部变量。

因为不可比较，函数变量不能作为 map 的 key。

```go
func plainFunc() {}

func closureFunc() func() int {
 count := 0
 return func() int {
  count++
  return count
 }
}

func main() {
 // 1. 函数变量的 size 恒为 8（64 位），闭包不影响 size
 var f1 func() = plainFunc
 f2 := closureFunc()

 fmt.Println(unsafe.Sizeof(f1)) // 8
 fmt.Println(unsafe.Sizeof(f2)) // 8

 // 2. 函数变量可与 nil 比较
 var fn func(int) int
 fmt.Println(fn == nil) // true

 fn = func(x int) int { return x * 2 }
 fmt.Println(fn == nil) // false

 // 3. 函数变量之间不能通过 == 比较（编译报错）
 // a := func() {}
 // b := func() {}
 // fmt.Println(a == b) // invalid operation: a == b (func can only be compared to nil)

 // 4. 函数变量不能作为 map 的 key（编译报错）
 // m := map[func()]string{} // invalid map key type func()
}
```

### 函数类型赋值、传参

函数是引用类型，赋值和传参仍是值传递，但只会拷贝“引用头”，得到“引用头”的独立副本，它们引用的仍是同一个底层数据。

```go
func makeCounter() func() int {
 count := 0
 return func() int {
  count++
  return count
 }
}

func main() {
 c1 := makeCounter()
 c2 := c1 // 赋值：拷贝引用头（指针），c1 和 c2 指向同一个 funcval

 fmt.Println(c1()) // 1
 fmt.Println(c2()) // 2，c2 和 c1 共享同一个 count，所以 c2() 继续在 c1() 的基础上递增
 fmt.Println(c1()) // 3
}
```

### 函数选项模式

Go 不支持函数参数默认值，也不支持关键字参数（即调用时指定参数名传参），只能按参数声明顺序传值。

函数选项模式（Functional Options Pattern）用于优雅地配置结构体（尤其是构造函数），核心思想是用 `func(*Config)` 类型的函数作为可变参数，常用于需要大量可选参数的场景。

优点：

- 参数顺序无关，可有可无，按需传入
- 可读性强，函数名清晰表达意图：`WithPort(8080)`
- 易扩展，新增配置项只需添加新的 `WithXXX` 函数
- 向后兼容，不破坏已有代码，不变更已有函数签名

什么时候该用？

- 构造函数参数 ≥ 3 个
- 有大量可选参数
- 需要长期维护的库或 SDK

有两种函数选项模式：

- 闭包返回 error 风格
- Uber 风格（Option 接口）

#### 闭包返回 error 风格

```go
// 1. 定义 Server 结构体
type Server struct {
 addr     string
 port     int
 timeout  time.Duration
 maxConns int
}

// 2. 定义 Option 类型
type Option func(*Server) error

// 3. 默认配置
func defaultServer(addr string) *Server {
 return &Server{
  addr:     addr,
  port:     8080,
  timeout:  time.Second * 30,
  maxConns: 100,
```

#### Uber 风格（Option 接口）

```go
// 1. 配置结构体（私有）
type Server struct {
 addr     string
 port     int
 timeout  time.Duration
 maxConns int
}

// 2. Option 接口（关键）
type Option interface {
 apply(*Server)
}

// 3. 函数适配器（标准写法）
type optionFunc func(*Server)

func (f optionFunc) apply(s *Server) {
 f(s)
}

// 4. 默认值构造函数
func defaultServer(addr string) *Server {
 return &Server{
  addr:     addr,
  port:     8080,
  timeout:  time.Second * 30,
  maxConns: 100,
 }
}

// 5. 公共构造函数
func NewServer(addr string, opts ...Option) *Server {
 s := defaultServer(addr)

 for _, opt := range opts {
  opt.apply(s)
 }

 // 最终一致性校验（Uber 强烈推荐）
 normalize(s)

 return s
}

// 6. normalize（兜底修正 & 校验）
func normalize(s *Server) {
 if s.port <= 0 {
  s.port = 8080
 }
 if s.timeout <= 0 {
  s.timeout = time.Second * 30
 }
 if s.maxConns <= 0 {
  s.maxConns = 100
 }
}

// 7. 对外暴露的选项函数
func WithPort(port int) Option {
 // 将匿名函数转换为 optionFunc 类型后返回，optionFunc 实现了 Option 接口，可以赋值给 Option 类型
 return optionFunc(func(s *Server) {
  s.port = port
 })
}

func WithTimeout(timeout time.Duration) Option {
 return optionFunc(func(s *Server) {
  s.timeout = timeout
 })
}

func WithMaxConns(n int) Option {
 return optionFunc(func(s *Server) {
  s.maxConns = n
 })
}

// 8. 使用示例
func main() {
 server := NewServer(
  "127.0.0.1",
  WithPort(9090),
  WithTimeout(time.Minute),
  WithMaxConns(200),
 )

 fmt.Printf("server addr: %s\n", server.addr)
 fmt.Printf("server port: %d\n", server.port)
 fmt.Printf("server timeout: %v\n", server.timeout)
 fmt.Printf("server maxConns: %d\n", server.maxConns)
}
```

#### 两种风格对比

| 维度 | Uber 风格（Option 接口） | 闭包返回 error 风格 |
| -- | -- | -- |
| Option 类型 | `interface { apply(*T) }` | `func(*T) error` |
| 构造函数返回值 | `*T` | `(*T, error)` |
| 校验时机 | `normalize()` 兜底修正 | 每个 Option 或 New 中返回 error |
| 扩展性 | 强（可加结构体 Option） | 一般 |
| 安全性 | 高（限制为 Option 接口） | 任意函数都能传 |
| 调用复杂度 | 低 | 需要处理 error |
| 容错性 | 自动修正 | 直接失败 |
| 学习成本 | 稍高 | 直观 |

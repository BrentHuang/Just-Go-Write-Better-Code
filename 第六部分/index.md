# 第六部分

## 概览

本部分深入讲解 Go 语言的函数机制，涵盖函数定义、可变参数、多返回值与命名返回值、函数作为第一类值、函数选项模式、`init()` 函数、递归函数、闭包、defer 延迟执行、panic-recover 错误恢复，以及变量逃逸分析。理解这些机制是掌握 Go 语言核心编程范式的关键。

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 函数](01函数.md) | 函数定义与参数、可变参数、多返回值与命名返回值、函数注释、调用约定（ABI）、参数传递机制、表达式求值顺序、函数作为第一类值、函数选项模式 | 掌握函数的完整语法与底层机制，合理设计函数签名与参数传递 |
| [02 init() 函数](02init()函数.md) | `init()` 的执行顺序、使用场景与注意事项 | 理解包初始化机制，避免滥用 `init()` |
| [03 递归函数](03递归函数.md) | 递归的基本结构、间接递归、无限递归与栈溢出 | 正确使用递归解决问题，理解其局限性 |

| [06 panic-recover 机制](06panic-recover机制.md) | panic 的传播与覆盖、recover 的使用限制、协程间的 panic-recover、`safeCall` 封装 | 理解 panic-recover 的传播机制，在适当场景使用 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第五部分（复合类型），尤其是切片与映射的引用语义，因为函数参数传递、闭包捕获、defer 返回值等机制都依赖这些基础。
- 建议按章节顺序学习：函数、init() 函数、递归函数、闭包、defer 延迟、panic-recover 机制、变量逃逸。
- "函数"一节内容较多，涵盖语法、底层结构与函数选项模式，建议分两次阅读。
- "闭包"与"defer"是函数的进阶应用，理解后有助于编写惯用的 Go 代码。
- "变量逃逸"涉及编译器优化原理，可作为进阶内容在熟悉基础语法后选学。

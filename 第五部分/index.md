# 第五部分

## 概览

本部分介绍 Go 语言的复合数据类型，包括指针、结构体、数组、切片、映射，以及复合字面量语法糖、`range` 迭代机制与 `iter` 包、`unsafe` 包等底层内存操作工具。理解复合类型的内存模型与引用语义，是编写正确、高效 Go 代码的关键。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 指针类型](01指针类型.md) | 取地址与解引用、指针与值类型的选择、`new()` 与 `make()` 的区别、`unsafe.Pointer` 与指针算术运算 | 掌握指针的基本用法，合理选择值类型与指针类型 |
| [02 结构体类型](02结构体类型.md) | 结构体定义与构造、工厂函数、可见性、匿名嵌入与成员提升、方法覆盖与字段遮蔽 | 理解 Go 通过组合实现代码复用的设计哲学 |
| [03 数组类型](03数组类型.md) | 数组的定义与构造、值语义传递、二维数组与内存布局 | 理解数组固定长度和值类型的特性，为学习切片打好基础 |

| [06 复合字面量语法糖](06复合字面量语法糖.md) | 内层类型名省略规则、指针隐式取地址 | 写出更简洁的复合类型字面量 |

## 学习路径与前置知识

- 学习本部分前，建议先完成第三部分（基本类型）和第四部分（流程控制），本部分大量示例依赖变量声明、类型系统和 for 循环等基础知识。
- 建议按章节顺序学习：指针类型、结构体类型、数组类型、切片类型、映射类型、复合字面量语法糖、range 迭代与 iter 包、unsafe 包。
- 切片和映射是 Go 中最常用的两种复合类型，应重点掌握其底层结构和引用语义。
- `range` 迭代与 `iter` 包涉及 Go 1.22/1.23 的新特性，建议在学完基础迭代语法后阅读。
- `unsafe` 包为进阶内容，涉及底层内存操作，初学者可在需要时再查阅。

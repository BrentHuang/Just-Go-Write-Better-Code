# 复合字面量语法糖

在复合类型中，当嵌套较深时，完整写出每一层的类型名会非常冗长。Go 允许在特定位置省略内层复合字面量的类型名，使代码更简洁。

在书写数组、切片或映射类型的复合字面量（`T{...}`）时，若其中的元素或映射的键本身也是复合字面量，且其类型与外层容器 `T` 的元素类型或键类型相同，则可以省略内层复合字面量的类型名，直接写作 `{...}`，由编译器按外层元素/键类型实例化。

同理，若外层容器的元素或键类型为指向复合类型的指针 `*T`（如 `[]*T`、`map[*T]V`），且该位置上本应填写的值是复合字面量的地址（原本需写作 `&T{...}`），则可一并省略 `&T`，直接写作 `{...}`，由编译器隐式取地址构造指针。

省略规则的限制条件：

- 外层字面量必须是数组、切片或映射类型
- 仅当内层类型与外层元素/键类型严格一致（identical）时方可省略
- 指针指向的必须是复合类型（如 `*Point`、`*[2]int`），不能是 `*int` 等基本类型

```go
type Point struct{ X, Y float64 }

func main() {
 _ = [...]Point{{1.5, -3.5}, {0, 0}}   // 数组元素
 _ = [][]Point{{{0, 1}, {1, 2}}}       // 多层嵌套
 _ = map[string]Point{"orig": {0, 0}}  // 映射值
 _ = map[Point]string{{0, 0}: "orig"}  // 映射键
 _ = []*Point{{1.5, -3.5}}             // 隐式 &Point{...}
 _ = map[*Point]int{{1, 2}: 3}         // 指针作为映射键也可省略
 _ = map[string]*Point{"orig": {0, 0}} // 指针作为映射值也可省略
 _ = [][]*Point{{{1, 2}}}              // 嵌套指针
 _ = []*[2]int{{1, 2}}                 // 指针指向数组也可以
}
```

```go
type Animal interface{ Speak() }
type Dog struct{ Name string }

func (d Dog) Speak() {}

func main() {
 // 外层是 Animal（接口），内层是 Dog（具体类型），类型不匹配，不能省略
 _ = []Animal{Dog{Name: "LaiFu"}} // 必须写 Dog，不能只写 {Name: "Fido"}
}
```

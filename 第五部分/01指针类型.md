# 指针类型

`*T` 表示指向 `T` 类型变量的指针类型，指针变量的值是它指向的变量的内存地址。注意：`T` 与 `*T` 是两种不同的类型，一般称 `T` 为值类型，称 `*T` 为指针类型。

两个运算符：

- `&` 取地址：获取变量的内存地址，返回指向该变量的指针
- `*` 解引用：访问指针指向的变量，可通过 `*p` 读取和修改

指针类型的零值为 nil，对值为 nil 的指针解引用会引发 panic。使用指针前（尤其来源于外部输入时）应判断是否为 nil。

在 64 位操作系统上，指针变量的 size 恒为 8 字节。

## 指针与结构体、切片、映射、接口类型

将函数参数定义为指针类型，除了可以在函数体中修改传入的数据外，还能避免拷贝大型数据结构带来的开销。但基本类型（bool、整型、浮点型、string）或小型结构体（仅包含 1、2 个基本类型字段）值传递的拷贝开销很小，使用指针反而可能增加 GC 压力（GC 需追踪堆上每个指针），且对 CPU 缓存不友好（指针间接寻址）。通常除非有明确的修改或共享需求，基本类型和小型结构体优先考虑值类型。

切片、映射、接口类型本身已是引用类型，通常不需要指向它们的指针类型。

## 指针类型转换

`unsafe.Pointer` 类型可与任意类型的指针互转（慎用），类似于 C 语言中的 `void*` 指针类型。

```go
func main() {
 var f float64 = 3.1415
 bits := *(*uint64)(unsafe.Pointer(&f))  // 将 *float64 类型转换成 *uint64 类型
 fmt.Println(bits)                       // 4614256447914709615
 u := uint64(f)
 fmt.Println(u)  // 3

 // p := (*uint64)(&f) // 这样直接将 *float64 类型转换成 *uint64 类型是不行的，编译报错
}
```

## 二级指针 `**T`

指向指针的指针：`var pp **int`，`**T` 与 `*T` 也是两种不同的类型。

```go
func main() {
 var a int
 var p *int
 var pp **int

 a = 3000

 p = &a
 fmt.Printf("%T\n", p)  // *int

 pp = &p
 fmt.Printf("%T\n", pp)  // **int

 /* 获取 pp 的值 */
 fmt.Printf("变量 a = %d\n", a)
 fmt.Printf("指针变量 *p = %d\n", *p)
 fmt.Printf("指向指针的指针变量 **pp = %d\n", **pp)  // 访问二级指针指向的变量需要使用两个 * 号
}
```

## 指针算术运算

Go 不支持指针算术运算（如 `p++`、`p+offset`，编译报错），但可转换为 uintptr 类型进行运算（Go 1.17 引入的 `unsafe.Add` 是更安全的替代方案）。

```go
// 该函数仅演示通过 uintptr 进行指针运算，无实际意义
func getSecondElementPtrOld(arr []int) *int {
 p1 := unsafe.Pointer(&arr[0])                             // 获取第一个元素的地址
 p2 := unsafe.Pointer(uintptr(p1) + unsafe.Sizeof(arr[0])) // 转换为 uintptr 进行运算，然后立即转换回 unsafe.Pointer
 return (*int)(p2)                                         // 再转换回 *int
}

func getSecondElementPtrModern(arr []int) *int {
 p1 := unsafe.Pointer(&arr[0])               // 获取第一个元素的地址
 p2 := unsafe.Add(p1, unsafe.Sizeof(arr[0])) // 直接使用 unsafe.Add 进行指针运算，等价于上面的代码
 return (*int)(p2)                           // 再转换回 *int
}

func main() {
 arr := []int{1, 2, 3, 4, 5}
 second := getSecondElementPtrOld(arr)
 fmt.Println(*second) // 2

 second = getSecondElementPtrModern(arr)
 fmt.Println(*second) // 2
}
```

## new() 函数

内置函数 [func new(TypeOrExpr) *Type](https://pkg.go.dev/builtin#new) 分配一个新的已初始化变量，并返回指向它的指针。它接受一个参数，该参数可以是类型或表达式。

- 如果参数是类型 `T`，那么 `new(T)` 分配一个 `T` 类型的变量，并初始化为 `T` 类型的零值
- 如果参数是表达式 `x`，那么 `new(x)` 分配一个类型与 x 相同的变量，并初始化表达式 x 的值（如果是一个无类型常量，那么该常量会先被隐式转换为相应的默认类型）。该用法由 Go 1.26 引入。

```go
func main() {
 // 为 int 类型分配内存，初始值为 0
 p1 := new(int) // new(int) 返回 *int 类型的指针变量
 fmt.Printf("%p\n", p1)
 fmt.Printf("%d\n", *p1) // 0 (int 类型的零值)

 p2 := new(int)
 fmt.Printf("%p\n", p2)  // 与 p1 的地址不同。每次 new() 都会创建一个新的变量
 fmt.Printf("%d\n", *p2) // 0 (int 类型的零值)

 // 为自定义结构体分配内存，结构体的各个字段初始化为其类型的零值
 type Person struct {
  Name string
  Age  int
 }
 personPtr1 := new(Person) // new(Person) 返回 *Person 类型的指针变量
 fmt.Printf("%p\n", personPtr1)
 fmt.Printf("%q\n", personPtr1.Name) // "" (string 类型的零值)
 fmt.Printf("%d\n", personPtr1.Age)  // 0 (int 类型的零值)

 personPtr2 := new(Person)
 fmt.Printf("%p\n", personPtr2)      // 与 personPtr1 的地址不同。每次 new() 都会创建一个新的变量
 fmt.Printf("%q\n", personPtr2.Name) // "" (string 类型的零值)
 fmt.Printf("%d\n", personPtr2.Age)  // 0 (int 类型的零值)

 // 为长度为 5 的 int 数组分配内存，返回指向数组的指针
 arrPtr := new([5]int) // new([5]int) 返回 *[5]int 类型的指针变量
 for i := range 5 {
  arrPtr[i] = i * 2 // 通过指针操作数组元素
 }
 fmt.Printf("%v\n", *arrPtr) // [0 2 4 6 8]

 // 对于切片，new() 返回一个指向切片的指针，这个切片被初始化为 nil
 slicePtr := new([]int) // slicePtr 的类型是 *[]int
 if *slicePtr == nil {  // true  --指针指向的切片为 nil
  fmt.Println("nil")
 }
 *slicePtr = make([]int, 5) // 需要额外使用 make 初始化底层数组
 if *slicePtr != nil {      // true
  fmt.Printf("%v\n", *slicePtr) // [0 0 0 0 0]
 }

 p1 = new(20) // Go 1.26 引入，分配一个变量（值为 20），返回指向这个变量的指针（*int 类型）
 fmt.Printf("%p\n", p1)
 fmt.Printf("%T, %d\n", p1, *p1) // *int, 20

 p2 = new(20)
 fmt.Printf("%p\n", p2)          // 与 p1 的地址不同。每次 new() 都会创建一个新的变量
 fmt.Printf("%T, %d\n", p2, *p2) // *int, 20
}
```

### 结构体的 new() 函数

对于结构体，`new(MyStruct)` 和 `&MyStruct{}` 在功能上是等价的，都返回一个指向 `MyStruct` 零值的指针。

- 当不需要在创建时初始化特定字段（即所有字段都使用其类型的零值）时，两者皆可
- 若需要在创建时初始化特定字段，则优先使用结构体字面量 `&MyStruct{Field: value}`
- 直接用字面量语法创建结构体变量的方法更灵活、更常见

### new() 与 make() 的区别

| 特性 | `new(T)` | `make(T, ...)` |
| -- | -- | -- |
| 适用类型 | 任意类型 T | 仅限切片、映射、通道三种引用类型 |
| 返回类型 | `*T`（指向值为 `T` 类型零值变量的指针） | `T`（初始化后的值本身，非指针） |

# 映射类型（map）

Go 中映射类型 `map` 的底层是哈希表，查找、插入、删除操作的平均时间复杂度为 `O(1)`，当发生大量哈希冲突时，性能会退化到 `O(n)`。

声明映射类型的变量：`var 变量名 map[KeyType]ValueType`，注意：

- 键（key）类型：必须可比较。基本类型（bool、整型、string 等）、指针、结构体（所有字段可比较）、数组（元素可比较）、接口（底层具体类型可比较，否则引发 panic）、通道（元素类型相同）可比较，切片、映射、函数不可比较。浮点类型虽支持比较，但因精度问题不建议用作映射的 key（NaN 作为 key 也有问题，因为 NaN != NaN）
- 值（value）类型：任意类型。不允许获取映射中 value 的地址（编译报错），因为映射在扩容时键值对会重新分布，原来的 value 地址也就随之失效了
- 遍历顺序：遍历时随机选择一个桶开始，逐个遍历桶和溢出桶，所以每次遍历的顺序都不固定，这是设计上有意为之

```go
func main() {
 m := map[string]int{
  "apple":  5,
  "banana": 3,
  "cherry": 7,
  "date":   9,
  "elder":  1,
 }

 // fmt.Printf("%p\n", &m["apple"]) // 不允许对映射中键值对的 value 取地址，编译报错

 // 遍历三次，每次顺序可能不同
 for i := range 3 {
  fmt.Printf("round %d: ", i+1)
  for k, v := range m {
   fmt.Printf("%s:%d ", k, v)
  }
  fmt.Println()
 }

 // 可能的输出（每次运行遍历顺序都不同）：
 // round 1: cherry:7 elder:1 apple:5 banana:3 date:9
 // round 2: banana:3 date:9 elder:1 cherry:7 apple:5
 // round 3: apple:5 cherry:7 date:9 banana:3 elder:1
}
```

映射的零值为 nil，值为 nil 的映射中没有任何 key，也不能往其中添加键值对，会引发 panic。这与允许往值为 nil 的切片中 append 元素不同。

## 构造映射

### 映射字面量

```go
func main() {
 // 空 map 字面量
 m := map[string]int{} // 创建一个空 map（等价于 make(map[string]int)），这样的空 map 并不为 nil
 if m == nil {         // false
  fmt.Println("map is nil")
 }

 m["a"] = 1
 fmt.Println(m) // map[a:1]

 // 声明并初始化一个 map，键为 string 类型，值为 int 类型
 m = map[string]int{
  "apple":  5, // key 是必须的（对比：结构体字面量中的字段名不是必须的）
  "banana": 3,
  "cherry": 7, // 最后一项的后面必须加逗号
 }
 fmt.Println(m) // map[apple:5 banana:3 cherry:7]

 // 嵌套字面量（map 的值是结构体）
 type Person struct {
  Age  int
  City string
 }

 people := map[string]Person{
  "alice": {Age: 30, City: "NYC"},
  "bob":   {Age: 25, City: "SF"},
 }
 fmt.Println(people) // map[alice:{30 NYC} bob:{25 SF}]
}
```

注意：映射字面量的最后一项后面必须加逗号，除非将所有项与 `{}` 写在一行，这是 Go 的语法规则。

### make() 函数

内置函数 [func make(t Type, size ...IntegerType) Type](https://pkg.go.dev/builtin#make) 可以创建映射，有两种语法：

- `m := make(map[int]string)`，没有第二个参数，编译器会自动分配一个较小的初始容量，在插入操作时映射会自动扩容以容纳更多元素
- `m := make(map[int]string, 10)`，第二个参数指定映射的初始容量，能预估大小时指定初始容量可减少扩容次数，提升性能

注意：`make()` 函数的第一个参数是映射类型，返回类型是第一个参数指定的映射类型，而不是指向映射的指针类型。

```go
func main() {
 var m map[string]int
 if m == nil { // true  -map 的零值为 nil
  fmt.Println("map is nil")
 }

 // m["a"] = 1 // 往值为 nil 的 map 中添加键值对会引发 panic

 m = make(map[string]int)
 if m != nil { // true
  fmt.Println("map is not nil")
 }

 m["a"] = 1
 fmt.Println(m) // map[a:1]

 m2 := make(map[string]int, 10) // make() 的第二个参数指定 map 的初始容量
 m2["a"] = 1
 fmt.Println(m2) // map[a:1]
 m2["a"] = 2     // key 已存在，value 会被覆盖为 2
 fmt.Println(m2) // map[a:2]
}
```

## 映射底层结构

同切片一样，映射类型也是引用类型，可以认为映射的“引用头”是一个指向底层数据结构 `maps.Map`（源代码：`${GOROOT}/src/internal/runtime/maps/map.go`）的指针类型 `*maps.Map`。

在 64 位操作系统上，映射变量的 size 恒为 8 字节，与映射中实际存储了多少个键值对无关。

```go
func main() {
 m := map[string]int{"hello": 1}
 fmt.Println(unsafe.Sizeof(m)) // 8

 var m1 map[string]int          // m1 为 nil
 fmt.Println(unsafe.Sizeof(m1)) // 8
}
```

## 映射的操作

### 插入或修改元素

`m[key] = value`，key 不存在时新增，key 存在时修改。

插入键值对可能导致映射自动扩容。

不能往值为 nil 的映射中添加键值对，会引发 panic。这与允许往值为 nil 的切片 append 元素的行为不同，根本原因是往映射中添加键值对是“就地修改”，往切片中 append 元素是“创建新切片”。

### 获取元素

`v = m[key]`，key 不存在时，v 为其类型的零值。这样就无法区分 key 不存在和 key 存在但 value 为零值的情况。

双赋值检测 key 是否存在：`v, ok := m[key]`，key 存在时 ok 为 true，不存在时 ok 为 false。

```go
func main() {
 m1 := make(map[string]int)
 fmt.Println(m1["apple"]) // 0

 if v, ok := m1["apple"]; ok { // bool 返回值命名为 ok，这是 Go 的 comma-ok 惯用法
  fmt.Println(v)
 } else { // true
  fmt.Println("not exist")
 }

 m1["apple"] = 5
 if v, ok := m1["apple"]; ok { // true
  fmt.Println(v) // 5
 } else {
  fmt.Println("not exist")
 }

 var m2 map[string]int    // m2 为 nil
 fmt.Println(m2["apple"]) // 0  --可以获取值为 nil 的 map 中的元素，结果永远是 key 不存在

 v, ok := m2["apple"]
 fmt.Println(v, ok) // 0 false
}
```

可以获取值为 nil 的映射中的元素，不会引发 panic，结果永远是 key 不存在。

### delete 删除元素

内置函数 [func delete(m map[Type]Type1, key Type)](https://pkg.go.dev/builtin#delete) 用于删除映射的中指定 key 的键值对，key 不存在时什么都不做，不会引发 panic。

可以删除值为 nil 的映射中的元素，因为 key 不存在，结果是什么都不会做。

```go
func main() {
 m1 := make(map[string]int)
 m1["apple"] = 5
 if v, ok := m1["apple"]; ok { // true
  fmt.Println(v) // 5
 } else {
  fmt.Println("not exist")
 }

 delete(m1, "banner") // 删除不存在的 key 也不会报错，什么都不做，不会 panic
  delete(m1, "apple")

 if v, ok := m1["apple"]; ok {
  fmt.Println(v)
 } else { // true
  fmt.Println("not exist")
 }

 var m2 map[string]int // m2 为 nil
 delete(m2, "apple") // 删除值为 nil 的 map 中的键值对，什么都不做，不会 panic
}
```

### 遍历

```go
func main() {
 m := map[string]int{
  "a": 1,
  "b": 2,
 }

 for k, v := range m { // k、v 都是副本
  fmt.Printf("key=%v, value=%v\n", k, v)
  v = 100 // v 是值的副本，修改 v 不会改变 map 中的 value
 }
}
```

在 range 迭代中可以用 `delete()` 函数删除当前迭代的键值对。删除当前迭代的元素不影响迭代器状态，循环按初始顺序继续执行；但删除尚未迭代的元素可能导致该元素被跳过。

```go
func main() {
 m := map[string]int{"apple": 1, "banana": 2, "orange": 3}
 for k, v := range m {
  if v == 2 {
   delete(m, k) // 安全删除当前迭代的元素
  }
 }
 fmt.Printf("%v\n", m) // map[apple:1 orange:3]

 m1 := map[string]int{"a": 1, "b": 2, "c": 3}
 for k := range m1 {
  fmt.Printf("访问: %s\n", k) // 可能只输出 "a" 和 "b"，"c" 被跳过

  if k == "b" {
   delete(m1, "c") // c 可能在 b 之前访问，也可能在 b 之后访问，因为每次迭代的顺序是随机的
  }
 }
 fmt.Printf("%v\n", m1) // map[a:1 b:2]

 m2 := map[string]int{"a": 1, "b": 2, "c": 3, "d": 4}
 fmt.Println("开始遍历")
 for k := range m2 {
  fmt.Printf("访问: %s\n", k) // 可能输出 "a"、"b"、"c" 或 "d"，只循环一次

  // 在第一次迭代时清空所有键值对
  clear(m2)
 }
 fmt.Printf("%v\n", m2) // map[]
}
```

应当避免在遍历映射时添加元素，在 range 迭代中向映射添加新的键值对的行为是未定义的（undefined behavior）。新添加的元素在本次迭代中可能被访问，也可能不被访问，取决于映射的扩容状态和具体实现。虽然一般不会引发 panic，但这种做法是不安全且不推荐的。

### clear 清空映射

内置函数 [func clear[T ~[]Type | ~map[Type]Type1](t T)](https://pkg.go.dev/builtin#clear)（Go 1.21 引入）删除映射中的所有键值对，结果是一个空映射（`map[string]int{}`）。如果参数 t 为 nil，那么 `clear()` 不会执行任何操作。

```go
func main() {
 m := map[string]int{"apple": 5, "banana": 3, "cherry": 7}
 fmt.Println(m) // map[apple:5 banana:3 cherry:7]
 clear(m)
 fmt.Println(m) // map[]

 var m1 map[string]int // m1 为 nil
 if m1 == nil {        // true
  fmt.Println("m1 is nil")
 }

 clear(m1)      // 参数为 nil，什么都不做，不会 panic
 if m1 == nil { // true
  fmt.Println("m1 is nil")
 }
}
```

`clear()` 函数对映射与切片的行为不同，

- 对映射，是删除映射中的所有键值对
- 对切片，是将切片长度范围内的元素置为其类型的零值

## 映射的 len、cap

len 表示映射中的键值对个数，映射不能取 cap，编译报错。映射的自动扩容是 Go 运行时内部的行为，用户无需关心，所以 cap 对映射没有意义。

```go
func main() {
 m := map[string]int{"hello": 1}
 fmt.Println(len(m)) // 1 --len 表示 map 中的键值对个数
 // fmt.Println(cap(m)) // map 不能取 cap，编译报错
}
```

## 映射赋值、传参

映射类型的赋值和传参仍是值传递，但只会拷贝“引用头”，得到的是“引用头”的一个副本，它们引用的是同一个底层数据结构（`maps.Map`）。

```go
func main() {
 m1 := map[string]int{
  "a": 1,
  "b": 2,
 }

 m2 := m1        // map 变量赋值，m2 与 m1 共享底层数据（hash 表的存储桶等数据结构）
 fmt.Println(m1) // map[a:1 b:2]
 fmt.Println(m2) // map[a:1 b:2]

 m2["a"] = 100   // m2 修改了 a 的值，m1 也会改变
 fmt.Println(m1) // map[a:100 b:2]
 fmt.Println(m2) // map[a:100 b:2]

 f(m1)
 fmt.Println(m1) // map[a:200 b:2]  --a 的值在函数 f() 中被修改了

 g(m1)
 fmt.Println(m1) // map[a:200 b:2 i0:0 i1:1 i2:2 i3:3 i4:4 i5:5 i6:6 i7:7 i8:8 i9:9]  --map 在函数 g() 中扩容了
}

func f(m map[string]int) {
 m["a"] = 200 // 在函数体中修改 map 的键值对会影响原始 map
}

func g(m map[string]int) {
 for i := range 10 {
  m[fmt.Sprintf("i%d", i)] = i // 往 map 中添加键值对导致自动扩容。与切片扩容不同，map 扩容时不会创建一个新的底层数据结构，扩容后 map 的“引用头”是不变的，所以 map 作为函数参数时不需要使用指针类型
 }
}
```

## 映射比较

与切片一样，映射只能与 nil 比较，不能通过 `==` 操作符来比较两个映射是否相等。因为不可比较，所以也不能作为映射的 key。

```go
func main() {
 m1 := map[string]int{"a": 1, "b": 2}
 m2 := map[string]int{"a": 1, "b": 2}

 if m1 == m2 { // 编译报错：map can only be compared to nil
  fmt.Println("m1 == m2")
 }
}
```

## 自定义类型作为映射的 key

只要自定义类型是可比较的（即支持 `==` 和 `!=` 操作），就可以作为映射的 key。

```go
// 定义结构体，所有字段都是可比较的类型，可以作为映射的 key
type User struct {
 ID   string // string，可比较
 Name string // string，可比较
 Age  int    // int，可比较
 // s    []int // 切片类型，不可比较，不能作为映射的 key
}

func main() {
 m := make(map[User]int) // user->score

 alice := User{"001", "Alice", 25}
 m[alice] = 88
 m[User{"002", "Bob", 30}] = 95

 if u, ok := m[alice]; ok {
  fmt.Printf("Alice's score: %d\n", u) // Alice's score: 88
 }
}
```

## 多级映射

映射的 value 可以是另一个映射，用于构建多级索引等复杂数据结构：

```go
func main() {
 // 定义一个嵌套的 map，表示不同城市的不同水果的库存
 cityFruits := make(map[string]map[string]int) // 城市名->(水果名->库存)
 cityFruits["Beijing"] = map[string]int{"apple": 50, "banana": 30}
 cityFruits["Shanghai"] = map[string]int{"orange": 40, "pear": 20}

 // 获取嵌套 map 的 value
 fmt.Println(cityFruits["Beijing"]["apple"]) // 输出：50
}
```

## 并发安全

<!-- autocorrect-disable -->
映射类型不是并发安全的，如果多个协程并发读写同一个 map，会引发“fatal error: concurrent map writes” panic。解决方案主要有三种：
<!-- autocorrect-enable -->

- 使用 [sync.Mutex](https://pkg.go.dev/sync#Mutex)（互斥锁）或 [sync.RWMutex](https://pkg.go.dev/sync#RWMutex)（读写锁，适用于读多写少的场景）来封装对 map 的访问
- Go 1.9+ 标准库提供了并发安全的 [sync.Map](https://pkg.go.dev/sync#Map)，其接口和性能特性与普通映射不同，更适用于键值对相对稳定、读多写少的场景，在此类场景下性能优于“sync.Mutex + 普通映射”
- 分片锁（sharding）：对于超大规模、超高并发的场景，可以将一个大映射分成多个小映射，每个小映射用自己的锁，可以极大降低锁的竞争，提升性能

    ```go
    // ShardedMap 支持泛型的分片 map
    type ShardedMap[K comparable, V any] struct {
     shards     []*Shard[K, V] // 每个切片元素就是一个分片（独立的 map）
     shardCount int            // 表示分片的数量，每个分片对应一个独立的 map
     hasher     func(K) uint32 // 哈希函数，决定 key 分配到哪个分片：hash(key) % shardCount
    }
    
    type Shard[K comparable, V any] struct {
     data map[K]V
     sync.RWMutex
    }
    
    // NewShardedMap 创建泛型分片 map
    func NewShardedMap[K comparable, V any](shardCount int, hasher func(K) uint32) *ShardedMap[K, V] {
     if shardCount <= 0 {
      shardCount = 32
     }
    
     if hasher == nil {
      // 默认 hasher，支持 string 和整数类型
      hasher = getDefaultHasher[K]()
     }
    
     shards := make([]*Shard[K, V], shardCount)
     for i := 0; i < shardCount; i++ {
      shards[i] = &Shard[K, V]{
       data: make(map[K]V),
      }
     }
    
     return &ShardedMap[K, V]{
      shards:     shards,
      shardCount: shardCount,
      hasher:     hasher,
     }
    }
    
    // fnv32 FNV-1a 哈希函数
    func fnv32(key string) uint32 {
     hash := uint32(2166136261)       // FNV offset basis（初始值）
     const prime32 = uint32(16777619) // FNV prime（质数）
     for i := 0; i < len(key); i++ {
      hash ^= uint32(key[i]) // 先异或
      hash *= prime32        // 后乘
     }
     return hash
    }
    
    // 默认 hasher 实现
    func getDefaultHasher[K comparable]() func(K) uint32 {
     var k K
     switch any(k).(type) { // type switch
     case string:
      return func(key K) uint32 {
       s := any(key).(string) // type assert
       return fnv32(s)
      }
     case int:
      return func(key K) uint32 {
       i := any(key).(int)
       return uint32(i)
      }
     default:
      panic("unsupported key type, please provide custom hasher")
     }
    }
    
    func (m *ShardedMap[K, V]) getShard(key K) *Shard[K, V] {
     hash := m.hasher(key)
     return m.shards[hash%uint32(m.shardCount)]
    }
    
    func (m *ShardedMap[K, V]) Set(key K, value V) {
     shard := m.getShard(key)
     shard.Lock()
     defer shard.Unlock()
    
     shard.data[key] = value
    }
    
    func (m *ShardedMap[K, V]) Get(key K) (V, bool) {
     shard := m.getShard(key)
     shard.RLock()
     defer shard.RUnlock()
    
     value, ok := shard.data[key]
     return value, ok
    }
    
    func (m *ShardedMap[K, V]) Contains(key K) bool {
     shard := m.getShard(key)
     shard.RLock()
     defer shard.RUnlock()
    
     _, ok := shard.data[key]
     return ok
    }
    
    func (m *ShardedMap[K, V]) Delete(key K) {
     shard := m.getShard(key)
     shard.Lock()
     defer shard.Unlock()
    
     delete(shard.data, key)
    }
    
    func (m *ShardedMap[K, V]) Len() int {
     length := 0
     for i := 0; i < m.shardCount; i++ {
      m.shards[i].RLock()
      length += len(m.shards[i].data)
      m.shards[i].RUnlock()
     }
    
     return length
    }
    
    func benchmark() {
     const (
      numShards   = 64
      numRoutines = 1000
      numOps      = 10000
     )
    
     // 测试分片 map
     m := NewShardedMap[string, int](numShards, nil) // string->int
    
     start := time.Now()
     var wg sync.WaitGroup
    
     // 并发写入测试
     for i := range numRoutines {
      wg.Add(1)
      go func(id int) {
       defer wg.Done()
       for j := range numOps {
        key := fmt.Sprintf("key_%d_%d", id, j)
        m.Set(key, j)
       }
      }(i)
     }
     wg.Wait()
    
     duration := time.Since(start)
    
     p := message.NewPrinter(message.MatchLanguage("en"))                              // golang.org/x/text/message（标准库扩展）
     p.Printf("分片 map(string->int) 并发写入：%v 次, 耗时: %v\n", numRoutines*numOps, duration) // 按照 locale 规则格式化数字，英语用逗号分隔
    }
    
    func main() {
     benchmark()
    }
    ```

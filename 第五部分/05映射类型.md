# 映射类型（map）

Go 中映射类型的底层是哈希表，查找、插入、删除操作的平均时间复杂度为 `O(1)`，当发生大量哈希冲突时，性能会退化到 `O(n)`。

声明 Map 变量：`var 变量名 map[KeyType]ValueType`，注意：

- 键（Key）类型：必须可比较。基本类型（bool、int、float、complex、string 等）、指针、结构体（所有字段可比较）、数组（元素可比较）、接口（底层动态类型可比较，否则引发 panic）、通道（元素类型相同）可比较，切片、map、函数不可比较。浮点类型虽支持比较，但因精度问题不建议用作 map 的 key（NaN 作为 key 也有问题，因为 NaN != NaN）
- 值（Value）类型：任意类型。不允许获取 map 中 value 的地址（编译报错），因为 map 扩容时键值对重新分布，value 地址失效
- 遍历顺序：遍历时随机选择一个桶开始，逐个遍历桶和溢出桶，所以每次遍历的顺序都不固定，这是设计上有意为之

```go
func main() {
 m := map[string]int{
  "apple":  5,
  "banana": 3,
  "cherry": 7,
  "date":   9,
  "elder":  1,
 }

 // fmt.Printf("%p\n", &m["apple"]) // 不允许直接对 value 取地址，编译报错

 // 遍历三次，每次顺序可能不同
 for i := range 3 {
  fmt.Printf("round %d: ", i+1)
  for k, v := range m {
   fmt.Printf("%s:%d ", k, v)
  }
  fmt.Println()
 }
 // 可能的输出（每次运行顺序都不同）：
 // round 1: cherry:7 elder:1 apple:5 banana:3 date:9
 // round 2: banana:3 date:9 elder:1 cherry:7 apple:5
 // round 3: apple:5 cherry:7 date:9 banana:3 elder:1
}
```

Map 的零值为 nil，值为 nil 的 Map 中没有 key，也不能往其中添加键值对，会引发 panic。

## 创建 Map 的方式

## Map 字面量

```go
func main() {
 // 空 Map 字面量
 m := map[string]int{} // 创建一个空 Map（等价于 make(map[string]int)）
 m1["a"] = 1
 fmt.Println(m1) // map[a:1]

 // 声明并初始化一个 Map，键为 string，值为 int
 m = map[string]int{
  "apple":  5, // key 是必须的（对比：结构体字面量的 name 不是必须的）
  "banana": 3,
  "cherry": 7, // 最后一项的后面必须加逗号
 }
 fmt.Println(m) // map[apple:5 banana:3 cherry:7]

 // 嵌套字面量（Map 的值是结构体或另一个 Map）
 type Person struct {
  Age  int
  City string
 }

 people := map[string]Person{
  "alice": {Age: 30, City: "NYC"},
  "bob":   {Age: 25, City: "SF"},
 }
 fmt.Println(people) // map[alice:{30 NYC} bob:{25 SF}]

 // Map 的值也是 Map
 nested := map[string]map[string]int{
  "group1": {"a": 1, "b": 2},
  "group2": {"c": 3, "d": 4},
 }
 fmt.Println(nested) // map[group1:map[a:1 b:2] group2:map[c:3 d:4]]
}
```

注意事项：在字面量的最后一项后面必须加逗号，除非将所有项与 `{}` 写在一行，这是 Go 的语法规则。

## make 函数

内置函数 [make](https://pkg.go.dev/builtin#make) 可以创建 Map，有两种语法：

- `s := make(map[int]string)`，系统会自动分配一个较小的初始容量，在插入时 Map 会自动扩容以容纳更多元素
- `s := make(map[int]string, 10)`，第二个参数指定初始容量，能预估大小时指定初始容量可减少扩容次数

注意：make 函数返回的是第一个参数指定的 Map 类型，而不是 Map 指针。

```go
func main() {
 var m map[string]int
 if m == nil { // true
  fmt.Println("map is nil")
 }

 // m["a"] = 1 // 往 nil Map 中添加键值对，会引发 panic

 m = make(map[string]int) // make 函数
 m["a"] = 1
 fmt.Println(m) // map[a:1]

 m2 := make(map[string]int, 10) // make 函数，第二个参数指定 Map 的初始容量
 m2["a"] = 1
 fmt.Println(m2) // map[a:1]
 m2["a"] = 2     // key 已存在，value 会被覆盖为 2
 fmt.Println(m2) // map[a:2]
}
```

## Map 操作

## 插入或修改元素

`m[key] = value`，key 不存在时新增，key 存在时修改。m 为 nil 时会引发 panic。

## 获取元素

`v = m[key]`，key 不存在或 m 为 nil 时 v 为其类型的零值。

双赋值检测 key 是否存在：`v, ok := m[key]`，key 存在时 ok 为 true，不存在时 ok 为 false。

```go
func main() {
 m1 := make(map[string]int)
 fmt.Println(m1["Bell Labs"]) // 0

 if v, ok := m1["Bell Labs"]; ok {
  fmt.Println(v)
 } else { // true
  fmt.Println("not exist")
 }

 var m2 map[string]int    // m 为 nil
 fmt.Println(m2["apple"]) // 0

 v, ok := m2["apple"]
 fmt.Println(v, ok) // 0 false
}
```

## delete 删除元素

内置函数 [delete](https://pkg.go.dev/builtin#delete) 用于删除 Map 的元素：`delete(m, key)`，m 为 nil 或 key 不存在时什么都不做，不会引发 panic。

## clear 清空 Map

[clear](https://pkg.go.dev/builtin#clear) 是一个内置函数，函数原型：`func clear[T ~[]Type | ~map[Type]Type1](t T)`，参数只能是 Map 或切片。

- 对于 Map，clear 会删除所有键值对，结果是一个空 Map（`map[string]int{}`）
- 对于切片，clear 会将切片长度范围内的所有元素设置为其类型的零值。如果参数 t 为 nil，那么 clear 不会执行任何操作

```go
func main() {
 m := map[string]int{"apple": 5, "banana": 3, "cherry": 7}
 fmt.Println(m) // map[apple:5 banana:3 cherry:7]
 clear(m)
 fmt.Println(m) // map[]

 s := []int{1, 2, 3}
 fmt.Println(s)                              // [1 2 3]
 fmt.Printf("%v, len: %v, cap: %v\n", s, len(s), cap(s)) // [1 2 3] 3 3
 clear(s)
 fmt.Println(s)                              // [0 0 0]（元素被置零，长度不变）
 fmt.Printf("%v, len: %v, cap: %v\n", s, len(s), cap(s)) // [0 0 0] 3 3
}
```

## 遍历 Map

```go
func main() {
 m := map[string]int{
  "a": 1,
  "b": 2,
 }

 for k, v := range m { // k、v 都是副本
  fmt.Printf("key=%v, value=%v\n", k, v)
  v = 100 // v 是值的副本，修改 v 不会改变 map 中的 value
 }
}
```

range 迭代中可用 delete 函数删除当前迭代的键值对。删除当前迭代的元素不影响迭代器状态，循环按初始顺序继续；但删除尚未迭代的元素可能导致该元素被跳过。

```go
func main() {
 m := map[string]int{"apple": 1, "banana": 2, "orange": 3}
 for k, v := range m {
  if v == 2 {
   delete(m, k) // 安全删除当前迭代的元素
  }
 }
 fmt.Printf("%v\n", m) // map[apple:1 orange:3]

 m1 := map[string]int{"a": 1, "b": 2, "c": 3}
 for k := range m1 {
  fmt.Printf("访问: %s\n", k) // 可能只输出 "a" 和 "b"，"c" 被跳过

  if k == "b" {
   delete(m1, "c") // c 可能在 b 之前访问，也可能在 b 之后访问，因为每次迭代的顺序是随机的
  }
 }
 fmt.Printf("%v\n", m1) // map[a:1 b:2]

 m2 := map[string]int{"a": 1, "b": 2, "c": 3, "d": 4}
 fmt.Println("开始遍历")
 for k := range m2 {
  fmt.Printf("访问: %s\n", k) // 可能输出 "a"、"b"、"c" 或 "d"，只循环一次

  // 在第一次迭代时清空所有键值对
  clear(m2)
 }
 fmt.Printf("%v\n", m2) // map[]
}
```

应当避免在遍历 Map 时添加元素，在 for range 循环中向 Map 添加新的键值对的行为是未定义的（undefined behavior）。新添加的元素在本次迭代中可能被访问，也可能不被访问，取决于 Map 的扩容状态和具体实现。虽然一般不会引发 panic，但这种做法是不安全且不推荐的。

## Map 的 len

len 表示 Map 中的键值对个数，Map 不能取 cap，编译报错。

```go
func main() {
 var m map[string]int = map[string]int{"hello": 1}
 fmt.Println(len(m)) // len 表示 Map 中的键值对个数
 // fmt.Println(cap(m)) // Map 不能取 cap，编译报错
}
```

## Map 类型赋值、传参

Map 是引用类型，赋值和传参仍是值传递，但只会拷贝“引用头”，得到“引用头”的独立副本，它们引用的仍是同一个底层数据。可以认为 Map 的“引用头”是一个指向底层数据结构（maps.Map，源代码：`${GOROOT}/src/internal/runtime/maps/map.go`）的指针 `*maps.Map`。

```go
func main() {
 m1 := map[string]int{
  "a": 1,
  "b": 2,
 }
 // m2 := map[string]int{
 //  "a": 1,
 //  "b": 2,
 // }

 // if m1 == m2 { // 编译报错：map can only be compared to nil
 //  fmt.Println("m1 == m2")
 // }

 fmt.Println(unsafe.Sizeof(m1)) // 在 64 位操作系统上恒为 8，与 Map 中实际存储了多少个键值对无关，因为 Map 的“引用头”是一个指向底层数据结构的指针

 m3 := m1        // Map 变量赋值，m3 与 m1 共享底层数据结构
 fmt.Println(m1) // map[a:1 b:2]
 fmt.Println(m3) // map[a:1 b:2]

 m3["a"] = 100   // m3 修改了 a 的值，m1 也会改变
 fmt.Println(m1) // map[a:100 b:2]
 fmt.Println(m3) // map[a:100 b:2]

 f(m1)
 fmt.Println(m1) // map[a:200 b:2]

 g(m1)
 fmt.Println(m1) // map[a:200 b:2 i0:0 i1:1 i2:2 i3:3 i4:4 i5:5 i6:6 i7:7 i8:8 i9:9]
}

func f(m map[string]int) {
 m["a"] = 200 // Map 作为函数参数，在函数体中修改 Map 键值对会影响原始 Map
}

func g(m map[string]int) {
 for i := range 10 {
  m[fmt.Sprintf("i%d", i)] = i // 与切片扩容不同，Map 扩容时不会创建一个新的底层结构，所以 Map 作为函数参数时不需要使用指针类型
 }
}
```

## Map 比较

与切片一样，Map 只能与 nil 比较，不能通过 `==` 操作符来判断两个 Map 是否相等。因为不可比较，所以 Map 也不能作为 Map 的 key。

## 自定义类型作为 Map 的 key

只要自定义类型是可比较的（即支持 `==` 和 `!=` 操作），就可以作为 Map 的 key。

```go
// 定义结构体，所有字段都是可比较的类型，可以作为 Map 的键
type User struct {
 ID   string // string，可比较
 Name string // string，可比较
 Age  int    // int，可比较
 // s    []int // 切片类型，不可比较，不能作为 Map 的键
}

func main() {
 m := make(map[User]int) // user->score

 alice := User{"001", "Alice", 25}
 m[alice] = 88
 m[User{"002", "Bob", 30}] = 95

 if u, ok := m[alice]; ok {
  fmt.Printf("Alice's score: %d\n", u) // Alice's score: 88
 }
}
```

## 多级 Map

Map 的 value 可以是另一个 Map，用于构建多级索引等复杂数据结构：

```go
func main() {
 // 定义一个嵌套的 Map，表示不同城市的不同水果库存
 cityFruits := make(map[string]map[string]int) // 城市名->(水果名->库存)
 cityFruits["Beijing"] = map[string]int{"apple": 50, "banana": 30}
 cityFruits["Shanghai"] = map[string]int{"orange": 40, "pear": 20}

 // 访问嵌套 Map 的 value
 fmt.Println(cityFruits["Beijing"]["apple"]) // 输出：50
}
```

## 复合字面量语法糖

在写数组、切片或映射类型的复合字面量时，如果里面的元素或映射的键本身也是复合字面量，并且它的类型跟外层容器的元素/键类型完全一样，那类型名可以整个省掉，直接写 `{...}` 就行。同理，如果外层容器装的是指针类型（比如 `[]*T`），直接往里写一个 `{...}`，Go 会隐式地取地址并构造指针。注意：这个省略只在类型严格匹配时才允许。

```go
type Point struct{ X, Y int }

type Animal interface{ Speak() }
type Dog struct{ Name string }

func (d Dog) Speak() {}

func main() {
 // 外层 []Point，内层也是 Point -> 省掉 Point
 points := []Point{
  {X: 1, Y: 2},
  {X: 3, Y: 4},
 }
 fmt.Println(points)

 // 外层 []*Point，内层隐式 &Point -> 省掉 &Point
 nodes := []*Point{
  {X: 10, Y: 20},
  {X: 30, Y: 40},
 }
 fmt.Println(nodes)

 // map 的键同理
 m := map[Point]int{
  {X: 1, Y: 2}: 100, // 省掉 Point
 }
 fmt.Println(m)

 //  不能省：类型不匹配
 // 外层是 Animal（接口），内层是 Dog（具体类型）-> 不能省
 animals := []Animal{
  Dog{Name: "Fido"}, // 必须写 Dog，不能只写 {Name: "Fido"}
 }
 fmt.Println(animals)
}
```

## 并发安全

Map 不是并发安全的，如果多个 Goroutine 同时读写一个 Map，会引发“fatal error: concurrent map writes”panic。解决方案主要有三种：

- 使用 sync.Mutex（互斥锁）或 sync.RWMutex（读写锁，适用于读多写少的场景）来封装对 Map 的访问
- Go 1.9+ 标准库提供并发安全的 sync.Map，其接口和性能特性与普通 Map 不同，更适用于键值对相对稳定、读多写少的特定场景，在特定场景下比“Mutex + 普通 Map”的性能更好
- 分片锁（Sharding）：对于超大规模、超高并发的场景，可以将一个大 Map 分成多个小 Map，每个小 Map 用自己的锁，可以极大降低锁的竞争，提升性能 todo

    ```go
    // ShardedMapGeneric 支持泛型的分片 Map
    type ShardedMapGeneric[K comparable, V any] struct {
     shards     []*ShardGeneric[K, V] // 每个切片元素就是一个分片（独立的 Map）
     shardCount int                   // 表示分片的数量，每个分片对应一个独立的 Map
     hasher     func(K) uint32        // 哈希函数，决定 key 分配到哪个分片：hash(key) % shardCount
    }
    
    type ShardGeneric[K comparable, V any] struct {
     data map[K]V
     sync.RWMutex
    }
    
    // NewShardedMapGeneric 创建泛型分片 Map
    func NewShardedMapGeneric[K comparable, V any](shardCount int, hasher func(K) uint32) *ShardedMapGeneric[K, V] {
     if shardCount <= 0 {
      shardCount = 32
     }
    
     if hasher == nil {
      // 默认 hasher，支持 string 和整数类型
      hasher = getDefaultHasher[K]()
     }
    
     shards := make([]*ShardGeneric[K, V], shardCount)
     for i := 0; i < shardCount; i++ {
      shards[i] = &ShardGeneric[K, V]{
       data: make(map[K]V),
      }
     }
    
     return &ShardedMapGeneric[K, V]{
      shards:     shards,
      shardCount: shardCount,
      hasher:     hasher,
     }
    }
    
    // fnv32 FNV-1a 哈希函数
    func fnv32(key string) uint32 {
     hash := uint32(2166136261)       // FNV offset basis（初始值）
     const prime32 = uint32(16777619) // FNV prime（质数）
     for i := 0; i < len(key); i++ {
      hash ^= uint32(key[i]) // 先异或
      hash *= prime32        // 后乘
     }
     return hash
    }
    
    // 默认 hasher 实现
    func getDefaultHasher[K comparable]() func(K) uint32 {
     var k K
     switch any(k).(type) {
     case string:
      return func(key K) uint32 {
       s := any(key).(string)
       return fnv32(s)
      }
     case int:
      return func(key K) uint32 {
       i := any(key).(int)
       return uint32(i)
      }
     default:
      panic("unsupported key type, please provide custom hasher")
     }
    }
    
    func (m *ShardedMapGeneric[K, V]) getShard(key K) *ShardGeneric[K, V] {
     hash := m.hasher(key)
     return m.shards[hash%uint32(m.shardCount)]
    }
    
    func (m *ShardedMapGeneric[K, V]) Set(key K, value V) {
     shard := m.getShard(key)
     shard.Lock()
     defer shard.Unlock()
    
     shard.data[key] = value
    }
    
    func (m *ShardedMapGeneric[K, V]) Get(key K) (V, bool) {
     shard := m.getShard(key)
     shard.RLock()
     defer shard.RUnlock()
    
     value, exists := shard.data[key]
     return value, exists
    }
    
    func (m *ShardedMapGeneric[K, V]) Contains(key K) bool {
     shard := m.getShard(key)
     shard.RLock()
     defer shard.RUnlock()
    
     _, exists := shard.data[key]
     return exists
    }
    
    func (m *ShardedMapGeneric[K, V]) Delete(key K) {
     shard := m.getShard(key)
     shard.Lock()
     defer shard.Unlock()
    
     delete(shard.data, key)
    }
    
    func (m *ShardedMapGeneric[K, V]) Len() int {
     length := 0
     for i := 0; i < m.shardCount; i++ {
      m.shards[i].RLock()
      length += len(m.shards[i].data)
      m.shards[i].RUnlock()
     }
    
     return length
    }
    
    func benchmark() {
     const (
      numShards   = 64
      numRoutines = 1000
      numOps      = 10000
     )
    
     // 测试分片 Map
     shardedMap := NewShardedMapGeneric[string, int](numShards, nil)
    
     start := time.Now()
     var wg sync.WaitGroup
    
     // 并发写入测试
     for i := range numRoutines {
      wg.Add(1)
      go func(id int) {
       defer wg.Done()
       for j := range numOps {
        key := fmt.Sprintf("key_%d_%d", id, j)
        shardedMap.Set(key, j)
       }
      }(i)
     }
     wg.Wait()
    
     duration := time.Since(start)
     fmt.Printf("分片 map 写入：%v operations, time: %v\n", numRoutines*numOps, duration)
    
    }
    
    func main() {
     benchmark()
    }
    ```

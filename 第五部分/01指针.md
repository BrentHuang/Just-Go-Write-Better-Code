## 指针类型

类型 `*T` 表示指向 `T` 类型值的指针，指针变量的值是一个内存地址。特别注意：`T` 与 `*T` 是两种不同的类型，一般称 `T` 为值类型，称 `*T` 为指针类型。

两个运算符：

- `&` 取地址：获取变量的内存地址，返回指向该变量的指针
- `*` 解引用：访问指针指向的底层值，可通过 `*p` 读取和修改

指针的零值为 nil，解引用 nil 指针会引发 panic。使用指针前（尤其来源于外部输入时）应判断是否为 nil。

在 64 位操作系统上，指针的 unsafe.Sizeof 恒为 8。

### 指针与结构体、切片、映射、接口类型

将函数参数定义为指针类型，除了可在函数体中修改传入的数据，还能避免拷贝大型数据结构。但基本类型（bool、int、float64、string）或小型结构体（仅包含 1、2 个基本类型字段）值传递的拷贝开销很小，使用指针反而可能增加 GC 压力（GC 需追踪堆上每个指针）且对 CPU 缓存不友好（指针间接寻址）。通常除非有明确的修改或共享需求，基本类型和小型结构体优先考虑值类型。

切片、映射、接口类型本身已是引用类型，通常不需要指针。例外：需要在函数体中修改传入的原始切片本身（如重新分配、`append` 触发扩容后需要更新调用方的切片头）时，应传 `*[]T`。

### 指针类型转换

unsafe.Pointer 可与任意类型的指针互转（慎用）：

```go
func main() {
 var f float64 = 3.1415
 bits := *(*uint64)(unsafe.Pointer(&f))  // 将 *float64 类型转换成 *uint64 类型
 fmt.Println(bits)                       // 4614256447914709615
 u := uint64(f)
 fmt.Println(u)  // 3

 // p := (*uint64)(&f) // 这样直接将 *float64 类型转换成 *uint64 类型是不行的，编译报错
}
```

### 二级指针 `**T`

指向指针的指针：`var pp **int`，`**T` 与 `*T` 也是不同的类型。

```go
func main() {
 var a int
 var p *int
 var pp **int

 a = 3000

 p = &a
 fmt.Printf("%T\n", p)  // *int

 pp = &p
 fmt.Printf("%T\n", pp)  // **int

 /* 获取 pp 的值 */
 fmt.Printf("变量 a = %d\n", a)
 fmt.Printf("指针变量 *p = %d\n", *p)
 fmt.Printf("指向指针的指针变量 **pp = %d\n", **pp)  // 访问指向指针的指针变量值需要使用两个 * 号
}
```

### 指针算术运算

与 C 语言不同，Go 普通指针不支持算术运算（如 `p++`、`p+offset` 会编译报错），可转换为 uintptr 类型进行运算，但已被 unsafe.Add 替代。

```go
// 该函数仅演示通过 uintptr 进行指针运算，无实际意义
func getSecondElementPtrOld(arr []int) *int {
 p1 := unsafe.Pointer(&arr[0])                             // 获取第一个元素的地址
 p2 := unsafe.Pointer(uintptr(p1) + unsafe.Sizeof(arr[0])) // 转换为 uintptr 进行运算，然后立即转换回 unsafe.Pointer
 return (*int)(p2)                                         // 转换回 *int
}

func getSecondElementPtrMorden(arr []int) *int {
 p1 := unsafe.Pointer(&arr[0])               // 获取第一个元素的地址
 p2 := unsafe.Add(p1, unsafe.Sizeof(arr[0])) // 直接使用 unsafe.Add 进行指针运算，等价于上面的代码
 return (*int)(p2)                           // 转换回 *int
}

func main() {
 arr := []int{1, 2, 3, 4, 5}
 second := getSecondElementPtrOld(arr)
 fmt.Println(*second) // 2

 second = getSecondElementPtrMorden(arr)
 fmt.Println(*second) // 2
}
```

# 结构体类型

结构体是一组相关字段的聚合体，其中各个字段的类型往往不同。用 `type 结构体名 struct` 定义结构体类型：

```go
// 定义结构体类型 Vertex
type Vertex struct {
 X int // 字段名 类型
 Y int
}
```

也可以在一行声明多个同类型的字段，字段之间用逗号分隔。

```go
type Vertex struct {
 X, Y int // 在一行声明多个同类型的字段
}
```

通过点号访问结构体字段：`结构体变量.字段名`。如果有一个指向结构体的指针 p，那么可以通过 `(*p).X` 来访问其字段 X。这种方式书写较为繁琐，直接写 `p.X` 即可（隐式解引用），注意不是 C 语言那样的 `p->X`。

结构体的零值是其所有字段的零值构成的结构体。

## 构造结构体

结构体、数组、切片、映射这些复合类型使用 `类型名{}` 构造字面量，称为复合字面量。`{}` 中是元素列表，每个元素是键值对或纯值。

```go
type Vertex struct {
 X, Y int // 在一行声明多个同类型的字段
}

func main() {
 var (
  // 方式 1【推荐】：指定字段名初始化，字段的顺序无关紧要。未设置的字段会被隐式初始化为其类型的零值
  v1 = Vertex{X: 12} // Y 被隐式初始化为其类型的零值

  // 方式 2：不指定任何字段，所有字段都被隐式初始化为其类型的零值
  v2 = Vertex{} // X:0, Y:0

  // 方式 3：按字段顺序初始化。注意：所有字段必须全部初始化，否则编译报错
  v3 = Vertex{11, 21}

  p = &Vertex{3, 4} // 前缀 & 返回指向结构值的指针
 )

 v2.X = 100
 p.Y = 100

 // 方式 4：先声明后赋值，可以只给部分字段赋值，未赋值的字段会被隐式初始化为其类型的零值
 var v4 Vertex
 v4.X = 13

 // 方式 5：使用 new() 函数。不常用
 p1 := new(Vertex)
 p1.X = 100
 p1.Y = 100

 fmt.Printf("%v %v %v %v %v %v\n", v3, v1, v2, v4, *p, *p1) // 输出： {11 21} {12 0} {100 0} {13 0} {3 100} {100 100}
}
```

### 结构体工厂函数（构造函数）

- 命名约定：使用 `New` 前缀，如 `NewPerson`
- 错误处理：重要初始化应返回 `(T, error)` 或 `(*T, error)` 双返回值
- 单一职责：一个工厂函数只负责一种构造逻辑
- 必要验证：在工厂函数体中进行参数验证

```go
type Person struct {
 Name string
 Age  int
 City string
}

// 结构体工厂函数，返回值可以是指针，也可以是值，依实际情况而定
func NewPerson(name string, age int, city string) *Person {
 return &Person{Name: name, Age: age, City: city} // 用复合字面量构造结构体
}
```

不同于 C++ 中的构造函数，结构体工厂函数在 Go 中不会被自动调用，它们是普通的函数，需要显式调用才能创建结构体实例。

## 结构体字段的可见性

结构体字段名首字母大小写决定其可见性（是否导出）。

```go
// ${PROJ_ROOT}/mypkg/mypkg.go
package mypkg

type MyStruct struct {
 PublicField  int    // 导出的，其它包可访问
 privateField string // 未导出，仅限当前包内访问
}

func Foo() MyStruct {
 s := MyStruct{}
 s.PublicField = 10
 s.privateField = "secret"  // 包内可访问未导出的字段
 return s
}

// ${PROJ_ROOT}/main.go
package main

import (
 "fmt"

 "example.com/hello-world/mypkg" // example.com/hello-world 是模块路径
)

func main() {
 s := mypkg.MyStruct{}
 s.PublicField = 10         // 允许在包外访问结构体的导出字段
 s.privateField = "secret"  // 未导出的字段不能在包外访问，编译报错：cannot refer to unexported field privateField

 s1 := mypkg.Foo()
 fmt.Println(s1)  // {10 secret}
}
```

## 结构体组合（命名嵌入、匿名嵌入）

Go 推崇组合而非继承。Go 没有传统的类继承，而是通过结构体嵌入来实现代码复用（本质是“组合”），分为命名字段嵌入与匿名字段嵌入。

- 命名字段嵌入：`字段名 结构体值类型或指针类型`，比较常见
- 匿名字段嵌入：`结构体值类型或指针类型`，只有结构体值类型或指针类型，没有字段名（在底层，字段名与结构体名相同）

```go
type Person struct {
 Name string
 Age  int
 City string
}

type Employee struct {
 // Person // 匿名嵌入 Person 字段，结构体值类型。只有结构体值类型或指针类型，没有字段名
 *Person  // 匿名嵌入 *Person 字段，结构体指针类型
 JobTitle string
 Salary   float64
}

func main() {
 person := Person{}
 fmt.Printf("%+v\n", person) // {Name: Age:0 City:}
 fmt.Printf("%#v\n", person) // main.Person{Name:"", Age:0, City:""}

 e := Employee{
  Person: &Person{ // 不管是值类型还是指针类型，匿名嵌入字段名与结构体名相同，也为 Person
   Name: "Dave",
   Age:  40,
   City: "Berlin",
  },
  JobTitle: "Developer",
  Salary:   80000,
 }
 fmt.Printf("%+v\n", e) // {Person:0xe53608d00f0 JobTitle:Developer Salary:80000}
 fmt.Printf("%#v\n", e) // main.Employee{Person:(*main.Person)(0xe53608d00f0), JobTitle:"Developer", Salary:80000}

 fmt.Println(e.Name)        // 可以直接访问匿名嵌入字段的成员，而不需要给出完整的路径，这是因为匿名嵌入字段 Person/*Person 的成员被提升到了 Employee 中，就像它们是 Employee 自己的成员一样，可通过 Employee 类型的变量直接访问
 fmt.Println(e.Person.Name) // 也可以通过匿名嵌入字段名（即结构体名）间接访问嵌入字段的成员
}
```

匿名嵌入 `Person`/`*Person` 后，`Person` 结构体的字段和方法被提升（promoted）到了外层结构体 `Employee` 中，可通过 `Employee` 类型的变量直接访问，不必通过 `e.Person.` 间接访问。

若 `Employee` 中的 `Person` 字段为 `Person Person`（命名字段嵌入，变量名与类型名相同），则只能通过 `e.Person.` 访问嵌入的属性和方法。

### 成员提升

在 Go 中，当将一个结构体 `Inner` 匿名嵌入到另一个结构体 `Outer` 时，`Outer` 会自动获得 `Inner` 的所有字段和方法，这被称为“成员提升”（promoted fields and methods）。

提升并非“复制”，它更像是一种“委托”机制，当通过 `Outer` 类型的变量调用 `Inner` 的方法时，Go 实际上是将调用转发给了内嵌的 `Inner` 字段。

```go
type Inner struct {
 name string
}

type Outer struct {
 Inner
 name string
}

func (i Inner) Name() string {
 return i.name
}

func (o Outer) Name() string {
 return o.name
}

func main() {
 o := Outer{Inner{"inner"}, "outer"}

 fmt.Println(o.name)       // outer
 fmt.Println(o.Inner.name) // inner

 fmt.Println(o.Name())       // outer
 fmt.Println(o.Inner.Name()) // inner
}
```

字段遮蔽（field shadowing）：

- `o.name` 输出 "outer"：当外部结构体 `Outer` 定义了与匿名内嵌结构体 `Inner` 同名的字段时，直接通过外部结构体类型的变量访问（如 `o.name`）会优先获取外部结构体的字段。这种现象称为字段遮蔽，即 `Outer` 中的字段遮蔽了从 `Inner` 提升的同名字段
- `o.Inner.name` 输出 "inner"：通过显式指定内嵌结构体字段的完整路径，可以绕过字段遮蔽访问内嵌结构体 `Inner` 的字段

方法覆盖（method overriding）：

- `o.Name()` 输出 "outer"：当外部结构体 `Outer` 定义了与匿名内嵌结构体 `Inner` 同名的方法时，直接通过外部结构体类型的变量调用（如 `o.Name()`）会优先调用外部结构体的方法。这种现象称为方法覆盖，即 `Outer` 中的方法覆盖了从 `Inner` 提升的同名方法
- `o.Inner.Name()` 输出 "inner"：通过显式指定内嵌结构体方法的完整路径，可以绕过方法覆盖调用内嵌结构体 `Inner` 的方法

被遮蔽的字段和被覆盖的方法并未真正“删除”，通过显式完整路径（如 `o.Inner.name`、`o.Inner.Name()`）仍可访问它们。

### 注意事项

匿名字段嵌入是一种“语法糖式”的继承，虽然底层是组合，但匿名字段嵌入写起来、用起来很像继承：通过 `e.Name` 直接访问匿名嵌入字段 `Person`/`*Person` 的成员，好像 `Employee` “继承”了 `Person` 的成员一样。从这个角度而言，匿名字段嵌入在一定程度上破坏了封装性。

对于非导出的包内结构体，应当谨慎使用匿名嵌入。核心判断标准：匿名嵌入后，被提升的方法是否表达了外层结构体自身的“能力”？是，则使用匿名嵌入；否，则使用命名字段嵌入。典型场景就是 sync.Mutex：

```go
// cache 是非导出的包内结构体
type cache struct {
 sync.Mutex // 匿名嵌入
 m          map[string]string
}

var c = cache{m: make(map[string]string)}

func Lookup(key string) string {
 c.Lock()
 defer c.Unlock()
 v := c.m[key]
 return v
}
```

`cache` 结构体匿名嵌入 `sync.Mutex` 后，其`Lock()`、`Unlock()` 方法直接提升到 `cache` 上，调用方可以写 `c.Lock()` 而不是 `c.mu.Lock()`。这表达了一个语义：“`cache` 这个类型本身就具备加锁能力”，而不是“`cache` 内部有一个锁”。

对于导出的结构体，不推荐使用匿名嵌入来“继承”行为，而要用“命名私有字段 + 手写委派方法”，因为外部调用者不知道哪些方法是结构体自己提供的，哪些是从匿名嵌入字段提升上来的；并且匿名嵌入的类型一旦升级，可能意外引入新的方法，影响 API 的清晰性和稳定性。导出的结构体匿名嵌入接口类型而不是具体类型是“可接受”的，但需要理解其语义是“将接口的能力（方法集）并到外层结构体”，而不是“继承”接口的方法；外层结构体声明它“实现”了这些接口（本质是方法提升带来的隐式满足），但接口的具体实现需要在运行时提供。

导出的结构体匿名嵌入接口：

```go
// Logger 接口
type Logger interface {
 Info(msg string)
 Error(msg string)
}

// Metrics 接口
type Metrics interface {
 IncCounter(name string)
}

// zapLogger 实现了 Logger 接口（仅模拟）
type zapLogger struct{}

func (l zapLogger) Info(msg string)  { fmt.Printf("%v\n", msg) }
func (l zapLogger) Error(msg string) { fmt.Printf("%v\n", msg) }

// promMetrics 实现了 Metrics 接口（仅模拟）
type promMetrics struct{}

func (m promMetrics) IncCounter(name string) { fmt.Printf("%v\n", name) }

// 匿名嵌入接口，而不是具体类型
type App struct {
 Logger  // 接口：只声明“我需要 Logger 的能力”
 Metrics // 接口：只声明“我需要 Metrics 的能力”
}

func main() {
 a := &App{
  Logger:  zapLogger{}, // 运行时注入具体实现
  Metrics: promMetrics{},
 }
 a.Info("started")        // 调用的是注入的 zapLogger 的方法
 a.IncCounter("requests") // 调用的是注入的 promMetrics 的方法
}
```

## 结构体类型赋值、传参

结构体是值类型，赋值和传参是值传递，会拷贝整个结构体（浅拷贝），得到的是原始结构体的一个副本，与原始结构体完全独立。

如果结构体中包含切片、映射等引用类型的字段，那么拷贝的只是这些字段的“引用头”，副本字段和原始结构体字段共享同一个底层数据。

大型结构体传值会产生较大的拷贝开销，应通过指针传递。

```go
type S struct {
 A string
 B int
}

func modifyStruct(s S) { // 函数参数为值类型
 s.A = "sa" // 在函数体中修改的是原始结构体的副本，不影响原始结构体
}

func modifyStructWithPointer(s *S) { // 函数参数为指针类型
 s.A = "ga" // 通过指针修改的是原始结构体
}

func main() {
 s1 := S{A: "a", B: 1}

 s2 := s1        // 结构体变量赋值，会创建一个新的结构体（副本），与原始结构体独立
 fmt.Println(s1) // {a 1}
 fmt.Println(s2) // {a 1}

 s2.A = "b"      // 修改新结构体的字段，不会影响原始结构体
 fmt.Println(s1) // {a 1} --未改变
 fmt.Println(s2) // {b 1}

 modifyStruct(s2)
 fmt.Println(s2) // {b 1} --未改变
 modifyStructWithPointer(&s2)
 fmt.Println(s2) // {ga 1}
}
```

## 空结构体

空结构体不占用内存空间，常用于信号传递：

```go
func main() {
 var empty1 struct{}                             // 空结构体
 fmt.Printf("size: %d\n", unsafe.Sizeof(empty1)) // size: 0

 // 空结构体常用于通道信号传递
 signal := make(chan struct{})
 go func() {
  // 做一些工作
  signal <- empty1
 }()
 fmt.Printf("signal: %#v\n", <-signal) // signal: struct {}{}

 empty2 := struct{}{}                            // 空结构体
 fmt.Printf("size: %d\n", unsafe.Sizeof(empty2)) // size: 0

 go func() {
  signal <- empty2
 }()
 fmt.Printf("signal: %#v\n", <-signal) // signal: struct {}{}
}
```

## 结构体比较

结构体的所有字段都可比较时（如 bool、整型、string、指针类型，不包括切片、映射、函数类型），结构体本身也可比较，可比较的结构体可以作为映射的 key。

## 结构体标签

结构体标签（struct tags）是附加在结构体字段声明后的元数据，是一个原始字符串字面量（反引号），用于为字段提供额外的控制信息。这些标签不会影响程序逻辑，但可以被反射机制读取，广泛应用于序列化、ORM 等场景。

```go
type User struct {
 ID       int    `json:"id" db:"user_id"`
 Name     string `json:"name" db:"username"`
 Password string `json:"-" db:"password"` // "-" 表示 JSON 编解码时始终忽略该字段
}
```

结构体标签规则：

- 反引号中是 `key:"value"` 键值对格式，多个键值对用空格分隔
- key 命名约定：单词全小写，单词之间用下划线、中划线分隔，或连写在一起均可，key 不加双引号
- value 格式：value 是一个字符串，要加双引号，其中可以包含多个用逗号分隔的选项

特殊的 value 值（选项）：

- `"-"`：表示编解码时始终忽略该字段
- `"omitempty"`：如果字段值为 `empty`，即为 false、0、nil 指针、nil 接口或长度为零的字符串、数组、切片、映射，则编解码时忽略（omit）该字段。文档：<https://pkg.go.dev/encoding/json#Marshal>
- `"omitzero"`（Go 1.22 引入）：如果字段值为 `zero`，即：
  1. 如果字段类型具有 `IsZero() bool` 方法，将使用该方法来确定值是否为零
  2. 如果字段值为其类型的零值，则编解码时忽略该字段

如果同时指定了 `omitempty` 和 `omitzero`，则字段值只要满足 `empty` 或 `zero`，或同时满足这两个条件，就会被忽略。

### 结构体与 JSON 之间的序列化与反序列化

结构体标签的 key 固定为 `json`，value 用于控制标准库 [encoding/json](https://pkg.go.dev/encoding/json) 包的编解码行为。value 中的第一部分用于指定字段在 JSON 字符串中的名字；如果不指定，则与结构体字段名相同。

- [func Marshal(v any) ([]byte, error)](https://pkg.go.dev/encoding/json#Marshal) 将结构体 v（传值、传指针均可，大型结构体传指针可以减少拷贝开销）序列化为 JSON 字符串，返回字节切片
- [func Unmarshal(data []byte, v any) error](https://pkg.go.dev/encoding/json#Unmarshal) 将 JSON 字符串（字节切片）反序列化为结构体，v 要传入结构体指针

Marshal 是编排、整理、编组的意思，在编程语境中指的是把内存中的数据结构整理成可以传输或存储的字节序列。

注意：私有字段不会被序列化和反序列化。

```go
func main() {
 type User struct {
  Name  string `json:"name"` // 结构体的 Name 字段在 JSON 字符串中的名字为 name
  Email string `json:"email"` // 结构体的 Email 字段在 JSON 字符串中的名字为 email
  age   int    `json:"age"` // 私有字段，不会被序列化和反序列化，即使写了结构体标签
 }

 user := User{"Alice 哥哥", "alice@example.com", 18}
 data, err := json.Marshal(&user) // 传值、传指针均可，推荐传指针。紧凑形式的 json
 if err != nil {
  fmt.Printf("json marshaling failed, err: %v\n", err)
  os.Exit(1)
 }
 fmt.Println(string(data)) // {"name":"Alice 哥哥","email":"alice@example.com"}  --没有 age 字段

 data, err = json.MarshalIndent(&user, "", "  ") // 缩进形式的 json
 if err != nil {
  fmt.Printf("json marshaling failed, err: %v\n", err)
  os.Exit(1)
 }
 fmt.Println(string(data))

 // 将 JSON 字符串反序列化为结构体
 s := `{"name":"Bob 弟弟","email":"bob@example.com","age":18}`
 var u User
 err = json.Unmarshal([]byte(s), &u) // 传指针
 if err != nil {
  fmt.Printf("json unmarshaling failed, err: %v\n", err)
  os.Exit(1)
 }
 fmt.Printf("%#v\n", u) // main.User{Name:"Bob 弟弟", Email:"bob@example.com", age:0}  --age 为 0，而不是 18
}
```

`string` 选项：在 JSON 编解码中，`string` 选项的作用是强制将一个 Go 的基本类型值编码成带双引号的 JSON 字符串，而不是它默认对应的 JSON 类型。`string` 选项仅对 bool、整型、浮点型、string 这几种基本类型的字段有效，对于 bool 和数字类型，表现为加双引号（如 `false` -> `"false"`，`123` -> `"123"`），可避免数字精度丢失；对于 string 类型，会将内容先做一次 JSON 编码，再将结果作为 JSON 字符串存储（双重编码，如 `""` -> `"\"\""`）

```go
func main() {
 type Book struct {
  Title    string   `json:"title"`             // 结构体的 Title 字段在 JSON 字符串中的名字为 title
  Author   string   `json:"author,omitempty"`  // Author 值为 empty 时忽略该字段。value 中的多个选项用逗号分隔
  Pages    int      `json:"pages,string"`      // Pages 本来是 int 类型，string 选项表示将该字段编解码成带双引号的 JSON 字符串，而不是整数
  Secret   string   `json:"-"`                 // 编解码时始终忽略该字段
  Actors   []int    `json:"actors,omitempty"`  // Actors 值为 empty 时忽略该字段
  Comments []string `json:"comments,omitzero"` // Comments 值为 zero 时忽略该字段
  Flag     bool     `json:"flag,string"`       // flag 本来是 bool 类型，string 选项表示将该字段编解码成带双引号的 JSON 字符串，而不是布尔值
  Str      string   `json:",string"`           // json 的 value 中的第一部分为空，表示使用结构体字段名 Str 作为该字段在 JSON 字符串中的名字
 }

 {
  b := Book{Title: "go programming"}
  data, _ := json.Marshal(&b)
  fmt.Println(string(data)) // {"title":"go programming","pages":"0","flag":"false","Str":"\"\""}
  // 输出的 pages 为 "0"，而不是 0；flag 为 "false"，而不是 false，Str 为 "\"\""，而不是 ""，这是 string 选项的作用
  // 如果 Pages、Flag、Str 字段不指定 string 选项，则输出：{"title":"go programming","pages":0,"flag":false,"Str":""}
 }

 {
  b := Book{Title: "go programming", Comments: []string{}}
  data, _ := json.Marshal(&b)
  fmt.Println(string(data)) // {"title":"go programming","pages":"0","comments":[],"flag":"false","Str":"\"\""}
  // 与上面的输出相比，comments 字段被包含在输出中，因为 omitzero 选项仅在字段值为零值时才会忽略该字段，而长度为 0 的空切片不是切片类型的零值 nil
 }
}
```

### 字段验证

结构体标签的 key 固定为 `validate`，文档：<https://github.com/go-playground/validator>

```go
import (
 "errors"
 "fmt"

 "github.com/go-playground/validator/v10"
)

// User contains user information
type User struct {
 FirstName      string     `validate:"required"`
 LastName       string     `validate:"required"`
 Age            uint8      `validate:"gte=0,lte=130"`
 Email          string     `validate:"required,email"`
 Gender         string     `validate:"oneof=male female prefer_not_to"`
 FavouriteColor string     `validate:"iscolor"`                // alias for 'hexcolor|rgb|rgba|hsl|hsla'
 Addresses      []*Address `validate:"required,dive,required"` // a person can have a home and cottage...
}

// Address houses a users address information
type Address struct {
 Street string `validate:"required"`
 City   string `validate:"required"`
 Planet string `validate:"required"`
 Phone  string `validate:"required"`
}

// use a single instance of Validate, it caches struct info
var validate *validator.Validate

func main() {
 validate = validator.New(validator.WithRequiredStructEnabled())

 validateStruct()
 validateVariable()
}

func validateStruct() {
 address := &Address{
  Street: "Eavesdown Docks",
  Planet: "Persphone",
  Phone:  "none",
  // 缺少必填的 City 字段
 }

 user := &User{
  FirstName:      "Badger",
  LastName:       "Smith",
  Age:            135, // 超出了最大值 130
  Gender:         "male",
  Email:          "Badger.Smith@gmail.com",
  FavouriteColor: "#000-", // 颜色格式错误，后面多了一个 '-'
  Addresses:      []*Address{address},
 }

 // returns nil or ValidationErrors ( []FieldError )
 err := validate.Struct(user)
 if err != nil {
  if _, ok := errors.AsType[*validator.InvalidValidationError](err); ok {
   fmt.Println(err)
   return
  }

  if validateErrs, ok := errors.AsType[validator.ValidationErrors](err); ok {
   for _, e := range validateErrs {
    fmt.Println(e.Namespace())
    fmt.Println(e.Field())
    fmt.Println(e.StructNamespace())
    fmt.Println(e.StructField())
    fmt.Println(e.Tag())
    fmt.Println(e.ActualTag())
    fmt.Println(e.Kind())
    fmt.Println(e.Type())
    fmt.Println(e.Value())
    fmt.Println(e.Param())
    fmt.Println()
   }
  }

  // from here you can create your own error messages in whatever language you wish
  return
 }

 // save user to database
}

func validateVariable() {
 myEmail := "joeybloggs.gmail.com"

 errs := validate.Var(myEmail, "required,email")
 if errs != nil {
  fmt.Println(errs) // Key: '' Error:Field validation for '' failed on the 'email' tag
  return
 }
}
```

## 结构体递归

结构体 `S` 不能包含自身类型的成员（聚合值不能包含自身），数组同理。但可包含 `*S` 指针类型成员，从而支持创建递归数据结构（链表、树）。

```go
func main() {
 {
  // 编译报错：循环定义
  type Foo struct {
   Foo
  }

  // OK
  type Bar struct {
   *Bar
  }
 }

 {
  // 编译报错：循环定义
  type Foo [5]Foo

  // OK
  type Bar [5]*Bar
 }
}
```

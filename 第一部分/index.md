# 第一部分

## 概览

本部分介绍 Go 语言开发的基础环境搭建与工程化实践，涵盖开发环境配置、项目与源文件组织、包与模块管理，以及 Go 工具链的使用。掌握这些内容后，读者将能够独立完成 Go 项目的初始化、依赖管理与构建部署。

## 章节导航

| 章节 | 核心内容 | 学习目标 |
| -- | -- | -- |
| [01 开发环境](01开发环境.md) | Go 安装、关键环境变量（GOROOT、GOPATH、GOTOOLCHAIN、GOPROXY）与命令行补全等工具管理 | 搭建可用的 Go 开发环境，并配置模块代理加速依赖下载 |
| [02 项目与源文件](02项目与源文件.md) | 项目命名、源文件命名与结构、注释规范，gofmt 等格式化与静态检查工具 | 按照社区惯例组织项目与源文件，写出规范、可检查的代码 |
| [03 包](03包.md) | 包的概念、包级初始化、命名、导出规则、导入方式、内部包与循环导入 | 理解包作为 Go 代码组织与复用基本单元的工作原理 |

## 学习路径与前置知识

- 本部分为零基础起点，不要求读者预先掌握 Go 语法；但具备任意一门编程语言的使用经验（命令行操作、环境变量、编译与运行）会有帮助。
- 建议按章节顺序学习：开发环境、项目与源文件、包、模块、多模块开发、Go 工具链。
- 其中“包”与“模块”是理解后续所有示例的基础，务必优先掌握；“多模块开发”与“Go 工具链”属进阶内容，可在完成第二部分之前选学，也可待全书通读后回顾。
- 本部分完成后的 Hello World 项目将作为后续章节示例代码的基础载体。

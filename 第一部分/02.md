# 项目与源文件

## 项目命名

按社区惯例，项目名（仓库名）使用全小写单词，单词之间以中划线 `-` 分隔。示例：

- [go-ethereum](https://github.com/ethereum/go-ethereum) 以太坊客户端（区块链）
- [go-micro](https://github.com/micro/go-micro) 微服务开发框架

Go 工具链不强制约束项目名，模块路径（`go.mod` 中 `module` 声明的值）才是 Go 识别模块的唯一标识。

## 源文件

### 源文件命名

- 文件名使用全小写单词，单词之间不使用中划线分隔，通常也不使用下划线分隔，所有单词连写在一起（测试文件、平台/架构特定文件除外）
- 文件名后缀为 `.go`
- 应用程序入口文件通常命名为 `main.go`
- 测试文件名以 `_test.go` 结尾，`go test` 仅扫描此类文件，编译并运行其中的 `TestXxx`、`BenchmarkXxx`、`ExampleXxx` 等测试函数
- 模糊测试函数形如 `FuzzXxx`（Go 1.18+），需写在以 `_test.go` 结尾的文件中。为便于区分，社区常以 `_fuzz_test.go` 作为模糊测试文件名，但该命名并非 Go 工具链的强制要求
- 平台/架构特定文件按照 `name_GOOS.go`、`name_GOARCH.go` 或 `name_GOOS_GOARCH.go` 的模式命名，编译时自动选择对应平台/架构。示例：`file_linux_amd64.go`

### 源文件结构

```text
// 声明所在的包
package 包名

// 导入依赖包
import (
    "标准库"
    "第三方库"
    "本项目内部包"
)

// 包级 const、var 声明，即包级常量、包级变量
// init() 函数（包初始化）
// struct、interface 类型定义
// 构造函数 NewXxx()
// struct 方法（按接收者分组）
// 其它工具函数
```

### 注释

- 行注释：以 `//` 开头，注释内容直到行尾结束
- 块注释：以 `/*` 开头，以 `*/` 结尾，注释内容可以跨越多行

注意：

- 注释应解释动机与取舍（“为什么”），而不是机械复述实现细节（“做了什么”）或转译源码
- 所有导出的包、常量、函数、类型、方法等应当添加注释

## 代码格式化工具

- [gofmt](https://go.dev/cmd/gofmt/) 官方工具，使用：`gofmt -w .`
- [gofumpt](https://github.com/mvdan/gofumpt) 更严格的 gofmt，安装：`go install mvdan.cc/gofumpt@latest`，使用 `gofumpt -l -w .`
- [golines](https://github.com/segmentio/golines) 处理长行（long lines）的格式化，安装：`go install github.com/segmentio/golines@latest`，使用 `golines -w .`，可通过 `--max-len` 指定最大长度

## 代码静态检查（lint）工具

### go vet

官方静态检查工具，执行 `go vet ./...` 检查代码中可能的错误。

完整检查器列表见 `go tool vet help`。

### staticcheck

官方文档：<https://staticcheck.dev/docs/>

安装：`go install honnef.co/go/tools/cmd/staticcheck@latest`

使用：`staticcheck ./...`

### revive

运行速度更快、更严格、可配置、可扩展，是 golint 的现代化替代品，官方文档：<https://github.com/mgechev/revive>

安装：`go install github.com/mgechev/revive@latest`

查看 revive 版本：`revive -version`

使用：`revive ./...`

`-config` 配置文件默认为 `$HOME/revive.toml`。如果找不到配置文件，revive 将使用内置的默认代码检查规则集。

### golangci-lint

集成多种检查器的静态分析工具，官方文档：<https://golangci-lint.run/>

安装指南：<https://golangci-lint.run/docs/welcome/install/#local-installation>

常用命令：

- `golangci-lint run` 等价于 `golangci-lint run ./...`
- `golangci-lint run --default=none -E errcheck` `-E/--enable` 启用 linter，`-D/--disable` 禁用 linter
- `golangci-lint run dir1 dir2/...` 分析指定的目录
- `golangci-lint run file1.go` 分析指定的文件
- `golangci-lint cache clean` 清理缓存

golangci-lint 的配置文件为 `.golangci.yml`，文档：<https://golangci-lint.run/docs/configuration/file/>

### gosec

代码安全漏洞扫描工具，官方文档：<https://github.com/securego/gosec/>

安装：`go install github.com/securego/gosec/v2/cmd/gosec@latest`

使用：`gosec -tests ./...`

## 第一个项目 Hello World

创建项目：

```bash
mkdir hello-world && cd hello-world
go mod init example.com/hello-world  # 模块初始化，指定模块路径为 example.com/hello-world
```

用 VSCode 打开项目：`code .`，创建 `main.go` 文件，内容如下：

```go
// 声明所在的包为 main
package main

// 导入标准库的 fmt 包，用于打印输出
import "fmt"

func main() {
 // 调用 fmt 包中的 Println 函数
 fmt.Println("Hello, World!")
}
```

运行代码：`go run main.go`，输出：Hello, World!

构建（build）可执行文件：`go build`，生成 hello-world 可执行文件

运行可执行程序：`./hello-world`，输出：Hello, World!

> [!TIP]
> 创建 `main.go` 文件后，VSCode 会提示安装 Go 相关插件，推荐 [官方 Go 插件](https://marketplace.visualstudio.com/items?itemName=golang.go)。安装完成后自动下载相关工具（如 gopls、dlv 等），按提示确认即可。

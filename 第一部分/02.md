# 项目与源文件

## 项目命名

项目名（仓库名）按社区惯例使用全小写单词，单词之间以中划线 `-` 连接。示例：

- [go-ethereum](https://github.com/ethereum/go-ethereum) 以太坊客户端（区块链）
- [go-micro](https://github.com/micro/go-micro) 微服务开发框架

Go 工具链不强制约束项目名，模块路径（`go.mod` 中 `module` 声明的值）才是 Go 识别模块的唯一标识。

## 源文件

### 命名规范

- 文件名使用全小写单词，单词之间不使用中划线连接，通常也不使用下划线连接，所有单词连写在一起（测试文件与平台特定文件除外）
- 文件名后缀为 `.go`
- 应用程序入口文件通常命名为 `main.go`
- 测试文件名以 `_test.go` 结尾，`go test` 仅扫描此类文件，编译并运行其中的 `TestXxx`、`BenchmarkXxx`、`ExampleXxx` 等测试函数
- 模糊测试文件名以 `_fuzz_test.go` 结尾，其中包含 `FuzzXxx` 测试函数
- 平台特定文件按照 `name_GOOS.go`、`name_GOARCH.go` 或 `name_GOOS_GOARCH.go` 的形式命名，编译时自动选择对应平台。示例：`file_linux_amd64.go`

### 文件结构

```text
// 声明所在的包
package 包名

// 导入依赖包
import (
    "标准库"
    "第三方库"
    "本项目内部包"
)

// 包级 const、var 声明，即包级常量、包级变量
// struct、interface 类型定义
// 构造函数 NewXxx()
// struct 方法（按接收者分组）
// 其它工具函数
```

### 代码格式化工具

- [gofmt](https://go.dev/cmd/gofmt/) 官方工具，使用：`gofmt -w .`
- [gofumpt](https://github.com/mvdan/gofumpt) 更严格的 gofmt，安装：`go install mvdan.cc/gofumpt@latest`，使用 `gofumpt -l -w .`
- [golines](https://github.com/segmentio/golines) 处理长行（long lines）的格式化，安装：`go install github.com/segmentio/golines@latest`，使用 `golines -w .`，可通过 `--max-len` 指定最大长度

## 第一个项目 Hello World

创建项目：

```bash
mkdir hello-world && cd hello-world
# 模块初始化，指定模块路径为 example.com/hello-world
go mod init example.com/hello-world
```

用 VSCode 打开项目：`code .`，创建 `main.go` 文件，内容如下：

```go
// 声明所在的包为 main
package main

// 导入标准库的 fmt 包，用于打印输出
import "fmt"

func main() {
 fmt.Println("Hello, World!") // 调用 fmt 包中的 Println 函数
}
```

运行程序：

```bash
go run main.go
# 输出：Hello, World!
```

构建（build）可执行文件：

```bash
go build       # 产生 hello-world 可执行文件
./hello-world  # 运行
```

> [!TIP]
> 创建 `main.go` 文件后，VSCode 会提示安装 Go 相关插件，推荐 [官方 Go 插件](https://marketplace.visualstudio.com/items?itemName=golang.go)。安装完成后自动下载相关工具（如 gopls、dlv 等），按提示确认即可。

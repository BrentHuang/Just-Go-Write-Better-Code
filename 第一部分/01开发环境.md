# 开发环境

Go 官网：<https://go.dev/>，安装指南：<https://go.dev/doc/install>。安装完成后执行 `go version` 确认版本。

## 环境变量

常用命令：

- `go env` 列出全部 Go 环境变量及其当前值
- `go env -w VAR=VAL` 持久化设置环境变量（写入 Go 的环境配置文件 `GOENV`，类 Unix 系统默认位于 `$HOME/.config/go/env`）
- `go env -u VAR` 清除自定义设置，恢复默认值

### GOROOT

Go 的安装目录（默认 `/usr/local/go`），包含标准库、编译器与工具链。通常由安装器自动设置，无需手动修改。

### GOPATH

Go 传统的工作区根目录（默认 `~/go`）。自 Go 1.16 模块模式成为默认以来，项目源码可存放于任意目录，GOPATH 不再承担源码存放职责，转而主要承担两类缓存职责：

- 工具安装：`go install` 安装的可执行文件存放于 `GOBIN`（默认为 `${GOPATH}/bin`）目录
- 依赖缓存：构建或 `go get` 下载的依赖包存放于 `GOMODCACHE`（默认为 `${GOPATH}/pkg/mod/`）目录

上述两个目录均可通过 `GOBIN` 和 `GOMODCACHE` 环境变量单独指定。

需将 `~/go/bin` 加入系统环境变量 `PATH`，才能在任意位置直接调用这些工具：

```bash
echo 'export PATH=$PATH:${HOME}/go/bin' >> ~/.bashrc
```

### GOTOOLCHAIN

控制 Go 工具链的获取与切换策略，Go 1.21 引入。取值如下：

- `local` 仅使用本地已安装版本，不自动下载其他版本
- `auto`（默认值）优先使用本地版本；若项目 `go.mod` 中的 `go` 或 `toolchain` 指令要求更高版本的 Go，则自动下载对应工具链，存放于模块缓存目录 `${GOPATH}/pkg/mod/`（形如 `golang.org/toolchain@v0.0.1-go1.XX.X...`）
- `go1.27.0` 强制使用指定版本；若该版本尚未安装，同样会自动下载

查看当前策略：`go env GOTOOLCHAIN`

### GOPROXY

设置模块代理，用于加速依赖下载并缓解网络访问问题：

```bash
go env GOPROXY  # 查看当前设置
go env -w GOPROXY="https://goproxy.cn,https://goproxy.io,https://proxy.golang.org,direct"  # 设置代理（从左到右依次尝试，最后 fallback 到 direct 直连）
go env -u GOPROXY  # 恢复默认值
```

## 工具管理

### Go 命令行补全

使用第三方工具 [posener/complete](https://github.com/posener/complete) 为 Go 子命令添加补全：

```bash
# https://github.com/posener/complete/tree/master
go install github.com/posener/complete/v2/gocomplete@latest
yes | COMP_INSTALL=1 gocomplete  # 卸载：COMP_UNINSTALL=1 gocomplete
```

安装后重新打开 shell 生效。

### delve（dlv）调试器

安装 Go 调试器 delve：

```bash
# https://github.com/go-delve/delve
go install github.com/go-delve/delve/cmd/dlv@latest
```

为 delve 添加命令行补全：

```bash
if ! grep -Fxq 'source <(dlv completion bash)' "${HOME}/.bashrc"; then
    echo 'source <(dlv completion bash)' >> "${HOME}/.bashrc"
fi
```

### 已安装工具的管理

使用第三方工具 [gup](https://github.com/nao1215/gup) 管理通过 `go install` 安装的全局 Go 命令行工具：

```bash
# https://github.com/nao1215/gup
go install github.com/nao1215/gup@latest
"${HOME}/go/bin/gup" completion --install  # gup 命令行补全
```

常用命令：

- `gup check` 检查可更新工具
- `gup update` 更新所有工具
- `gup update <tool>` 更新指定工具
- `gup list` 列出已安装工具
- `gup remove <tool>` 删除指定工具
- `gup export --output > gup.json` 导出工具列表到 json 文件
- `gup import --file gup.json` 从 json 文件导入并安装

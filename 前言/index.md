# 写作本书的原因

## 背景

市面上的 Go 编程书籍，有的出版时间较早，所基于的 Go 版本过低，未能覆盖模块管理、泛型、工作区等重要的现代语言特性；有的翻译质量参差不齐，语句生硬，影响阅读体验；还有的对知识点浅尝辄止，停留在 API 罗列层面，未能揭示设计意图与内在机理。

本书采用 Go 1.27 版本，覆盖最新的语言特性，将官方定义、官方文档与示例代码三者结合，力求让读者不仅知道“怎么用”，更理解“为什么这样设计”。

本书还专门设置了“数据结构”部分，深入讲解每种内置数据结构的底层实现、性能特征与适用场景，帮助读者在实际项目中做出合理的选择。

此外，本书不仅讲解语言本身，还涵盖工程化实践中的工具与方法，如项目结构、代码规范、测试策略、依赖管理等，帮助读者建立完整的开发工作流。

## 目标

本书面向具备一定编程基础、希望系统学习 Go 语言的开发者。读完本书后，读者将能够：

- 深入理解 Go 的核心语法、类型系统与并发模型
- 掌握 Go 模块、包管理与项目工程化实践
- 熟悉标准库中的关键数据结构与常用包
- 编写符合 Go 惯用风格的高质量代码
- 具备独立排查和解决实际开发问题的能力

## 说明

本书示例代码的开发环境为：Linux Mint 22.3 Zena

go version 为：go1.27.0 linux/amd64

shell 为：`/bin/bash`

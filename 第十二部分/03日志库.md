## 日志库

todo 对照一下官方文档

Go 1.21+ 标准库引入 `log/slog` 包，提供结构化日志记录。官方文档：[log/slog](https://pkg.go.dev/log/slog)

### 核心概念

| 特性 | 说明 |
| -- | -- |
| 日志级别 | Debug、Info、Warn、Error，可全局或按 Handler 设置 |
| 输出格式 | TextHandler（key=value）或 JSONHandler（json 对象），文本格式便于开发阅读，json 格式便于日志系统采集 |
| 基本用法 | `slog.Info("message", "key", value)`，支持附加任意多个键值对或 `slog.Attr` |
| 上下文支持 | `slog.InfoContext(ctx, "message", "key", value)`，便于在处理链中传递和记录跟踪信息。Logger.Log 和 Logger.LogAttrs 方法将 context 作为第一个参数 |
| 性能优化 | `LogAttrs` + `slog.Type`（如 `slog.Int`、`slog.String`）减少反射开销，示例：`slog.LogAttrs(context.Background(), slog.LevelInfo, "message", slog.String("key", value))` |
| 分组日志 | `logger.WithGroup("group")` 返回一个与原始 logger 具有相同 Handler 的新 Logger，新 Logger 产生的所有日志都会带有分组名称。在大型系统中，各个子系统可能使用相同的键记录日志，通过为每个子系统分配一个带有分组名称的 Logger，可以对各个子系统的日志进行区分 |
| 统一属性 | `logger.With("service", "auth")` 返回一个与原始 logger 具有相同 Handler 的新 Logger，新 Logger 产生的所有日志都会带有 "service=auth" 这个公共字段 |

slog 是 Goroutine-Safe（并发安全）的，可安全地在多个 Goroutine 中并发使用同一个 Logger 实例。需要注意：slog 保证的是其内置标准 Handler 的并发安全，自定义 Handler 需确保 `Handle` 方法也是 Goroutine-Safe 的。

```go
// 多个 Goroutine 并发使用同一个 Logger 实例，日志不会错乱
func main() {
 // 创建一个全局的 Logger
 logger := slog.New(slog.NewTextHandler(os.Stdout, nil))

 var wg sync.WaitGroup // 用于等待一组 Goroutine 执行完毕

 // 模拟启动多个并发的任务 - 方式 1
 for i := range 5 {
  wg.Add(1) // 计数器增加 1，表示有一个 Goroutine 会执行
  go func(taskID int) {
   defer wg.Done() // 当 Goroutine 执行完毕后，计数器减少 1，表示有一个 Goroutine 执行完毕
   // 每个 Goroutine 都使用同一个 logger 实例记录日志
   logger.Info("任务执行中",
    "task_id", taskID,
    "status", "processing")
  }(i)
 }

 // 模拟启动多个并发的任务 - 方式 2
 for i := range 5 {
  wg.Go(func(taskID int) func() {
   return func() {
    // 每个 Goroutine 都使用同一个 logger 实例记录日志
    logger.Info("任务执行中",
     "task_id", taskID,
     "status", "processing")
   }
  }(i))
 }

 wg.Wait() // 等待所有 Goroutine 执行完毕
 logger.Info("所有任务执行完毕")
}
```

> [!NOTE]
> [func (wg *WaitGroup) Go(f func())](https://pkg.go.dev/sync#WaitGroup.Go) 是 Go 1.25 新增的方法，在一个新协程中调用 f，并将该任务添加到 WaitGroup 中。当 f 返回时，该任务将从 WaitGroup 中移除。函数 f 不能 panic。

注意：`log/slog` 本身不提供异步写入功能。

### 基本用法

默认日志级别为 LevelInfo，输出到 `os.Stderr`，使用 TextHandler：

```go
func main() {
 slog.Debug("这是一条调试信息", "user_id", 123)    // 默认级别为 Info，这条级别不够，不会输出
 slog.Info("用户登录成功", "username", "alice")   // 会自动为每条日志换行，不需要手动添加 \n
 slog.Warn("磁盘空间不足", "available_GB", 1.5)
 slog.Error("数据库连接失败", "err", errors.New("hello, 世界"))

 // 一个 Attr 是一个键值对。Logger 的输出方法既接受键值对，也接受 Attr。
 slog.Info("hello", "count", 3)            // 键值对
 slog.Info("hello", slog.Int("count", 3))  // Attr，性能更好
}

/*
2025/11/19 13:44:04 INFO 用户登录成功 username=alice
2025/11/19 13:44:04 WARN 磁盘空间不足 available_GB=1.5
2025/11/19 13:44:04 ERROR 数据库连接失败 error="hello, 世界"
2025/11/19 13:44:04 INFO hello count=3
2025/11/19 13:44:04 INFO hello count=3
*/
```

可以通过 `slog.SetLogLoggerLevel(slog.LevelDebug)` 启用 Debug 级别日志。

### 自定义 Logger

`slog.New` 创建一个 Logger，`slog.NewTextHandler` 创建一个 TextHandler，用于将日志输出为 key=value 格式。通过 `slog.HandlerOptions` 配置 Handler，如添加源码位置、动态过滤或重写属性值。

`slog.SetDefault` 将自定义的 Logger 设置为全局默认，这样调用 slog.Info 等函数时会使用它。这个设置同时也会影响 log 标准库的输出。

显式文件名和行号：

```go
func init() {
 slog.SetDefault(slog.New(slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
  AddSource: true,  // 显示文件名（完整路径）和行号
 })))
}
```

只保留文件名和行号：

```go
func init() {
 handler := slog.NewTextHandler(os.Stdout, &slog.HandlerOptions{
  AddSource: true,
  ReplaceAttr: func(groups []string, a slog.Attr) slog.Attr {
   if a.Key == slog.SourceKey {
    source := a.Value.Any().(*slog.Source)
    // 只保留文件名和行号
    source.File = filepath.Base(source.File)
   }
   return a
  },
 })
 slog.SetDefault(slog.New(handler))
}
```

创建 JSON 格式和文本格式的 Logger：

```go
import (
 "log"
 "log/slog"
 "os"
)

func main() {
 // 创建输出为 json 格式的 Logger
 jsonLogger := slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{Level: slog.LevelInfo}))
 jsonLogger.Info("操作完成", "status", "success", "code", 200)
 // 输出：{"time":"2025-10-13T18:46:56.204092016+08:00","level":"INFO","msg":"操作完成","status":"success","code":200}
 jsonLogger.Info("操作完成", slog.String("status", "success"), slog.Int("code", 200))  // 性能更好
 // 输出：{"time":"2026-05-24T15:43:34.655556417+08:00","level":"INFO","msg":"操作完成","status":"success","code":200}

 // 创建输出为文本格式的 Logger
 textLogger := slog.New(slog.NewTextHandler(os.Stdout, nil))
 textLogger.Warn("温度过高", "current_temp", 85.5)
 // 输出：time=2025-10-13T18:46:56.204+08:00 level=WARN msg=温度过高 current_temp=85.5

 // 将自定义的 Logger 设置为全局默认，这样调用 slog.Info 等函数时会使用它。这个设置同时也会影响 log 标准库的输出。
 slog.SetDefault(jsonLogger)
 // 此后，slog.Info 和 log.Println 都会使用这个新的 json Logger
 slog.Info("这条日志是 json 格式", "username", "Hardy")
 // 输出：{"time":"2025-11-12T20:35:39.552745123+08:00","level":"INFO","msg":"这条日志是 json 格式","username":"Hardy"}
 log.Println("这条日志是 json 格式")
 // 输出：{"time":"2026-05-24T15:39:54.697233379+08:00","level":"INFO","msg":"这条日志是 json 格式"}
}
```

### 添加公共字段

使用 With 方法可以为 Logger 添加公共字段，这些字段会出现在该 Logger 产生的所有日志中。With 方法既接受键值对，也接受 Attr。

```go
func main() {
 jsonLogger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
 serviceLogger := jsonLogger.With("service", "user-service", "version", "1.0.0")  // 日志会自动包含 service 和 version 字段
 serviceLogger.Info("服务启动")
 serviceLogger.Info("操作完成", "status", "success", "code", 200)
 // 输出：{"time":"2025-10-13T18:46:56.204092016+08:00","level":"INFO","msg":"服务启动","service":"user-service","version":"1.0.0"}
 // 输出：{"time":"2025-10-13T18:46:56.204092016+08:00","level":"INFO","msg":"操作完成","service":"user-service","version":"1.0.0","status":"success","code":200}
}
```

### 性能优化

Logger 的输出方法既接受键值对，也接受 Attr。对于性能敏感或高频调用的代码路径，建议使用 LogAttrs 方法并传入强类型的 Attr 参数（如 `slog.String`、`slog.Int`），减少反射开销：

```go
func main() {
 logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))

 userID := "u20241013"
 loginCount := 27
 ip := "192.168.1.100"

 // 方式 1：使用交替的 key-value 对，常见方式，但有一定开销
 logger.Info("用户登录", "userID", userID, "loginCount", loginCount, "ip", ip)

 // 方式 2：使用强类型 Attr
 logger.Info("用户登录", slog.String("userID", userID), slog.Int("loginCount", loginCount), slog.String("ip", ip))

 // 方式 3：使用 LogAttrs 和强类型 Attr，性能更优
 ctx := context.Background()

 logger.LogAttrs(ctx, slog.LevelInfo, "用户登录",
  slog.String("userID", userID),
  slog.Int("loginCount", loginCount),
  slog.String("ip", ip),
 )

 logger.LogAttrs(ctx, slog.LevelInfo, "得分", slog.String("username", "Hardy"), slog.Float64("score", 100.0))
}
```

### 输出到文件

借助日志轮转库 [lumberjack](https://github.com/natefinch/lumberjack) 实现日志轮转：

```go
import (
 "log/slog"

 "gopkg.in/natefinch/lumberjack.v2"
)

// 需安装此库进行日志轮转，lumberjack：伐木工人
// go get gopkg.in/natefinch/lumberjack.v2

func main() {
 lumberjackLogger := &lumberjack.Logger{
  Filename:   "/tmp/app.log",
  MaxSize:    10,  // MB
  MaxBackups: 5,
  MaxAge:     30,  // days
 }

 logger := slog.New(slog.NewJSONHandler(lumberjackLogger, nil))
 logger.Info("This json log goes to a file with rotation.")
}
```

### 动态修改日志级别

```go
// 要为整个程序动态修改日志级别，首先需要初始化一个全局 LevelVar
var programLevel = new(slog.LevelVar) // 默认 Info 级别

func main() {

 // 然后使用 LevelVar 来构建一个 handler：
 h := slog.NewJSONHandler(os.Stderr, &slog.HandlerOptions{Level: programLevel})
 slog.SetDefault(slog.New(h))

 slog.Debug("111") // programLevel 默认为 Info，所以 Debug 级别的日志不会被记录
 slog.Info("222")

 // 现在，程序可以通过一条语句来更改其日志级别：
 programLevel.Set(slog.LevelDebug) // 现在将日志级别更改为 Debug

 slog.Debug("333") // Debug 级别的日志会被记录
 slog.Info("444")
}
```

### 多路输出

`MultiHandler` 可以将多个 Handler 组合成一个 Handler，这样日志事件就会被同时发送到多个目的地，例如同时输出到控制台和文件。

```go
import (
 "log/slog"
 "os"
 "path/filepath"
)

func main() {
 h1 := slog.NewJSONHandler(os.Stdout, nil)

 // 输出到文件
 logFile := filepath.Join(os.TempDir(), "log.txt")
 f, err := os.Create(logFile)
 if err != nil {
  panic(err)
 }
 defer f.Close()
 h2 := slog.NewTextHandler(f, nil)

 multiHandler := slog.NewMultiHandler(h1, h2)
 logger := slog.New(multiHandler)

 logger.Info("这条日志会同时输出到 stdout 和 文件")
}
```

### 集中式日志收集

生产环境通常使用 Fluentd、Logstash 等日志收集代理，Go 应用通过客户端库将日志发送给本地代理，再由代理转发到 Elasticsearch 等目的地。

### 第三方日志库

#### zerolog

[zerolog](https://github.com/rs/zerolog) 以高性能著称，这得益于其使用强类型字段和避免反射的设计。为了保持这一优势，请尽量使用链式调用的强类型方法，如 `.Str()`、`.Int()`，而非 `.Msgf()` 格式化输出，因为后者在底层使用了反射，会有性能损耗。

```go
import (
 "os"
 "time"

 "github.com/rs/zerolog"
 "github.com/rs/zerolog/log"
 "gopkg.in/natefinch/lumberjack.v2"
)

// go get -u github.com/rs/zerolog/log

func main() {
 // 配置 lumberjack 日志轮转器
 lumberjackLogger := &lumberjack.Logger{
  Filename:   "./logs/myapp.log",  // 日志文件路径
  MaxSize:    10,                  // 单个日志文件最大容量（MB）
  MaxBackups: 5,                   // 保留的旧日志文件最大数量
  MaxAge:     30,                  // 保留旧日志文件的最大天数
  Compress:   true,                // 是否压缩备份的日志文件
 }

 // 创建多路输出器：同时输出到控制台和文件
 multiWriter := zerolog.MultiLevelWriter(
  // 控制台输出，使用更易读的格式
  zerolog.ConsoleWriter{
   Out:        os.Stdout,
   TimeFormat: time.RFC3339,
  },
  // 文件输出，由 lumberjack 管理
  lumberjackLogger,
 )

 // 初始化全局 logger
 logger := zerolog.New(multiWriter).With().Timestamp().Caller().Logger()  // 输出时间、行号
 log.Logger = logger

 // 现在可以开始记录日志了
 log.Info().Str("status", "started").Msg("Application launched successfully.")  // Msg() 或 Send()
}

// 输出：2025-11-03T20:34:15+08:00 INF main.go:42 > Application launched successfully. status=started
```
